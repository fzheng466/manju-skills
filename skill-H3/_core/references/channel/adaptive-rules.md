# 自适应编译规则矩阵

规则在 `core/lib/adapt.py` 实现。执行顺序：**画幅（按交付线）→ 时长 → 模式 → 参考 → 音频 → 长度**（切分会改变每段需要的参考和台词）。

每次编译输出 `adaptation-report.md`，与面谈第 2 步预览是同一份内容。用户确认后才编译。

## 时长 R-DUR

| ID | 触发 | 动作 |
|---|---|---|
| R-DUR-01 | job 时长 > 生效 max | 在 beat 边界切分。切点：① 台词句末 ② 动作收势 ③ 已有 cut ④ 焦点移交。前段 end_state = 后段 start_state |
| R-DUR-02 | 单个 beat > max | 退回导演谱，不硬切 beat。台词不在句中切开（除非剧本 `<cutoff>`） |
| R-DUR-03 | 一句台词按语速放不进 max | 阻断。选项：换更长渠道 / 画外音+后期 / 授权拆句 |
| R-DUR-04 | 切分后某段 < min | 先与相邻段合并；合并不了则延长末态停留 ≤1.5s（必须写成可见停留） |
| R-DUR-05 | 渠道只要整数秒 | 向上取整；切点落在整秒 |
| R-DUR-06 | max 远大于原时长 | 只建议合并，不自动合并 |
| R-DUR-07 | 延长能力 verified | 可用「首段+延长」代替拆段；延长段首 1 秒只写微动作（FM-03） |

## 画幅 R-AR

| ID | 触发 | 动作 |
|---|---|---|
| R-AR-01 | 某条交付线渠道不支持该画幅 | **只暂停这一条线**。三选一：`switch_channel` / `wait` / `derivative`（`canon:false`，不替代正片）。其他交付线继续编译。 |
| R-AR-02 | 用户选了 9:16 | 按 `_core/references/assets/aspect-tracks.md`：双人并排改纵深或上下分层；横移改升降或推拉；四向板裁竖幅或单独出竖幅场景图 |
| R-AR-03 | 跟随首帧 | 仅当首帧是目标画幅；否则禁用帧锚 |
| R-AR-04 | 参考图画幅不同 | 允许（参考只锁身份），正文不写「按参考图构图」 |

## 模式 R-MODE

| ID | 触发 | 动作 |
|---|---|---|
| R-MODE-01 | 要首帧续接但渠道没有 | 改为参考或纯文本；末帧当普通参考（名额够时） |
| R-MODE-02 | 要尾帧但不支持 | 删尾帧，文字强调末态 |
| R-MODE-03 | 要参考集但渠道参考数=0 | 纯文本，每镜复述识别点和结构计数；标高风险 |

## 参考图 R-REF

按**资产**优先级，不是「身份>服饰>场景」（四视图里身份和服饰同一张图）。

P1 帧锚（仅帧锚模式）→ P2 本段主说话/动作角色板 → P3 其他可见角色 → P4 手持/交互道具 → P5 场景结构 → P6 非交互道具 → P7 风格氛围。

上限很大时仍按模型基线截断，**不因为名额多就多放**。未被正文引用的参考删除（G7）。上限 ≤2 且 ≥3 个主要可见角色 → 按角色拆段，禁止擅自拼图。

## 音频 R-AUD

`audio_output=none`：正文删音景/配乐；台词只写可见口型；生成 `audio_post_plan.json` 给后期 TTS。不支持 2.5 声音标记时一律自然语言。

## 其他

R-LEN-01 超字数：先删重复服饰形容和氛围修辞；站位、出场、台词、末态不删。R-NEG-01 无负向字段：前 3 项改写成正向约束。R-BILL-01 计费 unknown：可编译，阻断提交。

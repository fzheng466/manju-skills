# 双画幅交付线（16:9 与 9:16）

项目画幅是**开场第一问**，不是渠道说了算。可选：只 16:9、只 9:16、两条都要。

`project.json` 示例：

```json
{
  "deliverables": [
    {"track_id": "L", "aspect": "16:9"},
    {"track_id": "P", "aspect": "9:16"}
  ],
  "primary_track": "L"
}
```

## 资产

| 资产 | 共用？ | 规则 |
|---|---|---|
| 人物四视图身份板 | 共用 | `asset_role: identity`，画幅可跟主线，引用时不锁视频构图 |
| 场景四向结构板 | 结构共用 | 9:16 从该格取中心竖条，锚点必须在裁窗内；短边不够则单独出竖幅场景图，禁止拉伸 |
| 构图资产 | 分线 | `SCENE_<ID>_<方向>_P` 登记 parent、crop_box、aspect、track_id |

## 镜头提示词

| 项 | 16:9 | 9:16 |
|---|---|---|
| 开头 | 16:9横屏 | 9:16竖屏 |
| 双人 | 左右并排、过肩 | 前后纵深或上下错位 |
| 全身高度占比 | 65–85% | 75–90% |
| 运镜 | 横移、水平摇可用 | 升降、推拉、竖摇为主 |
| 安全区 | 左右边缘 | 上下约 8% 留给字幕/UI |

剧情 beats、台词、出场顺序两条线共用。构图字段放 `beats[].framing.L` / `beats[].framing.P`。副线构图必须单独审，不能套主线。

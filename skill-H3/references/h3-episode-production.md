# H3 漫剧镜头生产与连续性执行规范

本规范用于16:9、3D半写实国漫连续剧，将剧本、导演谱、H3提示词、审片和剪辑接成一条工作链。实际调用仍以当前provider capability与h3-prompt-compiler.md为准。

## 段卡与状态传递

一集是90–180秒的戏剧段落；单个H3 job是其中4–15秒、可审核且可拼接的表演片段。先按剧情转折拆场，再按一条主要因果链拆job。不能以人物展示、无来源空镜或无效运镜填充时长。

每个job在编译前写段卡，并将前段末态逐项传入本段首态：

| 字段 | 要求 |
|---|---|
| 剧情职责 | 观众新增知道什么，目标、关系或局势如何变化 |
| 承接来源 | 前一job/场次ID；开场段写建立依据 |
| 首态 | 可见性、场景锚点、世界轴、站位、朝向、视线、手与道具、伤损、光线、环境动态、声音尾部 |
| 主因果链 | 触发 → 行动/应对 → 可见结果 → 新状态 |
| 焦点转移 | 先跟随谁，何时因何种可见事件交给谁 |
| 末态与接口 | 下一段可直接继承的构图、动作相位、表情、道具和声音 |

“人物继续对视”“动作保持一致”不是合格状态。应写成可拍事实，例如：“女主位于廊柱南侧，右手悬在杯沿上方未触碰，目光越过水面锁在西岸灯影；水面自右向左的三圈涟漪尚未消散。”

## 剧本拆段

先拆可见事件链，再定镜头。每个事件都要回答：谁先感知什么、为何行动、另一方如何得到信息并回应、结果改变什么。台词必须附着于选择、阻碍或关系变化，不单独替代剧情。

文戏与相遇按“观察对象 → 察觉/选择 → 反应被读到 → 语言或动作回应 → 可继承停留”推进。未出场人物在段卡中明确为画外、完整遮挡或局部可见，并记录揭示触发、首次可见部位、路径及到达位置。

动作、武打与斗法按“预备/重心 → 路径/目标 → 接触、避让或失手 → 受力与环境反馈 → 双方新站位”覆盖。技能还需写“来源 → 聚集/成形 → 传播 → 命中/作用 → 消散或残留”。一个战斗job只设置一个峰值事件；峰值前有起手和目标，后面给对手或环境反馈及下一动作接口。

## 时长与负荷

先分配对白和动作时间，再写提示词。未试读时普通话按约3.5–5.5个汉字每秒估算，另加开口前0.2–0.5秒和句末0.3–0.8秒反应；有实测音频时以实测为准。

人物进离场、跨区域走位、精细道具交接、明显表情转折、完整对白、切镜、明显运镜、法术或特效峰值都会增加负荷。10秒内若同时包含两次切镜、多人连续走位、完整对白和精细交互，必须删减或拆成相邻job。复杂片段先用逐镜动作链、时间化导演谱和状态检查核对顺序、站位及末态；只有文字镜头表仍无法解决具体可视化歧义、且预演能降低成本时，才选择故事板。玄幻仙侠武打不制作多格剧情故事板，使用高细节逐镜提示词控制动作、景别、焦点和空间连续性。

## 导演谱与编译

每个job先写连续性账本、段卡、导演谱，后编译正文。beats必须连续覆盖全部时长；每个beat只包含一个主要变化，写焦点、人物位置和朝向、视线、动作路径、微表情或呼吸、摄影机、声音和结束状态。

正文依次写：绑定资产与首态；时间化动作；说话者和听者分开的表演；稳定音色档案与本句表演层；每beat最多一个主运动的摄影机与同步声音；最后写可续接末态。接近长度上限时先删重复服装、氛围和修辞，不能删站位、动作相位、对白、出场顺序和末态。

## 模式与素材选择

| 最大风险 | 优先方案 |
|---|---|
| 角色、场景、法器等外观需参考 | Ref2VA，按真实附件与控制范围绑定 |
| 已审核前段的末态要从同一画面继续 | 从归档视频抽真实末帧，使用I2VA |
| 还需明确落到指定结束构图 | FL2VA，首尾均为审核通过的16:9实际素材 |
| 无身份或续接锚定需求 | T2VA |

一个job只能选一种模式。首尾帧模式与Ref2VA不混用；需要续接时应让要保留的资产真实出现在锚帧中。不得把故事板整板、人物四视图整板或未审核图片当续接锚帧。

## 生成绿灯与审片

提交前确认：本段有单一剧情职责与完整因果链；每位角色的画内、画外或遮挡状态明确；环境、道具、特效和声音变化都有来源；重要动作保留起手、路径、反馈和结束；台词的原文、说者、音色档案、时长、停顿、双方反应完整；景别、人景比例、观察视点、焦点转移与切镜理由清楚；运镜有叙事理由；模式、附件、时长、16:9与capability记录一致；若本段确实采用故事板则已完成核验；用户已授权本job和预算。

每条成片先独立审片，再和前后段连看。按“job ID、时间码、问题、证据、最小修复、受影响邻段”登记，优先级为：身份与可见性 → 空间和轴线 → 动作因果 → 剧情与表演 → 摄影和声音。

先找根因再返修：资产或锚帧错误回到资产或模式；站位、动作、台词错误回导演谱；字段或附件错误回编译；仅生成后的局部漂移才返修当前段。只重做受影响job和必要直接邻段。前段视频必须已人工审核、归档后才可抽末帧；锚帧不代替后段审片。

## 剪辑复核

粗剪按剧情目标复核：每场是否推动目标、信息、关系或阻碍；焦点转移是否由事件触发；人物、法器、伤损、天气和声音是否有来源与去向；相邻job是否构成行动和反应的连续句。没有有效剧情推进的片段应删、并、重写或拆集，不能以延长运镜补时。

角色音色一致性只有在实际媒体可审听时才能标记为已验证。若provider的声线保持不稳定，可保留H3的视觉、环境与动作声，改用经授权的后期配音完成角色对白；不得承诺文字提示能锁定真人级声纹。

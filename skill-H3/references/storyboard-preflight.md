# 剧情故事板预演

## 用途与输入

故事板是可选的低成本核对方式，不是导演分镜的必经阶段。只有当文字镜头表仍无法核清事件顺序、人物可见性/站位或空间接缝，且静态预演能解决该问题时，才在付费视频生成前制作。玄幻仙侠武打不制作多格剧情故事板，使用逐镜动作链、景别/视点计划和空间状态核查。若采用故事板，使用已确认人物资产、从场景四向结构基准板裁出的对应单视图及必要道具资产；只验证事件顺序、人物可见性与站位、观察关系、动作因果、情绪反应、环境动态和片段接缝，不代替视频运动、口型与声音的实测。

## 分格与接缝

格数由实际剧情节拍决定。每格只表达一个可辨的动作状态、观察变化或信息揭示；连续动作按起手、变化、结果保留足够关键状态。单张最多24格。超过24格时，在自然动作节点按连续时间线拆为第二张及后续板；前一板末格与后一板首格必须继承相同的人物位置、朝向、动作相位、场景状态和声音尾部。

每格在板外清单登记：`panel_id / job_id / 时间窗 / 焦点或观察者 / 景别与机位 / 可见角色及场景锚点 / 视线目标 / 动作起点与结果 / 环境动态 / 下一格承接`。图内不依赖模型生成可读文字。主观镜头先给出观察者与视线证据，再展示所见或反应；动作戏按起手、应对、接触、受力与新站位分格。

## 参考、审核与视频绑定

逐板登记真实输入图及控制范围：人物四视图仅锁身份与服装；场景以四向基准板裁出的单视图锁可见结构；道具图仅锁形态。人物走位、机位、表演和动作由导演谱控制。逐格核验身份、空间锚点、世界轴、前后状态和事件顺序；失败只修受影响板及其接缝。用户确认剧情展示后，记录故事板版本和审核结果。

多宫格整板不能直接作为视频首帧、尾帧或唯一参考。需要画面锚点时，从通过的板中裁出无边框、无标注的单格，核验16:9、清晰度和资产一致性后，按实际H3模式绑定；单格不够清晰时另制可用锚图。故事板通过不授权视频生成。故事板涉及付费生图时，遵循逐张展示、确认后再下一张、无轮询且无自动重试的资产生成规则。

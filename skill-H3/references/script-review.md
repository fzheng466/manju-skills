# 剧本审查与改写

## 入口与证据范围

原创剧本写成可拍场次后、冻结对白与制作资产前运行审查；现成剧本先审查再决定修订。单场/片段只审当场可证实的因果、表演与空间，跨场前提列为待核，不能凭缺失的前情判定漏洞。多集审查按集推进，每轮读取当前集、已确认设定、前集结束状态及台账；不把人物的猜测当作客观世界事实。

用户只要求诊断时交问题和改写提案，不覆盖原稿。用户要求改写时保留原稿版本，记录改动场次、原句、改后句和改动原因。已冻结的台词或主创明确锁定的设定，先提出冲突及可行方案；未经改编授权，不直接改动。

## 五项审查

1. **因果、时间与信息**：逐场写出触发事件、人物选择、直接结果和下一场承接；核对世界规则、事件耗时、伏笔埋设与兑现、角色何时从何处获知信息。反转或解法若依赖此前未出现的能力、证据或援手，说明缺少哪条前置条件。前情未提供时改列待核条件。
2. **人物与关系**：检查表层目标、内在需求、当场风险、阻碍、行动策略、关系中的主动权和信任变化。关键背叛、亲近、退让或态度逆转必须有可见触发和过渡；沉默、克制或误会可以成立，不强制每场大反转。对白核对说话者要让对方做什么、实际怎么说、听者如何理解和反应；两人都知道的信息不靠生硬互述交代给观众。
3. **空间与状态**：核对人物是否在场、进入和离开的先后、场景门窗与站位、视线和持物手；跟踪关键道具的取得、转移、使用、损坏、遗失与修复，伤情、污损、服装和光线在相邻场次中的变化。只有足以影响剧情理解或视频接镜的状态才入台账。
4. **可视听表达**：将影响剧情的纯心理结论落实为观众可看到或听到的动作、停顿、选择、道具变化、可辨表情或声音。可用道具、动作与潜台词、第三者反应、冲突中的片段信息披露；不能用泛泛的眼神特写取代必要剧情，也不能为了“展示”拉长没有状态变化的镜头。
5. **集长与制作**：完整单集剧本及分镜应在90–180秒内承载连续故事；按试读、动作、必要停顿与转场估时，区分可同时发生和必须先后的事件。核对单场资产复用、法术/群像复杂度和已知题材常识；专业事实或发布要求需要外部核实时写明待核来源，不声称已完成法律或平台合规审定。

## 问题报告与优先级

每条意见使用同一证据链：`问题ID / 严重度 / 集-场-原句或状态锚点 / 已知前提 / 观众或制作后果 / 最小修补 / 受影响范围 / 复查结果`。引用必要的原文短句，不以空泛评价或未给出的剧情补齐证据。

- **P0 阻断**：核心因果矛盾、关键人物无理由失真、信息不可能获知、关键道具或人物凭空出现、无法在既定世界规则内成立的解法；影响剧本冻结或后续镜头制作。
- **P1 主要**：动机和关系过渡不足、重要伏笔悬空、说明性对白妨碍戏剧推进、状态衔接不明、关键事件不可视听化或真实时长不可承载。
- **P2 打磨**：在剧情已成立的前提下优化潜台词、角色声纹、节奏密度或资产复用。审美偏好不能单独升级为硬伤。

只报告有证据的项目。成立的关键段落也记录它完成了什么剧情任务。审查报告按P0、P1、P2排序；同一根因只保留一条，列出所有受影响场次。

## 修补与复审

缺少前置铺垫的关键转折，给出两种可选修补：前文尚可改时，在前场增加最小线索或行为；前文已锁定时，调整当前解法与已知条件接轨。两种改法都须检查人物动机、伏笔回收和时长，不能凭空创造新的巧合。仅在用户要求改写时落稿，改写范围限于已确认的问题及其必要邻场。

改写后从修订处向前检查前提，向后检查结果；复查受影响的关系、信息、道具、台词和集内时间。P0未解决时停在剧本草稿；P1如暂不修改，记录原因、观众风险与进入制作的条件。冻结后给对白分配稳定ID，并将冻结版本传给分镜和H3编译。

## 多集台账

多集项目在 `01_story/` 保留审查报告与精简台账，至少包括：`伏笔ID-埋设-预期/实际回收-状态`、`人物关系/信任与掌握信息`、`关键道具持有人与物理状态`、`集末剧情与空间状态`、`问题ID与处置`。主创锁定项注明锁定范围和版本；变更有记录，已解决项保留历史而不直接抹去。每集审完更新台账，再读入下一集。全剧完成后复查未回收伏笔、人物关系曲线、重复剧情功能和各集推动的实际变化；不以统一压力分数或强制集尾悬念取代剧情判断。

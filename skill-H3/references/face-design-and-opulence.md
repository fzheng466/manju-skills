# 脸型五官与华丽服饰设计

本参考用于需要强角色辨识度、精细面容或高规格礼服的资产设计。词汇是设计维度，不是固定审美标准；先按角色身份、年龄感、世界观和剧情选取，再组织成一张可直接生成的资产板提示词。

## 1. 四视图板中的脸型与五官设计

### 1.1 何时强化面容

人物脸型、五官和妆面统一设计在默认人物四视图资产板左侧的超大正面胸像中，不拆分为独立面部资产图。主角、重要配角、反复出现且需稳定识别的角色，应利用胸像面积充分刻画骨相、五官比例和肤质；右侧三张全身视图负责确认同一面容在整体角色中的一致性。

### 1.2 四视图胸像的面容呈现

默认16:9人物四视图板中，左侧约35–40%为超大正面胸像；面部需足够大，能清楚识别脸部轮廓、眼睑、鼻唇结构、肤质与妆容。发饰可保留，但不可用厚刘海、夸张冠饰或强烈阴影遮挡主要骨相。右侧正面、45度和背面全身仍保持同一身份；45度视图提供必要的侧向面部透视，背面视图展示发型和服饰结构，不增加独立头像窗、侧脸窗或额外人物。

面容设计阶段保持自然表情、发际线可辨和柔和塑形光；避免磨皮塑料脸、复制粘贴式对称五官或模板化网红脸。角色定稿后，四视图胸像、正面全身和45度全身必须是同一张脸，只允许透视变化，不另做面容资产图。

### 1.3 脸型轮廓词汇

从整体长宽、额颧颌关系、下颌角和下巴形状组合描述，不要只写一个脸型名：

- 鹅蛋/椭圆脸：额宽与颌宽过渡平顺，下颌收束柔和；可偏长、偏圆或偏窄。
- 圆脸：面中饱满、下颌转折弱；说明是幼态圆润还是丰润成熟，避免默认婴儿肥。
- 长脸/窄长脸：面部纵向比例更长，补充额头、面中或下巴具体哪段偏长。
- 方脸/方圆脸：下颌角清楚或经软组织过渡，说明颌宽与颧宽关系，避免直接等同男性化。
- 菱形脸：颧弓最宽，额角与下颌较收；说明颧骨是平滑外扩还是有清晰转折。
- 心形/倒三角脸：额部相对宽、下颌向尖下巴收窄；补充太阳穴与颊部饱满度。
- 梨形/下宽脸：下颌宽于额部，写清下颌角、咬肌和下巴轮廓。
- 窄额宽颌、宽额窄颌、短下巴、长下巴、圆下巴、方下巴、微翘下巴、平直下巴。

“鹅蛋脸”“瓜子脸”等名称只提供总体印象。接着补额头宽度、颧弓突出度、面中长度、下颌线走向和下巴端部，避免模型套用默认美女模板。

### 1.4 五官拆解字段

逐项选择互相协调的特征，优先指出相对比例和形状，不堆互斥形容词。

| 区域 | 描述维度 |
|---|---|
| 额头与发际线 | 额头高/中/低、宽窄、额角形状、发际线圆弧/平直/轻微美人尖、太阳穴饱满度 |
| 眉骨与眉形 | 眉弓平缓/清晰、眉间距、眉头浓淡、平眉/弧眉/长挑眉/剑眉、眉峰和眉尾位置 |
| 眼窝与眼睑 | 眼窝浅/中/深、上眼睑褶皱、内双/浅双/明显双/单眼皮等具体眼睑形态、眼头包裹度、卧蚕有无及程度 |
| 眼形与眼距 | 杏眼、圆眼、狭长眼、上挑/下垂眼尾、眼裂长度与高度、眼距偏近/协调/偏宽、瞳孔比例、左右轻微差异 |
| 鼻部 | 鼻根起点、鼻梁高度与宽度、鼻背直/微弧、鼻尖圆/窄/微翘、鼻翼宽度、鼻小柱和鼻孔正面可见度 |
| 颧颊 | 颧骨位置与外扩程度、颊部饱满/清瘦、苹果肌位置、面中平面转折、阴影深浅 |
| 口唇 | 嘴宽、唇峰形状、上/下唇厚度比例、唇珠、嘴角走向、唇缘清晰度；“樱桃小嘴”要补充小嘴相对脸宽和唇形，避免只生成涂色小圆点 |
| 下颌与下巴 | 咬肌宽度、下颌角锐/圆、下颌线清晰度、下巴长度/宽度/前突度/圆尖形、颏唇沟深浅 |
| 皮肤与识别点 | 肤色和底调、毛孔/细纹/绒毛等真实程度、痣/雀斑/疤痕位置、轻微不对称及稳定识别点 |

必要时记录面部比例倾向：额部/面中/下庭哪段较长，脸宽相对脸长，眼宽与眼距关系，鼻底到唇峰距离，下唇到颏底距离。可以使用“略长、偏窄、接近、微短”等视觉语言；除非项目有测量依据，不编造精确毫米数或黄金比例。

### 1.5 妆容与审美参照词

妆容单独描述眉、眼线、眼影、腮红、唇色、修容和高光的位置、边界、浓淡与质地。裸妆、清透妆、古典妆、舞台妆、冷艳妆、韩系妆造等属于妆造/摄影审美方向，不自动决定脸型或族裔特征。写“韩系”时补充项目实际需要的效果，例如底妆薄透或柔焦、眉形平缓、眼妆低对比、唇妆渐层；按角色调整，避免全部套成同一张脸。

“中德混合观感”“中俄混合观感”等可作为用户给出的角色设计简写，不代表某群体必然拥有固定五官。把它拆成可观察且由本角色设定选择的参数，例如眼窝层次、眉弓转折、鼻根高度、鼻梁宽窄、眼形、颧弓、下颌线、唇形和肤色；再写出哪些特征更突出、哪些保持柔和。不得仅凭标签推断肤色、发色、眼睛颜色、性格或身份，也不得将多个族群标签机械拼贴。用户提供照片或角色参考时以可见特征为准。

需要保留这类参照词时，可按以下方式转成角色专属描述，而不是直接把标签当完整提示词：

- **韩系妆造方向**：写明偏清透或柔焦的底妆、眉峰强弱、眼妆边界、卧蚕表现、腮红范围和唇妆质地；脸型和五官另行选择，不默认同一种韩式脸。
- **中德混合观感方向**：例如“以本角色设定的东亚脸型为基础，选用略清晰的眉弓与鼻根转折，眼窝保留中等深度，眼形和下颌维持柔和；具体肤色、发色由角色设定另定”。
- **中俄混合观感方向**：例如“以本角色设定的面部比例为基础，选用较立体的鼻背和清楚的颧部转面，眼睑与唇形保持指定形状，下颌线不过度锐化；具体瞳色、肤色和发色另行指定”。

这些是提供给设计者的组合句式，不是德国人、俄罗斯人、韩国人或任何群体的客观面部模板。每个角色按用户参考与故事设定重新选择参数。

### 1.6 降低模板脸的提示要点

- 给角色指定两至四个稳定的面部识别点，例如偏长的鹅蛋脸、较平的眉弓、外眼角轻微下垂、鼻尖略圆、上唇较薄；其余特征保持克制。
- 先写骨相和比例，再写美感评价。避免只写“绝美、精致、高级、混血感、明星脸”。
- 为不同角色分配不同的脸宽、面中长度、颧颌关系、眉眼间距和下巴轮廓；不要只靠发色、妆容或眼睛颜色区分。
- 保留与年龄相符的软组织、皮肤纹理和轻微左右差异；不把青春角色统一成幼态大眼尖下巴，也不把成熟角色统一成浓妆深沟。
- 四视图胸像与正面、45度全身视图中的脸部特征必须一致；角度变化只改变透视，不改变鼻型、脸宽、眼距或下巴形状。

### 1.7 四视图胸像面容提示词骨架

```text
生成一张16:9横屏人物四视图资产板。左侧约38%为同一角色的超大正面胸像，面部占足够面积以清楚呈现脸型、眉眼、鼻唇、肤质与妆容；右侧并排正面全身、人物自身左转45度全身、背面全身。角色为【年龄感/性别表达/身份】；【脸型长宽与额颧颌关系】；【眉骨/眉形/眼睑/眼形/眼距】；【鼻根/鼻梁/鼻尖/鼻翼】；【颧颊/下颌/下巴】；【唇宽/上下唇比例/嘴角】。肤色与底调为【】，皮肤保留【真实纹理程度】，稳定识别点为【两至四项】。胸像表情自然，发际线可辨，头发和头饰不得遮挡主要骨相。背景低干扰，柔和塑形光。保持同一身份、同一骨相和同一比例；全身视角只产生透视变化。不要文字、边框、额外头像、面部磨皮、模板化尖下巴、大眼网红脸或五官漂移。
```

不要将上述占位符原样交付；没有项目依据的参数由当前任务设定补全，不凭族裔标签自动推定。该骨架必须与服饰四视图合并成同一张资产板，不得拆成额外面部图。

### 1.8 女主脸型偏圆的排查与控制

若多名女主反复生成圆脸，通常不是脸型词汇不够，而是圆润信号比骨相约束更强。常见冲突包括：一边写“长椭圆/窄脸”，一边堆“可爱、幼态、娃娃脸、BJD、小脸、大眼、苹果肌饱满、婴儿肥、肉感脸”；或只写“鹅蛋脸”而未规定额头、颧部、下颌和下巴之间的宽度变化。BJD、幼态、可爱等词会强化圆润大眼观感，应只在确实需要时使用，并说明是渲染/妆造质感，不代表脸型。

**先定脸型轮廓，再写五官与气质。** 每个女主至少选择一条完整骨相路径，不能只用“鹅蛋脸/瓜子脸”单词：

| 目标轮廓 | 建议明确的几何关系 | 适合的角色效果 |
|---|---|---|
| 窄长椭圆/清冷鹅蛋 | 脸长明显大于颧宽；额部与颧部接近，下颌逐步收窄；面中略长，下巴窄圆或微尖但不锐 | 清冷、端庄、成熟的仙侠/宫廷女主 |
| 修长心形 | 上额略宽、颧部柔和、下颌明显向内收；下巴小而有长度，太阳穴不凹 | 明艳、灵动、贵气；不等于极尖V脸 |
| 菱形/骨相型 | 颧弓是最宽点，额角与下颌收窄；颧骨转折可见但脸颊不过瘦 | 有辨识度、凌厉、成熟女主 |
| 柔和方圆 | 额颧颌宽度接近，下颌角可见但由软组织平滑过渡；下巴偏平圆 | 英气、可靠、运动型；保留真实下颌结构 |
| 短椭圆/柔圆 | 脸宽与脸长差距较小，面中与颊部饱满、下颌转折弱 | 甜美、亲和、幼态角色；需主动选择，不能当作所有女主默认脸 |
| 窄下庭长脸 | 额部/面中长度偏长，颧宽适中，下颌纤细但不尖，下巴有自然长度 | 文静、疏离或脆弱感；避免额头和下巴同时拉长造成失衡 |

### 1.9 减少模型自动圆脸的提示词操作

当目标不是圆脸时，先在正向提示词前段给出明确轮廓和宽度关系，再描述五官。不要只依赖负向词。可将以下逻辑按目标改写进提示词：

```text
脸型为偏长的窄椭圆轮廓，脸长明显大于脸宽；额头宽度中等，颧弓不向两侧鼓出，面颊软组织克制，下颌线从耳下平顺收窄至有长度的圆尖下巴。保留自然骨相与轻微面部不对称。眼睛可大而明亮，但眼眶、眼距和面部宽度维持成年比例；脸颊不鼓、不做婴儿肥。
```

如果用户要可爱但不圆脸，把“可爱”落到表情、眼神、妆色、发型或穿搭，不靠缩短下庭和鼓起苹果肌实现。若目标为圆脸，就反向明确较短脸长、饱满颊部和弱下颌角，避免同时要求“窄长脸、尖下巴、幼态圆脸”。

排除词应与目标一致且只用于纠偏：目标为窄长/菱形/心形脸时，可加入“不要短圆脸、不要鼓胀苹果肌、不要婴儿肥、不要宽圆下颌、不要过短下庭、不要脸颊向外膨出”；目标本来是圆脸时不可添加这些排除词。泛写“不要大脸”容易触发过度缩脸或尖下巴，不建议单独使用。

脸宽控制须与发型配合。厚刘海、两侧蓬松卷发、外扩鬓发会让脸显短宽；若目标是窄长脸，发根保留纵向高度，两侧发束贴面或向下延伸，胸像至少露出颧部至下颌的一侧轮廓。不要一面用大量横向蓬松发量框脸，一面要求颧宽窄。

### 1.10 女主多样化的结构分配

同一作品的女主、女配和NPC不要都落在“鹅蛋小脸 + 大圆眼 + 尖下巴”。为核心女性角色建立脸型差异表，至少分配：纵横比例、最宽部位、下颌转折、下巴端型、面颊软组织、眼裂长度/眼尾角度、眉骨与眼距。面容差异应先在骨相上成立，再用妆面、年龄感和气质强化。

给女主出资产图前快速复核：

1. 正向提示里是否写了脸长/脸宽趋势、额/颧/颌宽度变化、下颌收束和下巴端型？
2. 是否同时出现圆脸与窄长脸、婴儿肥与清晰颧颌、幼态短下庭与成熟长脸等互相冲突词？
3. “可爱/甜美/娃娃感”是否误替代了脸型设计？
4. 刘海、脸框发束和脸颊阴影是否遮掉需要展示的轮廓？
5. 负向词是否只排除了不想要的圆润特征，没有误伤目标本身？

若成图仍圆，不要只重复“瓜子脸/精致小脸”。调整生成提示顺序：把脸型几何关系提到更前，删除导致短宽的冲突词，明确颊部软组织和下庭长度，再检查发型对脸宽的视觉影响。若参考资产本身已经是圆脸，文本无法可靠推翻图像身份约束，应先修订或重做人物资产，再用于后续绑定。

## 2. 华丽服饰的细节密度

### 2.1 华丽度按场合设定

用户明确要求“华丽、极尽繁复、盛装、典礼级”时，不能只增加“精美、华贵、重工、璀璨”等评价词。先声明服装规格，再把复杂度落实到剪影、层数、裁片、纹样、工艺、珠宝、发饰、垂坠物和材料反光。此外，玄幻修仙、仙侠、修真与古风宫廷的男主/女主，即使用户未特别声明“华丽”，也默认至少从“宫廷礼服”级起，不得退回“日常”级或单层素衣。华丽度可按剧情调节：

- 盛装：剪影明确，一至数层外搭，局部刺绣和一组主饰。
- 宫廷礼服：明确内中外层、拖尾/披帛、分区刺绣、成套头面与腰胸饰。
- 册封/大典礼服：扩大裙摆和肩袖轮廓，增加可读的冠饰结构、多部位连续纹样、成组珠宝与仪典性垂饰，规定不同区域的装饰密度。
- 神话/仙界仪典级：在大典规格上加入有来源的象征母题、层叠轻重材质、金属构件和少量剧情性异象；异象要说明来源与覆盖范围，不能把整套服装写成无结构光效。

架空宫廷的公主主角常态资产另有身份识别要求：即使人物穿日常造型，也不能直接套用普通贵女或侍女级的轻便底装。至少组合三类清楚可见的宗室主角信号，并落实到具体结构：有体量和承重逻辑的冠饰/成组头面、可辨的肩袖或外层廓形、分区重工的主衣纹样、宽幅多片裙摆、贵重面料与多材质对照、腰部主饰或成套玉石珠宝。避免只用高髻、淡色长裙和小花簪证明身份。年轻与傲娇通过面部年龄感、灵动束发、鲜明点色和表情仪态表达，不能因此把服装降成普通侍女常服；也不要求每次穿大典凤冠或成熟后妃礼服。

这些层级是可调的设计强度，不绑定性别或身份；日常人物也可因剧情穿着大典服。服装繁复不等于每个区域同样满、同样亮、同样重。

### 2.2 华丽设计展开清单

对用户要求的重点区域逐层写足；不相关类别可以删去，但不以一句“华丽礼服”代替结构。

1. **剪影与体积**：肩线、袖展宽度、腰线、裙身锥度/圆度、前后裙长差、拖尾长度、披帛走向、层叠外轮廓，以及人物站立时衣摆如何落地。
2. **衣层与裁片**：贴身内衣、衬裙/中衣、主礼服、罩纱/披帛、肩饰、腰封、裙片、后摆等；每层写领口、闭合方式、露出宽度、边缘和与下一层的连接。
3. **重点装饰分区**：冠心、肩部、胸襟、腰封、袖口、裙门、裙侧、裙摆、后背各自承担什么图案和工艺。可标高/中/低装饰密度，保留轮廓与材质间的视觉间隔。
4. **纹样体系**：指定主母题、辅助纹样、重复尺度、方向和疏密；大型主体纹样跨哪些裁片，边饰沿哪些接缝，暗纹在哪里退到背景。多个母题须有层级或叙事关系。
5. **刺绣与表面工艺**：盘金、平绣、珠绣、钉珠、羽片/鳞片贴饰、织金、缂丝感织纹、镂空、压褶、绳绣、金属包边等，分别落到具体衣片；写针脚/线材的粗细、凸起程度、疏密、颜色和高光。
6. **材质对照**：哑光底料、厚重锦缎、软缎、透明纱、珠母、皮革、金属与宝石形成可见对比；说明重量和垂坠关系，避免厚甲、重石与无支撑薄纱互相冲突。
7. **首饰套系**：冠体骨架、冠心主石、左右冠翼、簪脚、额链、耳坠、项链/璎珞、胸饰、腰佩、臂钏、戒指、鞋履装饰逐件说明。给出固定点、材料、尺度层级和落点；可繁复叠加，但不能无承托悬浮。
8. **动态与声音线索**：步摇、链坠、珠串、披帛、长带、裙片如何随步伐或转身摆动，哪些部件较重而动作迟缓，哪些轻纱响应风；只在镜头需要时加入声响。
9. **背面完整度**：冠饰后脑连接、发簪收束、衣背纹样、腰后系带、后裙接片和拖尾结构，不把背面当成纯色空白。

### 2.3 繁复度提示词组织模板

```text
【礼服规格与身份场合】……
【整体剪影】肩袖体积、腰线、裙摆/裤装轮廓、拖尾与披帛路径……
【内层到外层】逐层写领襟、衣长、裁片、固定方式、露出边界……
【配色与材质】每层色相/底调/明度/饱和度、面积、织物重量与受光……
【装饰密度地图】冠心/肩胸/腰/袖/裙门/裙摆/后背分别为高、中或低密度……
【纹样与工艺】母题层级、图案走向、覆盖裁片、刺绣/织造/镶嵌工艺……
【成套珠宝】冠、额饰、耳、颈胸、腰、臂腕、手部与足饰的固定点、材质、尺度、垂落终点……
【结构与动态】承重点、层间连接、重量差、行走和转身时的运动方式……
【跨视图锁定】正面、45度和背面为同一套礼服，装饰落位和结构连续……
```

成稿须把模板替换成具体设计；按用户给定身份与世界观选择元素，不自动套用凤冠、凤凰、红金或白金组合。高密度区域应具体到裁片和工艺，留白区域也应说明其材质或结构作用。

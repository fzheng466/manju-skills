# AI 漫剧仙侠服饰槽位组合库

本文件是玄幻修仙/仙侠/修真题材在 **AI 漫剧** 生产中的服饰设计库。它取代"固定三层式"的单一结构：角色造型由槽位组合生成，同一类型角色的差异必须发生在**结构层**（廓形、纱质处理、层搭方式、露肤处理、鞋履、腿足点缀），而不是只换配色和花纹。

## 0. 定位与硬规则

1. **本库服务 AI 漫剧，不做汉服考据。** 目标是夸张、高华丽、可非物理的造型语言；历史形制名称（齐胸襦裙、褙子、马面裙、历代鞋履复原等）不得作为默认设计依据，也不得用"合乎形制"约束造型。需要考据的属实拍/古装项目，另走 `palette-costume-jewelry.md`。
2. **允许的夸张范围**：超长曳地裙摆、非物理飘带与悬浮披纱、大面积半透纱、立体重工刺绣、夸张冠饰体量、任意高度开衩、腿环/足环/缠腿飘带、赤足与悬浮踏云表现、非对称剪裁、可发光的灵纹与材质。这些是 AI 漫剧的常态选项，不是越界。
3. **不放弃精度**：夸张不等于堆料。每套造型仍须写清层与层的露出关系、装饰密度分区、冠饰与腰佩的承重点、鞋履结构、饰品左右与固定方式，并按 `character-styling-review.md` 做冲突检查。
4. **不得靠风格形容词交货**：禁止只写"仙气飘飘""华丽""高级""绝美"。"仙气"必须转译为具体的纱质、飘带、开衩、悬垂、配色与材质结构。
5. **安全边界不放松**：露腿、腿环、足环、赤足等为**成年仙侠角色**的合法选项；未成年角色与非仙侠题材仍按既有合宜着装规则执行。
6. **取词纪律**：本库只给可组合的槽位选项与角色分支条件，不给固定成稿。每条提示词的选值应由角色身份、宗门、属性、气质与场景驱动，并逐项落位。
7. **本库不接管、也不锁定发型、发色、妆面、脸型骨相与配色色名**：这些仍由 `hair-style-library.md`、`hair-color-library.md`、`eye-makeup-library.md`、`face-archetype-library.md`、`palette-costume-jewelry.md` 与项目视觉圣经独立取词；§2.10 与 §3.1 中的示例发型、发色、色名只是实采样例，不是指定值。本库只决定"服装结构、鞋履、腿足点缀与承载"的方向与取值范围。
8. **本库给方向，不设格式锁**：§3.1 的三段式命名、分节骨架与服装节顺序是实采的**默认展开方向**；项目已有命名体系/提示词模板或用户另有要求时以其为准。**玄幻修仙的美装/华丽档下限是用户明确指定的题材规则，予以保留**（见 §5 与 `character-archetype-wardrobe-library.md` §1.0）；该下限约束的是结构、工艺与成套配饰的完成度，不锁定具体颜色、纹样或款式。

## 2. 槽位组合系统

九槽全部作答；不适用的槽写"无"并给一句原因。**不得为填槽强加实物**，也不得每个角色都落回同一组选值。

### 2.1 槽A 廓形与版型

写清是哪种结构、腰位、摆幅、开衩与剪裁的视觉重心；不要只写"长裙/袍子"。

| 方向 | 可选结构 |
|---|---|
| 女性·整体式 | 抹胸高腰曳地长裙、单肩斜披长裙、露肩广袖纱衫叠穿、束腰外袍+分片长裙、宽摆伞型重工裙、不对称单肩长裙、前短后长流动裙 |
| 女性·分离式 | 短上襦/云肩式上衣+长摆裙、束胸内层+外罩薄纱长衫、短衣+高腰直筒长裙、上衣+外袍开衩叠穿 |
| 女性·附披覆 | 披风式大氅+内层长裙、长飘带曳地裙、外褂敞开+内长裙 |
| 男性 | 交领广袖长袍、直身束腰仙袍、对襟开襟外氅+内袍、层叠广袖道袍、敞怀宽袖外袍+内束身、束腰战袍式长袍、肩甲式外披+长袍 |
| 剪裁变量 | 束腰/自然腰/低腰；收摆/宽摆/鱼尾收摆；单开衩/双侧开衩/前开衩/多片开衩；对称或刻意不对称 |

### 2.2 槽B 纱质与面料处理

面料从"透光性 × 光泽 × 重量 × 纹理"四个维度选，不选历史名物。每种面料须落到具体衣层。

| 维度 | 可选 |
|---|---|
| 透光 | 全透烟纱、半透轻绡、微透纱、不透缎/绸 |
| 光泽 | 缎面高光、珠光纱、哑光绸、丝绒哑光、金属丝织物、鳞光材质 |
| 重量与垂坠 | 轻飘无重力感、中等垂坠、厚重有量感、挺括造形 |
| 纹理 | 重工刺绣绢纱、暗纹提花、织金锦、激光镂空纱、拼色纱、冰裂纹纱 |
| 处理方式 | 单层悬垂、层叠透出、纱幔式叠盖、飘带拖尾、前后异材质拼接、渐变透纱、边缘雾化 |

### 2.3 槽C 层搭方案

层数由设计决定，**不设固定下限**。每套至少给出一个可读的结构关系（层叠露出、纱罩覆盖、披帛绕搭、开襟叠穿等）。

- 单层飘逸（靠剪裁、纱质与飘带承担层次，不靠加层）
- 错落双层（内外明度或透度对比）
- 三层叠穿（内紧+中间主层+外罩纱，写清每层露出区域）
- 抹胸+高腰长裙+半透外套
- 内束身+主袍+外大氅/披风
- 披帛/飘带缠绕式（绕臂、绕腰、垂坠终点）
- 单肩披纱叠穿、外袍敞开不闭合叠穿
- 前后异长叠穿（前短后长、后拖尾）

### 2.4 槽D 露肤度与开衩

逐点写清位置与程度，不要用"性感/端庄"替代。

| 露肤点位 | 可选处理 |
|---|---|
| 颈/锁骨 | 平口抹胸、交领微敞、立领全封 |
| 肩 | 露双肩、单肩斜搭、露肩+罩纱覆盖、肩部挖空 |
| 背 | 全露背、挖空式露背、透纱覆背 |
| 腰 | 侧腰挖空、腰带束腰、全包 |
| 腿 | 无开衩全遮、中等开衩（膝上）、侧高开衩（大腿中）、前开衩、双侧开衩、裙摆飞扬露腿、不对称单腿露 |
| 表现强度 | 端庄全覆盖 / 局部留白 / 若隐若现（透纱） / 明确露腿 |

露肤是设计选项，不与"性别=必露"或"清冷=必遮"绑定；同一角色不同场景版本可变。

### 2.5 槽E 外披与肩部

披帛缠绕、单侧长飘带、云肩式覆盖、肩纱半垂、短披风、长斗篷大氅、无肩结构（抹胸）、单肩斜搭、双垂飘带、悬浮式披纱。写明承重点与固定方式（肩扣、臂环、束带、灵力凝形），禁止无固定点的悬浮布片。

### 2.6 槽F 鞋履

鞋型、鞋头、鞋底/跟高、闭合结构、材质、与裙摆/裤脚关系逐项写清。AI 漫剧允许的额外表现：

绣履、软底纱履、绑带凉履、及踝软靴、长筒战靴、翘头软履、云纹长靴、缠足金缕履、木屐感结构、**赤足+足环/足链**、**悬浮踏云（足不落地，需写明是否为实体鞋）**。

赤足与悬浮必须与角色身份或功法绑定并写清理由，不作为默认；四视图保证鞋/足结构完整可见。

### 2.7 槽G 腿部与足部点缀

腿环（金属/皮革/织物/绳编）、大腿交叉绑带、缠腿飘带、绑腿绫带、踝链、足环、足链铃铛、脚背珠链、轻护胫、膝盖饰、异色腿纹或灵纹。写明左右（可刻意不对称）、固定方式与是否随动作摆动。允许"无腿饰"并明确写出。

### 2.8 槽H 头面、腰佩与腕饰

- 头面：本槽按**载体系族**取词，**不默认"冠＋簪＋步摇"三件套**，件数自由（可只一件主饰，也可成套叠戴）。可选族：①冠族（冠座/冠梁/冠翅/花冠/骨冠/羽冠/角冠）②钗簪族（长钗/发簪/梳背/金步摇/珠花钗）③额面族（额链/流苏额饰/花钿/眉心坠/珍珠面帘）④束发族（发带/束缨/发绳/发网/金属发牌/编发嵌珠与嵌银）⑤垂饰族（后垂珠链/璎珞/后披飘带/纱罩头纱）⑥自然族（绢花/绒羽/象牙骨饰/灵植须蔓）。**载体须与发型联动**：束发、盘发、高髻才适用钗簪冠与发网；披发、半披发、散发则用额链、发带、发绳、面帘、羽毛、编发嵌珠、发牌或头纱，不得给披发角色硬插发簪。发光灵纹头饰按项目允许时使用。
- 腰部承载：腰封/腰带、腰链、腰佩玉、禁步、命器挂点、披帛扣。
- 腕臂：臂钏、腕镯、护腕、戒指、璎珞/胸饰。
- 非人元素（**仅限妖、魔、妖修或剧情明确异化者**）：兽纹、鳞羽、毛领/肩毛、角/异化耳、爪、尾饰、羽饰、骨饰、异色瞳/竖瞳、妖纹魔纹。
- 每件写清佩戴位置、连接点、垂坠终点、材质、人物自身左右。

### 2.9 槽I 驱动来源（先答这槽，再填前面八槽）

身份与角色分支（§3）、宗门/势力、修行阶段、功法属性、气质、当前场景与状态、角色层级。**同一角色在不同场景可有不同版本，但廓形方向、主色逻辑与非人元素不得随机漂移。**

### 2.10 实采措辞样例（小红书 AI 漫剧）

下列措辞采集自小红书 AI 漫剧角色卡，用来校准各槽位的颗粒度与语感；**不得整段照搬**，须按本项目角色的槽位选值重新落位。

- 命名惯例：`【角色定位】·【配色】·【气质】` 三段式。实例："雪夜剑修 · 冷月孤锋 · 清冽禁欲"、"江湖医女 · 青绿素白 · 清雅质朴"、"异域灵裔 · 神秘绮丽 · 月影天狐"、"快意江湖 · 恣意少年 · 锋芒潇洒"。
- 男装措辞：月白与霜青广袖长袍、丝缕与轻纱交织、鹤羽与云纹暗纹、白玉流云发冠、高束半披长发、玉环腰坠与串链流苏、护腕束袖护肩与腰封、暗绣流云与风纹、墨蓝烟灰玄青侠客长衣、布料通透而有层次 / 衣料挺括又有层次、银线流转、叠穿轻纱与刺绣外袍、月相与灵狐纹刺绣、银白渐变长发半束配月牙星芒发饰、瞳色清冽 / 眼尾微挑。
- 女装措辞：雪白月白极浅冰蓝配银色、领口较高、纵向冰晶纹样与银色神圣图腾、肩臂白色羽毛片状装饰由肩向袖口逐渐变细并与透明轻纱融合、细长银白腰封镶嵌冰蓝水晶且不强调过度曲线、长裙自腰部垂直展开且裙型修长庄重、外层覆盖细密羽毛状刺绣与透明冰雪纱、长款披风与半透明头纱自头冠肩部延伸至地面形成纵向构图、交领窄袖短衫外搭无袖围裙、两侧开衩自然露出长裤、布质腰带系束并腰悬药囊与木质葫芦。
- 颗粒度参照：先给主配色，再写领口高度、胸前纹样、装饰走向、腰封宽窄与镶嵌、裙型与开衩决策、外层纱/披风/头纱的纵向构图、与头发的交叠关系；每项都要能对应到槽位，形容词单独出现视为未完成。
- **实采中的"BJD 人偶质感""高级CG""8K 高细节"是质感与渲染关键词，不是类型声明。** 本项目类型行以项目视觉圣经为准（玄幻/古风题材默认 3D半写实国漫CG），这些词只能作为质感修饰，不得替代或覆盖类型行。**此限定只适用于玄幻/古风语境**；都市/现代题材按用户 2026-10 拍板默认 `高精度3D半写实BJD人偶`，其类型行写法见 `modern-manju-costume-library.md` §6。

## 3. 角色分支条件

同一分支内仍必须按 §4 拉开结构差异；下表给"默认倾向"，不是封闭清单。

以下"头面与腰佩"列写的是该分支可用的**载体方向**，不是固定组合；只要符合载体×发型联动，同槽可换用 §2.8 任一载体系族（例如只用额链＋发带，或面帘＋绢花，完全不出现簪钗），同作同类角色之间必须换族，不得照抄同一套头面。

| 分支 | 廓形倾向 | 纱质与层搭 | 露肤度区间 | 鞋履池 | 腿足点缀 | 头面与腰佩 | 非人元素 |
|---|---|---|---|---|---|---|---|
| 清冷仙子 | 交领广袖仙袍 / 抹胸高腰曳地长裙+广袖纱衫 | 单层悬垂或错落双层；半透烟纱、哑光绸、渐层透纱 | 锁骨/肩局部留白；开衩至膝上，以"若隐若现"为主 | 软底纱履 / 翘头软履 / 赤足+细足环 / 踩云 | 细踝链或足环，可无 | 玉质冠饰或额链（按发型选载体，可仅此一件主饰，或叠束发族＋垂饰族）；细腰封+腰玉佩 | 无（可有极淡灵纹） |
| 明艳/妩媚仙子 | 抹胸高腰长裙+重工刺绣外罩纱 / 单肩斜披长裙 | 三层叠穿或纱幔式叠盖；重工刺绣绢纱、珠光纱 | 露肩露背、侧高开衩露腿 | 绑带凉履 / 翘头绣履 / 赤足+足环 | 大腿缠绕飘带、足环铃铛、腿环 | 金枝花冠或珠花＋璎珞＋流苏额饰（择二至三件，载体按发型）；重工腰封 | 无 |
| 圣女 / 神女 | 单肩斜披曳地长裙、宽摆伞型大摆 | 单层极长悬垂+纱幔叠盖；全透烟纱外罩 | 端庄全覆盖或露单肩，不开高衩 | 赤足+足环 / 软底纱履 / 踩云 | 细足环、脚背珠链 | 额饰中心宝石、圣光环饰、长后垂链 | 无（可有神圣光环） |

### 3.1 命名与提示词骨架（AI 漫剧惯例，默认方向）

以下为小红书 AI 漫剧实采的**默认展开方向**，用于校准颗粒度与语感；项目已有命名体系/提示词模板或用户另有要求时以其为准，不计入未完成判定。本库不接管发型、发色、妆面与配色色名——这些仍由 `hair-style-library.md`、`hair-color-library.md`、`eye-makeup-library.md`、`palette-costume-jewelry.md` 与项目视觉圣经独立取词。

- **三段式命名**：`【角色定位】·【配色】·【气质】`。可作为起手顺序，先定这三个词再展开槽位，使命名与槽A 到槽H 的取值倾向自洽。
- **分节骨架**：人物设定（年龄 / 头身比 / 身形 / 站姿）→ 外貌特征 → 发型与冠饰 → **服装** → 配饰 → 画面风格 → 核心关键词 → **避免**。
- **服装节内部顺序**：主配色 → 领口高度 → 胸前纹样 → 装饰走向 → 腰封（宽窄 / 镶嵌 / 是否强调曲线）→ 裙型与开衩决策（明确写出"不使用大面积高开衩"或给出开衩高度）→ 外层纱 / 披风 / 头纱的纵向构图 → 与头发的交叠关系。
- **每条造型必须带【避免】负向清单**（见 §3.2），与正向描述同等必填——此项为质量门，不属于可覆盖的格式方向。

## 4. 同类型角色差异化硬约束

1. 同一作品中，两名同类角色（如两名仙子、两名剑修）必须在**至少四个槽位**落在不同选值，且差异必须包含【槽A 廓形】【槽C 层搭】/【槽B 纱质处理】【槽D 露肤处理】【槽F 鞋履】这五项中的**至少两项**。
2. 差异只发生在配色、花纹或饰品颜色，判定为不合格，退回重选槽位。
3. 禁止组合复制：同作内不得出现两名角色共用同一"廓形+层搭+鞋履+腿饰"四元组。
4. 主角与配角同场时，配角按 `character-archetype-wardrobe-library.md` §2.4 降低竞争变量，但其槽位组合仍须是**另一套**，不是主角方案的减配版。
5. 跨集复用同一角色时，锁定槽A/槽C/槽D 的选值；仅允许饰品、外披、状态（洁净/战损/仪式完整）变化。

## 5. 达标判定（结构丰富度多路径）

一套造型达到"结构丰富度"要求，当且仅当满足**下列任一路径**，并同时具备定点重工工艺 + 成套头面与成套腰部承载（此处"成套头面"指**有主件＋明确固定结构**，不指必须出现簪/钗/步摇：可用 §2.8 任一头面载体系族组套，件数自由，具体载体按发型联动）：

| 路径 | 说明 |
|---|---|
| ① 重工多层叠 | 2–4 层且有清晰露出关系，每层材质不同 |
| ② 半透纱罩/揭纱层次 | 透纱外罩覆盖实层，形成若隐若现的露肤与材质对读 |
| ③ 高开衩 + 披帛/飘带 | 下装开衩与飘带共同构成运动轮廓 |
| ④ 抹胸 + 外纱外套 | 上身内层为抹胸/束胸，外层为独立薄纱 |
| ⑤ 腰封 + 腿饰/绑腿结构 | 腰部有明确承载结构，腿部有独立点缀或绑缚层级 |
| ⑥ 大氅/披风 + 内层结构 | 外披与内层形成内收外扩的轮廓对比 |

- 不满足任一路径且仅"一件套头长袍+一条腰带"，判定未达标，退回补足。
- "克制、素雅、清冷"只降装饰密度与色彩对比，不降面料等级、定点工艺与成套配饰，也不作为取消层搭路径的豁免。
- 不得为凑层数强加第三件无露出关系的衣服；层数服务于轮廓与材质对读。

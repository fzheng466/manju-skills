# 逐张生图、参考绑定与费用门

## 测试产物路径

只要本次是资产图提示词测试、资产图生成测试、参考绑定试验或失败复现，目标路径必须位于 `E:\Test-data-Skill\<project_id>\<batch_id>\02_asset-tests\` 下；提示词放 `prompts`，输入副本放 `inputs`，生成图放 `generated`，逐张结果放 `reviews`。不得把测试图、测试提示词或测试日志写入项目的 `02_assets`、`04_h3_prompts`、`05_media` 或仓库目录。正式生产资产仍按项目合同登记。

## 触发与清单

当用户已完成一组资产提示词，并说“开始生图”“按清单生成”等明确触发语时，从本轮已定稿的项目/对话清单读取资产名称、完整提示词、正负向提示词（若目标通道支持）、画幅/尺寸、输出路径和参考关系。用户不必再次粘贴。尚未定稿、资产数量不清或缺少会改变图像内容的关键事实时，先整理可用项，只对关键缺口提问。

正式调用前生成一份待处理队列，每项带稳定 `asset_id`、顺序、提示词版本、目标路径、画幅/尺寸、通道/模型、参考输入及用途。明确本轮只处理队首一项。每次至多生成一张，调用参数必须为 `n=1`；不得并行、预生成后续资产或调用批量数量。

## 逐张确认

1. 调用前向用户简要说明当前资产、将提交的提示词版本、画幅/尺寸、通道/模型、参考绑定关系、单张费用估算、已用费用与本批上限。
2. 实际提交一张并等待该次同步工具调用自行返回。返回后检查生成文件是否落地，展示图像/可打开路径，记录资产 ID、提示词版本、参考图、尺寸、状态和本次费用。
3. 停止后续生成，等待用户确认当前图。确认接受后将其登记为已确认锚点/可复用资产，再处理队列下一项；若用户要求修改、拒绝或换提示词，仅对当前项采取相应动作，说明再次生成会新增一次调用/费用并逐张继续。
4. 不因用户确认一张图而把剩余队列改成批量任务。每张资产完成后都要再等一次确认。

用户要求的“一句话调用”是对启动逐张工作流的授权，不代表同意批量生成、超出本轮已显示的费用上限、切换模型/通道、扩大尺寸、额外变体或自动重试。

## 参考图绑定决策

- 同一角色的换装、表情、姿势或需要延续面貌的三视图：优先绑定该角色唯一已确认锚点图；把完整角色卡锚点字段和本张的变化项写入提示词。若尚无锚点，第一张生成角色基准图，用户确认后才将它作为锚点供后续资产使用。
- 同一场景的天气、时间、损毁或机位变体：只有项目要求保持固定建筑、地标和陈设时，绑定同场景已确认基准图，并说明只控制空间结构/美术外观，不取代本镜机位与剧情状态。
- 同系列道具、服装套件或宣传视觉：仅当确需保持共同造型时绑定已确认系列基准，并标明参考控制范围。
- 无需延续身份/结构/设计的独立场景或道具，不为“有参考”而绑定图片。参考图只承担其声明的控制目的；不假设它自动控制构图、动作、文字或模型未支持的属性。
- 每张参考编辑开始前，向用户报清“本张绑定参考：资产名/ID/路径；用途；本次改变项”。如果锚点不可用、用户未确认或关系不清，暂停该张并说明原因。

## 通道与费用约束

图片生成与编辑唯一使用已配置的外部 API；不得切换或回退到其他本地/内置生图通道。不展示、不复制、不回显凭证。API prompt 按该通道规则原样传递；不得在提交时临时补写或扩展已定稿提示词。

提交前确认当前实际价格/额度计费方式、模型、图像尺寸、调用次数和本批预算上限。展示单张估算、已发生累计、本批剩余额度与失败后可能产生的费用。只在本批费用能被可靠估算且预计总额不超过用户明确的上限时提交。若费用未知、只有未经核验的旧价格、或无法保证单图/额度约束，停止在预览/待提交状态，先向用户说明缺少的计价信息；不把“单张”假装成金额上限。

任何一次请求开始后均不得轮询状态接口、重复查询、重复点击、换通道重试或并发补发。只允许等待该次同步工具调用自然返回一次。如果工具返回处理中/超时/结果不明，记录现有任务 ID/状态并停止；不得将状态不明解释为失败后重提。只有用户明确批准再次请求且费用仍在本批上限内时才重试。每次可能计费的重试作为新的单张调用计入费用。

本批硬上限到达即停止并报告队列剩余项。除非用户另行确认新额度，本批不扩大费用上限、图像数量、尺寸、模型或通道。

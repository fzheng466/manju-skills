# 人物发色与发丝材质库

用于人物资产、造型变体和视频连续性。发色必须区分固有色、挑染/渐变、灯光染色与功法变色；发型结构从 `hair-style-library.md` 选择。色名只是起点，最终描述到发根、主体、发梢、冷暖、明度、饱和度和发丝反光。

## 1. 基础色域

| 色域 | 可用色名与底调 | 提示词注意 |
|---|---|---|
| 黑色系 | 乌黑、墨黑、蓝黑、棕黑、软黑、灰黑 | 写受光处是冷蓝、暖棕还是中性窄高光；不把蓝色边光误认成蓝发 |
| 棕色系 | 黑茶、深栗、巧克力、冷亚麻棕、暖榛棕、焦糖棕、红棕 | 现代染发可写发根新生色；古风自然发色需符合世界设定 |
| 金/米色系 | 蜜金、麦金、香槟金、浅亚麻、米金、灰金 | 保留暗部发束结构，避免金属金箔头发 |
| 红/橙系 | 赤棕、铜红、酒红、绯红、朱红、暖橘 | 明确是染发、血脉特征还是激活色；和肤色、服装红区分 |
| 冷色系 | 深靛蓝、青蓝、青绿、孔雀绿、灰紫、烟紫 | 以低饱和主体配少量高纯度节点，避免全头荧光 |
| 无彩/浅色系 | 银灰、霜白、雪白、月白、珍珠灰、烟灰 | 写暖/冷阴影、发根与发尾层次；白发不等于老年外貌 |
| 深暗幻想系 | 紫黑、墨绿黑、暗赤黑、乌蓝、灰酒红 | 适合非人/魔修身份，暗部仍能分辨发束与背景 |

## 2. 分布方式与状态

| 方式 | 必须写清 |
|---|---|
| 单色 | 主体色、发根与发梢轻微色差、亮部反光色；不要“纯黑一片” |
| 根深梢浅 | 渐变从耳下/肩下/某段发长开始，过渡宽度与终点；背视同位置 |
| 发尾染 | 只占末端一段，明确颜色与边界柔硬，不能延伸到刘海 |
| 内层染/耳圈染 | 人物自身左/右、内层位置、披发或束发时露出范围 |
| 挑染/线染 | 条束数量级、宽度、起点和方向，避免每视图换条纹 |
| 分区双色 | 中分左右、顶层/底层或前后区的明确边界；背视照同一地图 |
| 局部霜化/白化 | 剧情触发位置、蔓延顺序、是否可逆；不直接替换整头造型 |
| 灵力发光 | 发色固有层不变；仅指定发丝边缘、发梢或符纹短时发光，并写照亮对象 |

发色可作为身份线索，但不要把“反派=白发、仙子=银发、女主=棕发”写成默认映射。若用户提供角色参考图，以图中可见的发根和阴影色为准；光源偏色与染色无法区分时记录为待核，不凭单张受光图定稿。

## 3. 3D半写实发丝表现

写发束的粗细层级、发丝顺直/毛躁程度、密度、发面高光宽度和透光边缘。深发色用中间亮度的束状层次把轮廓从暗服与暗背景中分出；浅发色保留灰/米/蓝调阴影，不漂成纯白。头顶、鬓侧、马尾和发尾可有不同受光，但固有色与挑染地图不随镜头翻转。染发不自动意味着化学损伤；干枯、分叉、湿润或金属般冷光都须有角色/剧情依据。

## 4. 配色与连续性登记

角色卡记录 `hair_base / root / mid / tip / accent_placement / color_cause / normal_state / activated_state / lighting_exclusions`。中文提示词写“主体【色】、发根【色】、从【位置】开始过渡到发尾【色】，人物自身【侧】的【几束】为【色】；在【光源】下只有高光偏【色】，固有色不变”。脸、服装和背景至少有一处明度或冷暖分离。四视图与后续视频保持同一分布；换发色必须建立明确版本与叙事触发。

## 5. 渐变与复合发色方向

渐变不是简单写两个颜色。先选分布拓扑，再定义颜色站点：根部色 → 主体色 → 过渡色/带 → 末端色。至少说明渐变从哪里开始、沿哪些发束延伸、过渡是柔雾融合还是清晰染段、最终停在什么长度；若只染发尾、内层或局部挑染，明确未染区。发束受光的高光颜色另写，不能和固有渐变混为一谈。

| 方向 | 根部 → 主体 → 发尾/强调区 | 适用观感与控制点 |
|---|---|---|
| 月光白金渐层 | 冷灰棕发根 → 珍珠白/铂金主体 → 柔金 → 浅樱粉末端 | 适合仙灵、火灵或高阶女性角色；金粉只占末端与少量外层发束，避免整头变成黄粉双色块 |
| 雾银玫瑰 | 烟黑/灰棕根 → 银灰中段 → 灰玫瑰/雾粉发梢 | 清冷中带柔美；低饱和粉集中末端，脸侧保留银灰明暗 |
| 乌木莓果 | 自然黑根 → 黑樱桃/莓红中段 → 暗玫瑰红末梢 | 都市甜酷、魔修或血系人物；红色沿发束内侧与末端分布，不把黑发整体染成平涂红 |
| 焦糖蜜桃 | 深栗根 → 榛棕/焦糖中段 → 蜜桃铜金末端 | 暖调现代人物；发根保留自然深度，皮肤与服装红橙区要错开明度 |
| 香槟奶金 | 深亚麻根 → 米金/香槟主体 → 珍珠浅金末端 | 轻盈、精致或贵气人物；控制金属感，暗部用米灰而非纯黑 |
| 靛青海潮 | 蓝黑根 → 深靛/孔雀蓝中段 → 青碧 → 雾白蓝末端 | 水、海、冰系人物；渐变沿外层长发形成流向，内层保持较深色以稳住体积 |
| 夜空星紫 | 墨黑根 → 蓝紫/茄紫中段 → 灰紫或冷银末端 | 幻术、夜行或神秘角色；紫色避开荧光饱和，亮色只放发尾/几束外层 |
| 青竹玉色 | 深茶/墨绿根 → 松石青或孔雀绿中段 → 玉白/灰青末端 | 木灵、东方幻想角色；玉白只占小面积发梢或内层，避免塑料薄荷绿 |
| 赤焰鎏金 | 乌棕根 → 深绯/朱红中段 → 熔金/琥珀末端 | 火系、战斗/神性角色；金色从红色发束末端分叉延展，不能像黄色挑染条纹 |
| 冰焰对色 | 蓝黑根 → 冰青主体 → 银白末端，少量暗紫过渡 | 冰/雷复合能力；限定冷色关系，暗紫作为窄过渡带，不铺成彩虹 |
| 黑白对分 | 人物自身左侧墨黑、右侧银白，或上层黑/底层白 | 身份双面、镜像/双生主题；分区边界从发缝或后脑中线连续延伸，所有视图不换边 |
| 藏色内层 | 外层乌黑/栗棕，内层耳后或后脑下层为青蓝、酒红、银紫 | 日常可隐藏、转头或动作时显露；定位写清左右、起点、面积和哪束头发会遮盖 |
| 面周色带 | 主体深色，仅两侧脸框束或刘海末端为浅金/粉/青 | 让色彩服务面部框线；两侧是否对称、色带粗细、从发根还是耳下起染需锁定 |
| 多段块染 | 深根 → 中段深色 → 一条明确的浅色环带 → 深/浅发尾 | 强风格漫画角色、偶像/舞台人物；控制为少量清楚色段，不做随机斑驳 |
| 日晒/自然高低光 | 深棕根与内层 → 中棕主体 → 暖浅棕外层末梢 | 现实都市角色；表现自然染发或日晒层次，不能误画成高饱和奇幻渐变 |

以上是可组合的色彩方向，不是角色清单。一次设计通常只选一种主渐变拓扑，再加一种小面积强调区；多种渐变并用时，必须说明它们在不同发区，避免全头多色混杂。具有作品版权的角色或官方造型只能用于观察渐变位置、层级与色彩关系，不直接复用角色专属完整造型、配饰或图案。

## 6. 渐变空间分布与色彩边界

- **纵向渐变**：沿头顶至发尾变化。写清过渡起始高度、过渡带长度、发尾终止颜色；刘海和鬓发是否跟随也要写明。
- **发束渐变**：只作用于几组独立发束。注明人物自身左右、前层/后层、外层/内层、束数级别与宽窄；每视图依同一发束地图延续。
- **内外层异色**：外层承担主色，底层或耳后束承担副色。正面写露出条件，背面显示色块从耳后至后脑的连接范围。
- **分区双色**：从发缝、头顶分区或后脑中线分开。明确角色自身左右，不以画面左右代替；后视左右不得镜像交换。
- **光照与能力变色**：常态固有色不动，只有特定光源产生窄高光，或能力启动后指定区域出现短时发光/褪色；注明触发、持续、恢复和对周围物体的照明影响。

写每个颜色区的面积关系时优先用“主色覆盖大部分发束、过渡色集中下段、末端强调色占发梢小段”等视觉比例词。除非设计需要，不强求精确百分比，以免四视图被模型画成硬切色块。白金/浅色渐变要保留根部阴影、发束交叠和灰度层次；深色渐变要让末端颜色与背景保持明度分离。

## 7. 渐变发色提示词检查

直接成稿前核对：

1. 发根、主体、过渡色、发尾色均有定义，或明确某站点不存在。
2. 染色原因明确：染发、血脉/种族固有、灵力状态、天生渐变或仅灯光反射。
3. 染色拓扑与实际发型相容；短发无需长发尾渐变描述，束发时需说明被遮挡的内层色。
4. 刘海、脸侧发束、马尾/辫子、披发和背面发束的颜色分布可推演且一致。
5. 渐变颜色不会被同色衣领、披风或场景吞没；特效状态不会永久改写固有发色。
6. 多色方案仍有一个主色，色彩节点可在普通漫剧画面尺寸下读出，不依赖极近景。

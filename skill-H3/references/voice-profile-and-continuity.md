# 角色音色档案与跨段一致性

本规范为角色建立可复用的声音身份，并约束剧本、导演谱、H3 提示词和后期配音的连续性。音色档案描述期望的听感，不等于声纹克隆、音高锁定或模型能力承诺。是否能由 H3 输入音频并稳定沿用音色，须按当前 provider/schema 实际核验。

## 1. 角色音色档案

每个有台词、OS 或 VO 的固定角色建立一个稳定 `voice_profile_id`，与项目 `speaker_id/actor_id` 一对一映射。档案至少写明：

| 字段 | 记录内容 |
|---|---|
| 年龄感与性别听感 | 听起来的年龄层、性别呈现；不由角色外貌机械推断 |
| 基础音高 | 低/中/高、重心偏低/居中/偏高；有实录时可补基频区间与样本条件 |
| 音域与动态 | 常用音区、自然上下限、情绪时允许变化的幅度；没有样本时用相对描述，不编造Hz数据 |
| 音色质地 | 明亮/暗哑、清透/浑厚、柔软/锐利、颗粒/气声/鼻音等，只选互相兼容的少量特征 |
| 共鸣与发声 | 口腔/胸腔/鼻腔的主次与听感、气息支撑、收尾方式；避免把解剖术语当成可验证事实 |
| 咬字与口音 | 普通话或明确方言、字头清晰度、卷舌/儿化等稳定习惯、吐字松紧 |
| 基础节奏 | 常态语速档、句间停顿、句尾走势、常见重音位置；有试读时记录实测语速及停顿 |
| 稳定识别点 | 2–4个可听见的声线锚点，加一段简洁、可跨镜头原样复用的标准描述 |
| 参考与版本 | 参考音频路径/来源/时长/状态，试音版本和确认状态；没有参考录音时标为文字设计档案 |

角色外貌图或性格标签不能证明真实音高、音域、共鸣位置或声纹。图片样例中诸如“基频220–260Hz”“F3–C6”等数值只适用于有测量条件的个体档案，不作为任何角色、性别或年龄的默认范围；不得仅凭声线文案声称模型会精确维持这些参数。

建议档案至少保留一条中性基准句的试读/成片，使用相同文本、语言、录音条件和近似响度，便于跨版本比较。克隆或使用真人参考音频前，确认素材来源和使用授权；没有授权或来源不明的录音不作为角色参考资产。

## 2. 常态与情绪变化边界

把声线拆为不变的身份层和可变的表演层：

- **身份层**：年龄听感、基础音区、主要音色、共鸣倾向、口音、咬字习惯和基础语速。跨场次与跨 job 保持稳定。
- **表演层**：音量、气息、音高短时偏移、语速、停顿、重音、句尾和情绪力度。按剧情变化，但只能在档案允许范围内变化。

为常用情绪建立小型变化表，例如温柔、平静、欢快、克制、强硬、悲伤：每种情绪只写相对基线的变化，如“音量略升、音高短暂上扬、尾音仍保持清晰轻柔”；不得为同一情绪同时要求互斥的低沉/尖亮、急促/缓慢。悲伤或愤怒可改变气息、音高和节奏，不自动改变角色年龄、口音或主音色。特殊状态如伪装、附身、变声、重伤失声须记录触发、起止和恢复条件，不能静默地变成永久新声线。

## 3. 剧本与项目台账

冻结对白时为每条语言单元登记稳定 `utterance_id`、`actor_id`、`voice_profile_id`、完整原句、语言、画内/OS/VO类别及当前情绪状态。H3 每个 job 的 `(S1)/(S2)` 是本段局部格式标签，可重新编号；项目稳定 ID 与局部标签的映射必须保存在台账，不能因为局部编号变化而换角色音色。

项目表可使用以下结构；将示例值替换为实际设计，不留空占位：

```yaml
voice_profiles:
  - voice_profile_id: heroine_voice_v1
    actor_id: heroine
    status: approved_text_profile
    identity_anchor: "中音区偏上，清透柔润，口腔共鸣明亮，普通话咬字清晰，句尾轻收；说快时仍保留温柔的弹性。"
    measured_pitch_hz: null
    measured_range: null
    baseline_rate: "中速，按试读校准"
    accent_and_diction: "普通话，轻声字自然，不刻意儿化"
    emotional_variation:
      assertive: "音高重心略降、句子更短、辅音清楚；保留清透主音色"
    reference_audio_asset_id: null
```

没有录音测量时，数值字段保留 `null`；没有审核音频时不得把文字档案标作已确认实际声纹。修改身份层建立新档案版本，并标出受影响的对白、job 和已生成音轨；单句情绪变化只更新对应语言单元。

## 4. 导演谱与 H3 编译

每条对白的导演字段除音量、音色、语速、情绪力度、表达策略、停顿、重音和句尾外，还需引用稳定 `voice_profile_id`。编译 H3 提示词时：

1. 在该角色本 job 第一次发声处写入完整基础声线锚点。
2. 同一角色后续台词复用相同锚点描述；需要控制长度时可在同一 job 内引用“沿用该角色已定义的基础声线”，但跨 job 不依赖模型记忆，须重新写出精简锚点。
3. 先写身份层，再写本句表演层；表演层只描述相对基线的变化，不能覆盖或重设身份层。
4. `<d>`内只放格式要求的语言标记和冻结原句。音色、情绪、停顿及声线锚点都放在标签外，不改写台词。
5. 说话人本段编号 `(Sx)` 仍按 H3 格式局部编排；编号和声线档案 ID 的映射在编译记录中可追溯。

音频参考只有在当前 H3 模式、provider 和接口明确接受该素材时才可绑定。项目记录文件、时长、来源、授权、用途和状态；素材需符合当前格式及数量/时长限制。即使音频被接受，也只能按已核实能力描述其用途，不宣称它必然锁定声音克隆。模式不支持时，使用一致的文字声线锚点或后期配音，不伪造音频输入能力。

## 5. 跨段声音 QA

审听时按角色收集各 job 的干声片段，优先比较相同或相近的中性句，再检查强情绪台词。逐项核对：年龄听感、基础音区、主音色、共鸣/气声、口音、咬字、常态语速与句尾；分别标注身份漂移和剧情允许的表演变化。不能仅凭音量或混响差异判定换声线。

发现漂移时先定位 job、语言单元和具体差异，核对是否重复写入或冲突描述、参考音频是否一致、provider是否支持相应模式。返修只覆盖受影响台词或音轨；不得靠每镜追加更多形容词掩盖锚点不稳定。没有可听媒体时只可报告“声线设计已锁定”，不能报告“音色一致性已验证”。

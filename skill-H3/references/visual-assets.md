# 视觉圣经、角色板与场景资产

多风格资产的选择、短模板和环境调用见 [多风格视觉资产提示词模块](visual-style-and-asset-modules.md)。先选风格，再写题材身份和资产结构；不把国漫、BJD 或任何渲染技术写成默认前缀。战甲、仙袍、头饰流苏另读仓库 `_core/references/assets/anime-3d-asset-lexicon.md`（结构计数：肩甲片数、流苏股数、飘带条数）。生图前必须通过 `python -m core.lib.asset_prompt`。

## 1. 项目风格圣经


先把一种主媒介/渲染方向锁为全剧基准，例如“3D半写实国漫CG”或“BJD雕塑感半写实国漫”。再定色彩范围、对比度、边缘处理、皮肤/布料/金属的反光方式、主辅光和背景层次。避免同一主提示词同时要求照片实拍、二维平涂、塑料BJD、皮克斯Q版和硬写实PBR。可以在角色或场景上有设计变化，但要能解释为同一世界的美术语言。

色彩写到“色名＋底调/冷暖＋明度/饱和度＋面积/部位＋材质响应”，例如珍珠白主衣、烟灰透明纱、水碧腰饰、香槟金滚边和扣件，并说明它们如何区分衣层、衬托肤色或对应身份。可用65/25/10快速起稿，但不是配色标准；繁复礼服可增加色阶和装饰色，需明确视觉顺序。项目色卡可记录HEX/RGB或实物参考以便团队沟通，不承诺生成像素精确。

配色、服装结构、纹样工艺和饰品连接词汇见 [配色、服装与饰品描述库](palette-costume-jewelry.md)。按项目题材选取其中玄幻仙侠、虚构华丽宫廷、现代都市、高武武侠或灵异规则怪谈模块；男女角色均须写清衣层、鞋履、发型、饰品固定点、材质和颜色落位。现代造型另按需要读取校园、职场、运动、JK、洛丽塔、COS、鞋袜与分项妆容规则。提示词只使用当前角色适用的设计项，不把词库堆进单条提示词。

人物妆发调用顺序：先从 [发型结构库](hair-style-library.md) 选择分区、束点、长度与固定方式，再从 [发色库](hair-color-library.md) 锁固有色及根尖分布；面部先锁五官，再从 [眼妆库](eye-makeup-library.md) 选择眼周分区处理，剧情需要额彩、花钿、面纹、封印或疤痕时读取 [脸部印花库](facial-markings-library.md)。四库只提供可组合的设计语言，最终写进同一条人物四视图提示词；未选中的词不进入成稿。面纹缺席也要在角色卡记为“无”，避免模型随机添加。每个角色同时保存一份 `character_design_record`，至少列出实际采用的库文件、条目/段落、具体落词、未采用候选及原因；没有这份记录，不得声称提示词已使用发型库或服饰库。

## 2. 角色身份卡

角色层级默认按男主/女主的高精美完成度处理；只有用户明确写出配角、NPC、路人或侍从时，才降低视觉竞争变量。明确出现玄幻修仙、仙侠或修真时，人物资产默认采用仙侠高精美方向，粗麻、破旧或无设计感素衣必须有剧情依据。

先分事实和设计补全，再锁：姓名/稳定ID、外观年龄、身份轮廓、身高体态、脸型、眉眼鼻唇、肤色、疤痕/痣、发际线与发色、发型束点、发饰结构、眼妆/面纹/印记、衣装套系、主辅色、材质、左右挂点、`voice_profile_id`及音色档案路径、可变状态、使用场次。人物资产板双手空置；持物手属于剧情道具和分镜记录，不进入四视图人物基准图。音色不能从人物图推断，应单独按 [角色音色档案与跨段一致性](voice-profile-and-continuity.md) 建立并核验。脸与体态做角色差异时优先改骨相/比例/发线/辨识性细节，不靠每人换夸张妆容。

脸部词汇选择一组协调骨相，继续写脸部长宽、额颧颌关系、下颌线和下巴；眼眉鼻唇分别描述形状与相对比例。避免给同一张脸叠互斥结构。肤色可以是冷瓷白、暖象牙、自然米色、浅蜜、麦色、深棕；不默认漂白。妆面分别写眉、眼线/眼影、颊色和唇色；男角不默认浓妆。脸型、五官、韩系等妆造审美词及混合外观参考的拆解方法见 [脸型五官与华丽服饰设计](face-design-and-opulence.md)。

脸型、五官和妆面统一刻画在四视图板左侧的超大正面胸像中，不拆分为独立面部资产图。主角/重要角色需在胸像中清晰展示骨相和五官比例；右侧正面、45度、背面全身保持同一身份，其中45度视角辅助确认侧向面部结构。避免厚刘海、大冠、浓妆和强表情遮挡脸缘与骨相。

### 角色类型与完整搭配强制入口

人物提示词先读 [角色类型与全套造型库](character-archetype-wardrobe-library.md)，分别选择世界约束、身份/职业、剧情功能、角色层级、气质、个人审美、关系阶段、当前场景、动作需求和状态，再编译完整 Look Card；题材不得直接指定服装。随后读取 [角色类型脸型骨相库](face-archetype-library.md)，独立选择骨相路径、气质与五官表现，并检查同作品角色区分度。先定日常、精致、舞台化或礼仪级造型强度；都市漫剧主角可以华丽、戏剧化，也可以穿精致的日常装或项目明确的学院制服。校园角色先查校服/私服设定与季节，再独立选择光腿、短袜或其他腿部层和适合的鞋型。黑丝袜、厚底大头鞋和夸张肩部结构都不是默认项。

每条人物提示词都要完整描述：具体发型与发色拓扑；上衣的内层、中层和外层；裤、裙、裙裤或连衣裙的实际结构；腰肩腕部的扣合/承载件；鞋履；袜类或明确的裸腿/护胫；配饰套系及位置；气质如何通过体态、视线和动作呈现。下装不得只写“裙子”或“裤子”，须说明剪裁、腰线、长度、褶量/裤型、活动结构和正侧背的可辨识点。不可将设计责任留给模型。

### 妆发服饰细节描述顺序

1. **身份与整体轮廓**：年龄感、体型、气质如何体现在站姿与服装剪影。
2. **五官/肤质/妆面**：脸型、眉眼、鼻唇、肤色、妆面强度、皮肤质感。
3. **头发与头饰**：天然/染色/灵力变化的发色来源，发根至发梢色阶；发际线、分缝、发量、发丝直卷、层次、束点高度、鬓发、后发长度、冠/簪固定位置、前侧背连接、飘带终点。
4. **服装由内到外并覆盖全身**：内衣/中衣/衬衫、主上衣、外套/外袍/甲胄；腰肩腕部结构；明确的裤/裙/裙裤；袜/腿部层；鞋履。每层写领型、露出区域、肩袖、衣长、闭合、下摆/褶片、活动余量和材质。
5. **全套配件与纹样**：头饰、耳颈胸饰、腰件、腕饰、包/武器挂点及鞋面细节按需组合；写数量、挂点、连接方式、人物自身左右、长度终点。纹样写主体母题和具体衣片部位。
6. **颜色与材质**：每层主色/辅色、鞋袜颜色与饰品金属色；丝/纱/皮/玉/金属的表面响应，刺绣工艺对应到衣片部位。
7. **气质和状态**：站姿、肩颈、重心、手势、视线、微表情及当前穿着完整度/磨损状态。
8. **多视角锁定**：胸像和三张全身为同一人、同一套状态；完整锁定上衣、下装、鞋袜、头发、饰品及容易漂移的左右结构。

可用色彩词汇示例见 [配色、服装与饰品描述库](palette-costume-jewelry.md)。此处列举不是封闭色表；可使用其他明确色名、偏色、明度和饱和度描述。词必须落到衣层或配件，不能只堆色名。

材质要映射到实体：哑光丝绸是宽柔高光，缎面沿褶皱出现连续亮带，绫锦是低对比织纹，轻纱边缘透光且叠层逐渐加深，皮革在关节处有褶，金属有局部高光与磨损，玉石有内纹和半透明边缘，宝石有切面高光与爪托。现代装可写牛仔斜纹与褪色线、棉质针织布的哑光和拉伸褶、罗纹针织、羊毛呢的绒面、尼龙/软壳的防泼水微光、网眼透气拼片、运动弹力布的张力与接缝。刺绣可具体写盘金绣、平绣、钉珠、滚边、花丝或錾刻，标明在哪块衣料及主辅图案。重宝石须有承重的托底，不要同时要求重工满幅与无重量薄纱。

发饰写结构而非词串：冠底如何固定在束发处；主石位于额前还是后脑；簪由哪侧穿入；链条/流苏在哪里连接、垂到哪一层衣料；背视如何接续。耳坠写托座、宝石、链节、末端位置；项链/腰坠写连接和受力点。方向始终以“人物自身左/右”标注，背视不镜像换边。

玄幻角色发色可用墨黑、冷黑、乌蓝、栗棕、茶褐、霜白、银灰、赤铜、绛紫等，但选择须对应血脉、修行阶段、阵营或个人识别，避免全员白发。明确发根、主体、发尾与受光高光分别是什么颜色；渐变和挑染写起止位置及面积，不能只写“黑白渐变”。战斗时说明束发是否松脱、飞扬方向与冠饰是否仍固定。眼妆、面纹、额印和伤痕分别记形状、颜色、准确落点、左右、常态可见性及触发变化；面纹须沿具体骨相走向，不覆盖关键表情。入魔/神格/功法全开只改变已登记的局部状态，不让脸型、瞳色、发长和五官无因果漂移。

## 3. 默认四视图板版式

一张16:9横屏图。左侧约35–40%为超大正面胸像；右侧约60–65%为同一身高基线的正面全身、人物自身左转45°全身、背面全身。顶冠、发梢和鞋底完整可见；右侧三人形比例一致、互不遮挡。背景用白/浅灰无缝底或低干扰纯色，柔和均匀光，人物与背景有边界。不要将胸像误作另一个身份，不要自动做五宫格/多头像/局部细节小窗。

人物四视图资产板禁止手持物：正面、45度和背面均以自然放松的空手站姿展示，两只手不握、抱、提、举书、包、手机、武器、法器或其他剧情道具，手部轮廓与服装袖口保持可见。背包和斜挎包若属于固定穿戴造型，可通过肩带承重而非手扶；独立道具另出道具资产图，视频镜头需要持物时再在分镜中绑定角色、道具、持物手和动作。

若用户要求严格看衣服侧缝或背部连接，把45°视图改为90°侧面，仍保持四视图。只有用户明确要求扩展资产，或单张板经过修订仍无法辨认关键结构时，才提出额外图；同一视图不要拆成多次生成再冒充一次图。

### 角色资产图提示词必须可直接复制

提示词编译分两步：先把 `character_design_record` 的唯一选定值展开为完整造型，再按本节模板组织正向和针对性负向提示词。检查记录中的发型拓扑、发色分区、衣层顺序、裤裙结构、袜/腿部层、鞋型、饰品左右和脸部识别点是否都在正文出现；缺任一项就退回造型记录，不用“同上”补齐。

交付前执行 [人物造型定稿与提示词一致性审核](character-styling-review.md)。从同一份确定的造型记录展开所有段落，审查完整搭配、左右位置、材质、姿态和正负向一致性；结构完整但视觉不协调的稿件仍须修订。

写一条完整正向提示词和针对性负向提示词。正向词覆盖：16:9与板式、角色身份和骨相、妆容肤色、头发和头饰前侧背结构、服装层次与工艺、首饰连接与左右、主辅色、材质受光、双手空置的自然站姿、四视角同一身份。负向项只针对本角色真实风险，如多脸、额外格子、冠饰结构漂移、手持或怀抱物件、裁切鞋履；不要堆互相冲突的“禁止”。

### 提示词组织模板（占位骨架，交付前必须替换）

```text
生成一张16:9横屏人物资产板：左侧约38%超大正面胸像，右侧并排正面全身、人物自身左转45°全身、背面全身；四个视角是同一角色。纯白/浅灰无缝背景，柔光，人物全身不裁切。
角色身份与骨相：……
肤色、眉眼妆、面纹/印记与皮肤质感（含位置及常态/触发态）：……
发色来源与色阶、发型与头饰结构（前/侧/背、固定点、垂落终点）：……
完整服装（内层→上衣主层→外层/甲胄→腰肩腕结构→裤/裙/裙裤→袜/腿部层→鞋履）：……
全套饰品与位置：……
主辅色与工艺/纹样的具体部位：……
材质受光与整体媒介：……

```

实际交付须填入完整具体描述，不能把模板省略号或“同上”发给图像工具。

国漫仙侠、玄幻人物要从协调词组中选，而非整库堆叠。可按冷瓷肌/暖象牙/麦色肤质；鹅蛋脸、圆脸、长脸、方圆脸、菱形脸；剑眉、柳叶眉、丹凤/桃花/杏眼；眉眼鼻唇分别落位并写出识别点，全部呈现在四视图板左侧的大胸像中，不新增面容资产图。发饰说明冠底固定点、主石位置、簪的穿插方向、流苏链的连接端点与背部落点。服装写“内搭→外袍/披帛→腰封→裙/裤→鞋”，图案具体到领缘、袖口、衣襟、下摆；配色写明底调、明度、饱和度、面积和服饰落位。薄纱叠层、锦缎暗纹、绣金的受光、玉的内纹/半透明边缘、宝石切面、皮革褶皱都映射到可见材质。用户明确要求华丽或礼仪级服装时，读取 [脸型五官与华丽服饰设计](face-design-and-opulence.md) 中的华丽度层级与细节展开清单；母题和饰品数量按身份、场合与设计繁复度决定，多种装饰并用时标明视觉层级、分布、固定点和材质。

提示词按出图工具真实格式交付：若有独立负向提示字段，可给针对性短负向词；若无此字段，不把“禁止XX”清单混入正向描述。常见风险只从本图挑选，例如额外人脸、视图数错误、裁切鞋履、冠饰跨视角漂移、文字水印或风格混杂。

## 4. 场景与道具资产

场景提示词按项目题材读取 [漫剧场景方向与提示词词库](scene-direction-library.md)，覆盖现代都市、古代宫廷、玄幻修仙、武侠江湖、末世灵异、校园言情和未来科技。先选符合项目设定的方向，再将具体地点、空间关系、材质、光源、色彩和剧情状态写实；词库是可选参考，不将整段词汇堆进提示词，也不把未核验的历史/科技设定当作事实。

场景DNA含区域边界、入口出口、固定地标、建筑/自然结构比例、材质、色卡、主光源、固定陈设。把永久结构、固定家具、状态陈设、临时剧情道具和人物随身道具分开。每个漫剧剧情场景默认建立一张16:9场景四向基准板：同一地点的正向、左侧向、右侧向、反向四个结构视图，明确相机方位、空间朝向与连续地标；其用途是锁定空间，而不是制作四张氛围概念图。四个视图须保持边界、门窗、柱列、家具、地面走向、尺度、光源和时间天气一致，不得把观察方向变化误画成建筑结构变化。仅当用户明确指定单视点场景时，才登记为单视点资产，并注明可用机位范围；新增方向超出资产可确认范围时，先补齐四向基准板。多入口、跨层、追逐、打斗或复杂遮挡还需另做俯视/轴测调度图，不能用四向板代替路线图。实际图片未展示的区域保持未知，不从文字或文件名臆造。

按场景家族→区域→四向结构基准→机位→时间/天气/损毁变体建版本关系。变体只改变事件要求的部分，不让家具、门向、建筑尺度无故漂移。四向基准只锁空间，不要求为了“母版完整”额外制作日夜版本；用户只有夜景剧情时直接锁定夜景基准即可。

场景四向基准板优先交代可复用固定结构、主要光源、各视点之间的方位对应和行动区域；四个视图使用统一比例、相机高度及中性环境状态，不加入角色、景深虚化、运动模糊或剧情瞬时效果。使用同一张16:9板的2×2等大视窗展示四向：左上正向、右上左侧向、左下右侧向、右下反向，每个裁出的视图仍为16:9；如模型难以生成准确文字，不要求图内标注，改由资产记录映射视图。不得把四个不同场景拼成四视图。除剧情确需人群外，不把随机人物烘焙进母场景。四向板不能表达高差、路线或遮挡时，再增做顶视调度图；每张补充资产只解决一个识别问题。

场景图区分固定结构与可持续环境动态。母版呈现可复用空间，不烘焙只属于某一镜的鱼群、飞鸟、雨滴轨迹、火焰姿态或临时剧情道具；可重复且有剧情用途的动态写入场景状态说明，标明源头、所在区域、运动方向、强度及可见结果。视频分镜可在这些边界内调用动态，不得为了“画面活起来”随意新增剧情实体或改变环境状态。

四向板是空间核对母版。镜头实际绑定场景图时，按 `view_map` 取相应视图并裁成单独参考图，登记母版资产ID、视图方位、裁切区域、输出路径及校验状态；如需更高分辨率，再以已确认母版对应视图为参考制作单视角图，仍按单张生成费用门执行。不要把整张四向拼板直接当作剧情画面的首帧或唯一场景参考，以免模型把四格版式复制进视频。裁切图只能证明该视图内可见结构；不得以裁切放大推断未展示的空间。

关键道具一张16:9结构板优先展示轮廓、比例、开合/握持处、材质、磨损和状态。武器资产板默认采用“左侧完整主图、右侧细节图”：按器型轮廓长度、展开宽度、结构复杂度及需要放大的部位，在左侧分配约48–68%画幅，右侧分配其余32–52%；数字是构图范围，不是要求精确切割。细长武器（剑、枪、戟、棍、弓）通常主图56–62%、细节区38–44%；宽展/重型武器（斧、盾、伞、扇、环阵）通常主图60–68%、细节区32–40%；短小但结构密集的武器/法器（短刃、印、珠、暗器）通常主图48–56%、细节区44–52%。以主图完整呈现独特剪影为先；器物过长时允许斜向摆放，但尖端、柄尾、弓弦或子件不得裁切。右侧默认安排2–3个边界稳定的局部放大窗，分别解决连接/握持结构、材料/刻纹、必要的启动结构或状态之一；每窗都对应左侧同一物件的真实部位，不另画一把完整武器，不强制塞满全部细节。细节窗不足以读出内容时删减低优先级窗口，不能压缩主图。

普通物件不因为“通透/玉质”而自行发光；若剧情特意令法器发光，写明发光源和照亮的受体。小物需要手持比例时写在镜头提示词，不必额外生成资产。玄幻修仙项目的男女主本命法宝、重要角色专属法器及核心炼器道具，读取 [玄幻修仙主角武器与法器资产设计](xianxia-hero-artifacts.md)，在常规结构信息外增加原创剪影、炼材与锻造逻辑、灵纹层级、灵力路径和状态特效；普通角色/NPC武器继续按一般道具规范，不强行堆砌主角级复杂度，但仍使用主图+右侧细节图版式。提示词应写清16:9横板、左侧主图占比区间、右侧细节区占比区间及各细节窗内容；不依赖模型自行决定版式。若生成工具无法稳定生成分栏，先保留完整主图并减少细节窗，不改为多张独立生成或自动追加调用。

## 5. 资产状态与提示词依赖

资产记录：`asset_id / kind / name / version / parent_version / source / evidence / purpose / controls / does_not_control / allowed_variation / ratio / path / hash / status / shots`。场景四向板另记录 `view_map`（视图方位/朝向/固定地标）、`world_axis`（空间轴线）、`anchor_map`（入口、窗、柱、固定陈设等关系）和 `state_baseline`（天气、时间、光源、环境动态基线）。参考类型区分身份、场景结构、服装、动作、风格、构图、声音；一项参考不要同时承担互相冲突的全部控制。

提示词按单张图独立可复制：写足项目风格、当前实体外观、场景固定锚点、当前状态、构图、光线和比例。不可以用“同上一镜/同角色卡/参照前图”代替当前模型实际收到的参考或描述。上传的四视图板只锁一个角色身份，不是镜头起始画面。

# 表演、摄影、分镜与连续性

## 镜头是可审查单元

一个镜头围绕一个主要可见动作或一个明确的观察变化。复杂打斗可有连续的子节拍，但每一节拍要有明确起因和结束状态。镜头切换须带来信息、关系、动作阶段、时空或观察位置变化；不要仅为填镜数切。

镜头工作表字段：

| 字段 | 需要记录的内容 |
|---|---|
| `shot_id / group_id` | 全局稳定ID与生成组ID |
| `start/end` | 项目时间线起止秒数；无空洞、重叠 |
| `purpose` | 观众在此新增知道/感受到什么 |
| `viewpoint / focus_owner` | 当前镜头的观察视点，以及本场带领观众的角色/行动 |
| `subject/framing` | 谁或什么是主体，景别、构图和层次 |
| `screen_height_ratio` | 人物或关键主体约占画面高度比例；双人镜分别记录 |
| `camera` | 机位位置/高度/朝向、焦点和必要的景深 |
| `movement` | 移动类型、触发点、路径、幅度、速度与终点 |
| `blocking` | 人物位置、身体朝向、视线对象、持物手、入离画路径 |
| `cut_reason` | 切镜触发事件、切后焦点及新增信息；无切镜时标 none |
| `performance` | 情绪目标、策略、触发、可见身体/面部变化、听者反应 |
| `dialogue/audio` | utterance ID、原文、说者、语气、OS/VO、同步声音事件 |
| `start_state/end_state` | 人、物、姿态、场景、伤损、光线与声音接缝状态 |
| `continuity_from` | 应从哪个镜头状态继承；跳时/换场明确标注 |

镜头时长由对白试读、动作节拍、反应停留和转场需求倒推。2–5秒对话近景、短动作镜可作节奏参考，不设所有项目通用硬门槛。生成任务时长单独计算。禁止靠空镜拉长镜头凑剧本标注时长。

## H3导演谱：先锁时间，再写形容词

正式 H3 job 必须先完成导演谱，不能直接从剧情梗概扩写成长段提示词。导演谱以 job 本地时间为准，把整段连续覆盖成若干 `beats`；每个 beat 是一个可观察的状态变化窗口，不是镜头术语堆叠。相邻 beat 不留空洞、不重叠，最后一个 beat 必须到达 job 时长。

每个 beat 至少记录：

| 字段 | 必须回答的问题 |
|---|---|
| `start_seconds / end_seconds` | 这段变化准确发生在哪个时间窗 |
| `focus` | 观众此刻主要看谁、哪只手或哪个物件 |
| `viewpoint / shot_scale / screen_height_ratio` | 主客观观察位置、景别及人物/关键主体约占画面高度的比例 |
| `visible_action` | 谁先做什么，动作路径、接触点和可见结果是什么 |
| `positions / spatial_layer` | 每个在场人物相对空间锚点、画面区域、前中后景层次的位置及身体朝向 |
| `cut_reason` | 切镜由何可见事件触发，切后让观众新增读到什么 |
| `gaze` | 每个人看向谁或什么，何时转移视线 |
| `expression` | 触发前状态、最先变化的面部区域、是否压回、结束表情 |
| `camera` | 此时间窗内摄影机保持什么或只执行哪一个运动 |
| `audio` | 同步环境声、动作声、对白事件或有意静默 |
| `end_state` | 交给下一 beat 的人物、手、道具、表情和镜头状态 |

站位不能只写“二人隔案对视”。至少用一个固定场景锚点和一个画面区域双重定位，例如“角色A在长案东端、画面右三分之一，身体朝西北；角色B完整位于西柱后，此时脸、手与衣角均不进入画面”。同一人物换位时写起点、路径、到达时间和终点。身体朝向、脸朝向、眼睛目标分别记录。

### 可见性与出场顺序

每个 job 在首个 beat 明确：已在画面内的人、完全在画外或遮挡后的人、局部可见的人。需要悬念式出场时，使用可验证的揭示条件：

- 揭示前：人物完整位于具体遮挡物后，脸、手、衣角均不进入画面；
- 揭示触发：由一个动作、声音、视线或切镜触发；
- 首次可见：写准确时间窗、先出现的身体部位和画面位置；
- 完成出场：写到达位置、身体朝向、与其他人物的距离；
- 揭示后：镜头至少停留足够时间，让观众识别身份和反应。

两人第一次相遇、伏击、惊吓、身份揭露等镜头必须有 `entrance_order`。未轮到出场的人不得用“留一段身影”“隐约站着”等模糊描述提前泄露；若确实要预示，只指定唯一可见线索及其叙事目的。

### 动作负荷与拆段

细节多不等于同一时间塞入更多动作。先计算 job 内的高负荷事件：进场/离场、跨区域位移、开合或交接关键道具、复杂手部接触、显著情绪转折、完整对白、切镜或大幅运镜。一个 10 秒 job 默认只承载一条主要因果链；两次以上切镜、两名人物连续走位、道具操作和完整对白同时出现时，必须删减、稳定机位或拆成相邻 job。不能用更长提示词掩盖时间不足。

每个 beat 只保留一个主变化，允许与它同步的自然反应。先完成动作，再给反应读取时间，再进入对白；口型对白期间避免转身、跨步、开匣、拔刀等精细动作。若一句话是本段信息高潮，至少留出起句前的准备和句末后的反应停留。

## 场次焦点与观察视点

每场戏先写清戏剧焦点：当前由谁的目标、感知或行动带领观众，场内阻碍是什么，本场结束时哪项信息、关系或局势发生了可见变化。对手戏可以轮流给双方主观权重，但每个 beat 只设一个主要观察对象；另一方通过入画、视线、动作或声音进入观众认知。切换焦点必须由剧情事件触发，并写明触发点和观众因此新增的信息，不能为了“双方都拍到”机械正反打。

主观镜头必须明确视点角色、其正在看的目标、画面边界和观察动机。角色看水就让观众从其可理解的视点看到水面目标，再以视线回切确认角色注意到什么；不得把主观镜头写成无来源的景物插入。目标物的动作要服务人物感知或剧情因果，不能为了画面丰富临时增加会改变情节的新生物、物件、人物或事件。

环境动态按“可见来源/触发 → 运动路径 → 可观察结果 → 人物是否察觉”设计。只加入与地点状态、天气、人物动作或剧情有关且能持续的动态，例如水面涟漪、鱼群追逐、檐水落下、灯焰受风轻摆、衣袖被风带动；说明动态位于画面何处、速度/幅度和持续状态。静态场景不等于死画面，但也不以无关粒子、随机飞鸟或随机路人填满画面。动态背景不得抢过本 beat 的戏剧焦点。

每次切镜或特写前回答：切换由哪个可见事件触发、观众此刻需要读到什么、切后如何改变信息/关系/动作理解。若答案只是“更有氛围”“更电影感”，保留原景别与机位。微表情确实承载剧情信息时才切近景；需要先建立角色与目标的空间关系时，先用可读的中景/双人景，再按因果切到观察对象或反应。不要连续堆脸部特写，也不要在情绪尚无触发时提前给反应镜头。

动作戏按“谁发起、谁响应、动作路径、接触结果、双方新位置/姿态”连续覆盖。每个动作节拍可决定唯一主视点；攻击、格挡、受击或关键技能的镜头权重按剧情功能分配。角色施展专属技能、破局或承担代价时可短暂获得主观或视觉重点，但须先有明确起手和目标，再展示作用结果及对手/环境反馈。禁止动作凭空跳位、命中无反馈、人物等待状态消失，或用慢动作/环绕代替快速动作衔接。

## 摄影可执行性

摄影机从一个可理解的位置出发，按可达路径移动到一个有叙事意义的终点。区分：推轨/拉轨是相机位置改变，变焦是视角/焦距变化；摇摄是机位不平移而镜头转向，横移是摄影机横向移动；升降与俯仰分别说明相机高度变化和视线角度变化。景别与焦距不互相替代。只有在能控制透视或景深时才填焦距/光圈。

编译成 H3 提示词时，用自然语言说清运动类型、构图变化幅度和速度；例如缓慢小幅推近、快速大幅向右横移、固定机位静止。不要把推轨和变焦、摇摄和横移、升降和俯仰混为同一种运动。只有幅度或速度会改变画面节奏时才强调，避免在一条镜头里堆叠无明确触发点的多个运动。

动作化运镜要交代对象和终点：跟随谁、从哪个方向跟、何时停；环绕需说明弧线路径和被摄对象，不能写“镜头炫酷环绕”。复杂镜头先拆成静态构图/机位路径预演；动作本身不需要高难运动时优先稳定机位。

正式镜头使用 `camera_plan`，至少含：`start_composition`、`camera_position`、`height_angle`、`lens_intent`、`movement`、`movement_trigger`、`movement_path_speed`、`movement_end`、`end_composition`、`cut_policy`。`movement`一次只能有一个主运动；推轨后俯摇属于两个顺序动作，必须分 beat 写触发点，不能一句并列。切镜时写准确切点和切换依据；切镜后重新定义机位、主体、景别和轴线侧。连续运镜与硬切不能在同一时间窗同时发生。

运镜服务于信息变化：建立空间用稳定广/中景，手部操作用可读近景，第一次认出对方用脸部或双人关系近景。镜头到达终点后要停住，不让相机在对白和微表情高潮时继续无目的漂移。没有明确叙事收益时，稳定机位优先于推、摇、升降和环绕叠加。

## 场景动态与时空连续性

分镜中的场景必须引用已登记场景ID和已确认空间锚点。每个 beat 只使用资产视图确实能支持的区域与方向；场景图没展示的门后、廊外、建筑另一侧保持未知。需要切到新方向时，先依据场景四向板核对墙体、入口、窗、柱列、固定陈设、地面走向和光源，再确定摄影机站位；不能为匹配构图临时重画空间。

场景持续动态要跨镜继承：同一水面波纹、雨势、灯火、风向、烟雾、落叶或战损，在镜头切换时保持方向、强度和状态，除非画面中出现改变它的原因。建立场景状态表，记录固定结构、可变环境状态、已发生的变化及其触发时间。环境细节只能复用已有状态或由剧情明确引入；不能在后续镜头凭空出现/消失。

双人对手戏的切换必须保持轴线、人物所在空间位置、视线方向和背景锚点。正反打可以改变画面左右，但不得改变世界方位。每个新机位都要从四向场景图中能定位的站位出发，并说明所见锚点与遮挡关系；如果场景四向图本身无法确认空间关系，先补结构资产，不靠提示词硬猜。

## 表演与人物关系

逐句判断角色此刻想影响谁、达到什么目的、遇到什么阻力、采用什么表达策略、听者如何即时反应。没有证据不新编隐藏动机。角色表演用可见动作写：眼神目标与停留、眼睑/眉间、嘴唇/下颌、呼吸节奏、肩颈、手指、重心和动作幅度。每镜只选少数有效信号，不把十种微表情堆在同一时点。

情绪提示按“触发事件 → 外在目标/掩饰策略 → 面部信号 → 身体/呼吸信号 → 行为或关系变化”组织。面部可拆眉间/眉梢、眼睑/视线、嘴角/唇部/下颌，并选一两项有因果的细节（如泪光渐聚、吞咽、咬肌收紧）；不要求每镜把眉眼嘴三项写满，也不把“瞳孔骤缩”“青筋暴起”“眼底无光”等视觉词机械套用到所有角色。可将同类情绪按强度递进，如察觉异样→迟疑→错愕，克制不满→压住怒意→失控；强度只随事件变化，不为镜头表演而跳级。

表演描述需要有时间过程：起始表情/姿态、哪个信息触发变化、变化先出现在何处、角色是否压回去、最后停在哪里。反应镜头给观众足够读取时间；对白中的面部变化不能覆盖口型需要，也不要把复杂表情、台词、转身和大动作都塞在同一时点。听者反应依据其实际听到/看到的信息安排，可用回避视线、停顿、呼吸中断、手上动作停止等克制反应，不必自动切成夸张脸。

正式镜头使用 `performance_plan`，至少含：`objective`（想让对方怎样）、`concealment`（正在掩饰什么）、`trigger`、`baseline`、`micro_expression_sequence`、`body_breath`、`listener_reaction`、`hold_seconds`、`end_expression`。微表情按先后写两到三个信号即可，例如“刀被按住后0.15秒手指先停；上眼睑轻抬；眉心随后收紧；她吸气但把惊讶压回，嘴唇保持闭合”。禁止把“眼神复杂、气场强、表情微妙”当作可执行表演。

对白表演同时引用稳定 `voice_profile_id`，身份层声线遵循 [角色音色档案与跨段一致性](voice-profile-and-continuity.md)；导演谱只写本句相对基线的情绪变化。相邻 job 要重新写出或绑定同一声线锚点，不能依赖模型记忆。

说话者和听者分别有表演任务。说话者在开口前完成视线落点与呼吸准备；发声时嘴部承担口型，只保留低幅眉眼变化；句末闭口后再完成较明显的情绪收束。听者反应不能抢在关键词之前，也不能全程静止；写清其听到哪个词后发生何种微反应及停留时间。

## 对白导演谱

每条画内对白除冻结原文外，必须记录 `start_seconds / end_seconds`、`pre_line_action`、`delivery`、`pause_plan`、`stress`、`cadence_end`、`post_line_reaction` 和 `listener_reaction`。其中：

- `pre_line_action`：开口前的吸气、视线锁定、手部停止或吞咽；
- `delivery`：音量、音色、语速、情绪力度与角色的表达策略；
- `pause_plan`：只描述原句标点处或短语边界的停顿长度，不改写 `<d>` 内原文；
- `stress`：最多一到两个关键词，写重音方式而非加符号改台词；
- `cadence_end`：句尾上扬/下沉、收紧/放松、音量回落方式；
- `post_line_reaction`：闭口后的目光、呼吸和表情停留；
- `listener_reaction`：听者在哪个词或句尾之后反应，不能提前。

对白时长先试读；没有实测时，普通话按约3.5–5.5个汉字/秒估算，再加入开口前0.2–0.5秒准备和句末0.3–0.8秒反应。快语速必须符合人物处境。对话近景的摄影机在关键词和句尾反应期间保持稳定；对白未结束不切走发声证据，除非明确采用听者反应镜头且声音连续。

写实表演与表情包夸张是不同路线。漫剧默认按角色身份和项目风格控制幅度；只有剧情明确需要喜剧化/漫画式反差时才放大五官动作。角色既定的表情习惯可记录为表演约束或少量复用参考；单次分镜不自动要求制作九宫格/独立表情资产。若确需表情参考图，保持脸型、年龄感、发型、妆面和服饰等身份锚点，只改变情绪状态。

FACS仅按需：L1用普通可见词；L2在局部近景需要精确表情时记录相关AU/肌肉区域；L3用于表情设计/逐帧诊断。AU编号是内部分析提示，不直接把多组代码塞进普通视频提示词。悲伤不自动等于流泪，愤怒不自动等于红眼发光。妆面、肤色、年龄感和身份保持，状态改变要有剧情触发。

听者和背景人物有处境合适的微反应，不抢主动作；不知道的信息不提前反应。OS/VO是画外声音，明确来源和画内人物是否张口。某人被写为“在场”就要在画面、焦外或明确离画状态中交代；别在镜头间凭空消失/回到旧位置。

## 空间连续性

角色自身左/右、空间地图方向和画面左/右是三个不同坐标。建立主空间轴线，并用门、桌、窗、地砖、壁灯等具体锚点定义位置；正反打的画面左右可以变化，人物世界位置不能因剪辑无故改变。越轴时用建立镜头或实际运动说明新的空间方向。

局部镜头要写清这是谁的手/肩、它位于画面哪一侧、连接到何处；身体朝向和眼睛目标分开写。持物手与物件状态需跨镜一致。进出画写清从哪个门/方向进入、路径与目的地。场景真实图没显示的部分不补造为已确认空间。

空间复杂度选路：S0单背景无位移；S1单区域简单双人；S2多入口/遮挡/交接物；S3追逐或跨区域动作；S4多层建筑/群战/连续空间变化。S2以上按需求做可走路径或调度图；S0/S1不自动产生多余地图。

## 连续性与段缝

逐对检查上一镜末态与下一镜首态：位置/朝向/动作相位、左右手与道具、道具开合、服装/伤损、视线目标、表情呼吸、场景时间天气、光源和声音尾部。连接点若有跳时/闪回/转场，标清变化发生在哪里。

输出的末态必须是可见具体状态，不写“保持连续/严格继承”。边界帧只在实际存在、可用且当前 H3 模式接受时进入素材清单；没有边界帧就用文字描述并接受实际一致性检查，不宣称强锁。语言单元按ID拼回原文；动作不能超出对白可用时间。

## 预演与局部修复

当S2以上空间、多人动作或复杂VFX可能导致走位错误，先生成静态构图/纸面路线草图；无需每个场次都出分镜图。审核问题按`shot_id + 时间码 + 缺陷 + 最小修复 + 影响邻镜`记录。优先顺序为身份/主体→空间/轴线→动作因果→对白/表情→摄影→装饰细节。通过镜头锁定，仅让受影响镜头及其直接邻接镜头重新审核。

## 镜头状态账本与文武承接

### 景别与主观镜头的公开参考边界

景别信息功能、镜头连续性和 POV 的观察—目标—反应关系，参照 [Adobe 的连续镜头说明](https://www.adobe.com/tw/creativecloud/video/production/cinematography/camera-shots-and-angles/sequence-shot.html)及[造剧的景别与镜头语法章节](https://microdrama.cc/read/031-shot-language/)。这些资料帮助确定远景交代空间、全身景交代动作、近景承载反应和关系信息的用途；不规定统一的人物画面百分比。本文的数值区间属于项目内部取景起点，须结合16:9构图、人物人数、场景规模和动作可读性调整，不能称为行业硬标准或 H3/Seedance 接口参数。

每个生成 job 记录一个可复用的状态账本；它是导演谱与提示词之间的唯一连续性来源，不能用模糊的“保持一致”代替。至少登记：`world_axis`、`focus_owner`、`visible_cast`、`screen_positions`、`body_and_gaze`、`hands_and_props`、`costume_damage`、`environment_state`、`lighting_state`、`sound_tail`、`action_phase`和`transition_reason`。结束状态必须是下一 job 可以直接起拍的可见状态。

文戏采用“行动或信息触发 → 观察 → 可读反应 → 语言或选择 → 稳定末态”的承接。对白前先给视线与呼吸准备；台词期间避免同时转身、跨区域走位、复杂手部交互或多次切镜；句末留出反应读取时间。焦点在角色之间交接时，登记触发台词或动作、接手角色及观众新增信息。

武戏与法术采用“预备/重心 → 运动路径 → 接触或避让 → 受力反馈 → 新站位”的连续链；可拆成多个4–15秒job，但不能跳过动作因果。跨 job 继承攻击方向、世界轴、持物手、道具形态、动作相位和双方距离。若在动作中切断，前段以可辨的中间相位结束，后段从同一相位继续，不把蓄力、命中和收势压成同一首帧。专属技能的镜头重点只在明确起手、目标和作用结果之后给予。

连续 job 优先从上一条已审核归档视频抽取合规锚帧；若尚无可用视频，状态账本只作为文字预检，不能声称画面已被锁定。画面级续接使用I2VA、L2VA或FL2VA；角色、场景、道具参考使用Ref2VA；同一job严格遵守模式互斥。

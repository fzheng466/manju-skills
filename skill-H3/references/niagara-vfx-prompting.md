# Niagara 思路的漫剧特效提示词规范

本规范把 Unreal Niagara 的系统、发射器、逐帧更新和事件触发，转换为 MiniMax H3 可见、可剪接的特效描述。它不要求使用 Unreal，也不把软件参数直接投喂模型。

## 效果卡

每个持续出现的术法、异能、法器激活、护盾、攻击或规则异常建立一个 effect ID。先写效果卡，再进入导演谱：

| 字段 | 内容 |
|---|---|
| 叙事功能 | 威胁、保护、引导视线、命中证据、环境异常或余波 |
| 触发源与锚点 | 手势、法器结构、阵眼、伤口、设备、门缝或另一效果；准确落在何处 |
| 主形体 | 刃光、环阵、屏障、火舌、水脉、雷丝、雾带、碎晶、符纸、阴影或裂缝 |
| 效果层 | 只选实际需要的核心主体、附着流、轨迹、撞击、环境反馈、残留层 |
| 生命周期 | 静默、征兆、聚集、启动、传播、接触/作用、衰减、残留、消失或回收 |
| 运动规则 | 发射方向、速度变化、牵引、重力、旋涡、碰撞、回弹、吸附和消散边界 |
| 光色与边界 | 主辅色、透明度、边缘软硬、受光面、作用目标、遮挡与不影响区域 |
| 连续性锁定 | 下一镜必须继承的阶段、方向、范围、损伤、残留和声音尾部 |

每个特效先定一个主形体，再加不超过三个有职责的辅助层。没有主形体的散点粒子、无方向光雾和全屏滤镜不能承担剧情信息。

## Niagara 到镜头事实的映射

| Niagara 概念 | H3 的可见描述 |
|---|---|
| 系统 | 同一 effect ID 下共享的源头、规则、颜色层级、范围和结束条件 |
| 发射器 | 一层独立效果，例如剑脊流光、掌心符片、地裂火星或命中扬尘 |
| 生成 | 何时、从何处、以何种初始尺寸和朝向出现 |
| 逐帧更新 | 如何加减速、旋转、拉长、变色、收缩、受风/重力/牵引或绕障碍运动 |
| 事件处理 | 命中、碰撞、阵纹接通、收势等事件触发次级火花、冲击圈、碎屑或声响 |
| 渲染 | 实体碎片、半透明雾、硬边符文、柔光火焰、细长雷丝或折射扭曲，以及与人物和背景的遮挡关系 |

不要在模型正文中写发射器、模块、CPU/GPU 或参数名；把它们改写成可见动作、形体和时序。

## 六层编写法

按需要选择，不能强制全开：

1. 核心主体：一眼可辨的法术或器物形体。
2. 附着流：沿手臂、兵器纹路、阵线或地裂运行的能量，写起止点和方向。
3. 轨迹层：飞行物或攻击的速度、弧线、长度、断续和拖尾衰减；拖尾必须跟随真实本体。
4. 撞击层：只在接触点出现，写接触点、冲击方向、短时闪光、碎屑或冲击圈。
5. 环境反馈层：地面、雨水、尘雾、帷幔、树叶、柱体、衣发或空气如何回应。
6. 残留层：余烬、未闭合阵纹、飘散雾带、裂痕、落尘、余响或光线回落。

核心主体不得被辅助层遮住。人物脸、关键手势、攻击目标、接触点与空间锚点优先于特效密度。

## 题材规则

玄幻修仙：从法器结构、灵纹槽、悬环、刃脊、阵眼或施法手势发生。雷、火、水、风、冰、木和空间术必须有不同主形体与运动规则，不能只换颜色。

都市异能与未来科技：从设备、身体标记、可穿戴装置、城市设施或空间节点触发，写投影平面、扫描路径、实体与全息边界和现实材质反射。

灵异规则怪谈：作为规则证据和感知异常出现，例如灯光按路径熄灭、镜面反射延迟、纹样逆向爬行、影子不同步、雾从门缝倒流。异常必须有触发、边界和后果。

古风宫廷、武侠和都市言情没有超自然事件时，只使用烛焰、香灰、帷幔、雨滴、剑刃火星、车灯等现场动态；不强加漂浮花瓣、镜头光斑或粒子。

## 提示词顺序

发起：在[时间窗]，[角色/法器/节点]以[动作]触发[effect ID]，能量从[锚点]出现。

成形：先形成[核心主体]，边缘[硬/软/断续]，主色为[颜色]，辅色只在[部位]；[附着流]沿[路径]向[方向]移动。

传播：主体以[速度变化/轨迹]朝[目标]前进，拖尾仅留在[路径后方]并在[时间/距离]后衰减，不覆盖[角色脸/手/目标]。

作用：在[接触点]发生[碰撞/穿透/包裹/封锁/照明]；[撞击层]向[方向]扩开，[环境]产生[反馈]，受光面位于[位置]。

收束：到[结束时间]，[主体]变为[残留状态]；[方向、范围、损伤、声音]留给下一 beat 或 job。

“炫酷、炸裂、仙气拉满、粒子丰富、电影级VFX”不构成可执行描述。

## 镜头、声音与接缝

同一 beat 内，特效主运动服从人物主动作和镜头主运动。人物施法、法器飞行和镜头环绕不能同时都成为主运动；需要时拆 beat。广景交代范围和攻击方向，近景读取起手、纹路接通或命中证据。

声音按源头同步：聚集是吸附、细密电鸣、材质共振或水汽抽离；传播有方向性掠过声；接触点才出现冲击、碎裂或闷响；残留保留余响、落尘、雨声变化或光源回落。声音不能早于对应画面触发。

跨 job 至少继承 effect ID、阶段、源头、主形体、运动方向、范围、命中状态、环境损伤、受光方向和声音尾部。前段以蓄势结束，后段从同一蓄势相位继续；不能直接跳到爆炸或消失。需要画面级续接时，从已审核前段抽真实末帧。

## 审核与返修

核查源头、目标、路径、作用边界是否可读；主形体是否被光雾和粒子遮住；撞击、受力、尘雾、衣发、光影和声音是否同步；颜色是否混淆角色或其他能力；跨镜方向、范围、损伤、残留和声音是否继承。

失败时回到效果卡，定位源头、层级、时序、范围或受光哪项未定义；只修受影响层与镜头，不能持续在原句追加“更华丽、更强、更明显”。

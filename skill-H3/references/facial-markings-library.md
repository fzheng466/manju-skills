# 脸部印花、花钿与法纹库

用于3D半写实国漫的宫廷、玄幻、武侠、现代COS与灵异人物。先确定脸部元素的本体：彩绘/贴饰/刺青/胎记/疤痕/鳞片/法术投影，它们的材质与剧情状态不同。不能把所有眉心装饰都叫花钿，也不能把可拆头饰误作皮肤上的印记。真实朝代妆俗只有考据确认后才标历史名称；架空设计用可见形状描述。

## 1. 类型与可选位置

| 类型 | 可用形状和题材 | 必须锁定 |
|---|---|---|
| 额间花钿/额彩 | 花瓣、叶片、飞鸟、星月、云卷、几何菱形、火焰、细小点珠 | 眉心上下位置、整体宽高、中心轴、颜料/贴片/宝石的真实材质 |
| 眼尾与颧侧彩绘 | 花枝、羽翎、云线、藤纹、水波、几何折线 | 人物自身左/右、起点、走向、是否跨眼睑与颧骨 |
| 眉骨/鼻梁/面中印记 | 细线、点阵、竖纹、星点、祭仪符号 | 避开眼球、鼻翼与表情活动区，说明线宽与断点 |
| 唇角/下颌纹 | 小型印点、分叉线、兽化纹 | 与唇妆、胡须、伤疤分开；近景可辨，远景不扩成大块 |
| 血脉/族群纹 | 额角、太阳穴、颧侧或耳前的鳞纹、羽纹、树脉、晶纹 | 来源、覆盖边界、左右对称性、常态和觉醒态 |
| 宗门/契约/封印 | 额印、眼下符线、颈侧延伸纹、阵心点 | 阵法归属、激活条件、从哪一点沿哪条路径亮起 |
| 伤痕/胎记/旧纹身 | 独特形状、颜色、皮肤凹凸与愈合程度 | 永久/临时、获得时间、镜像不得换边 |
| 灵异/异化 | 皮下暗线、灰白裂纹、血色回路、局部霜化 | 触发规则、蔓延顺序、是否遮挡五官和恢复条件 |

## 2. 图案构成词库

植物可从花瓣、花蕊、叶脉、藤蔓与枝梗构成；天象可从月相、星点、日轮、云涡与雷线构成；灵兽可从羽眼、鳞片、角枝、尾羽与爪痕抽象；宗门可从几何阵心、环线、折角和节点组成。选一个主母题，规定中心、朝向、线条粗细、重复节奏和终点；辅助纹样若存在，尺寸和亮度应低于主纹。不要直接复刻特定剧集、游戏或作者的完整角色脸纹。

花钿的制作方式可为颜料点绘、薄金箔、绢片、宝石贴、金属贴片或法术凝形；写清贴合皮肤的边缘、厚度、反光和阴影。贴片有皮肤接触面，额坠则由头饰垂下，二者在侧视与背视的结构完全不同。法纹可以短时发光，颜料、疤痕、普通宝石不因“仙气”自行发光。

## 3. 配色、密度与身份

朱砂/胭脂适合暖调礼妆或祭仪；旧金/香槟金适合华丽宫廷；青碧/石绿可对应灵植或水系；银灰/冰蓝可对应霜月；乌紫/暗赤可对应异化与魔功；墨黑/铁灰可对应高武与灵异。此为可选色域，不是身份固定映射。写色名、底调、饱和度、皮肤上的实际面积、材质和明暗；大面积面纹应减少眼妆强度，复杂眼妆时额印宜简洁。男女主都可有精细花钿或面纹，NPC可以素面；数量由身份与剧情决定。

同一角色的常态、仪典、战斗、受伤、觉醒各设独立状态：永久识别印记保持位置和基本形状；可卸妆的额彩可在换装后消失；功法纹只在触发时沿已登记路径出现；损伤纹不提前出现在基准资产。若身上也有同源纹样，说明它如何从面部延伸到衣领下或手臂，不能无连接地随机复制。

## 4. 资产卡与提示词编译

角色卡记录 `mark_kind / motif / material / anchor / character_side / dimensions / line_width / color / normal_visibility / activation / removal / version`。锚点以眉心、眉尾、颧骨最高点、鼻梁中轴等面部结构定位；人物自身左右在正面、45度与反打中保持一致。资产板胸像需清楚辨认纹样边界，45度验证贴饰厚度或纹路沿骨相的方向；全身视图不应把小印记放大成另一个图案。不另开独立脸部资产板。

句式骨架（占位，不得照抄）：`【材质类型】的【母题】位于人物自身【位置】，中心距【面部锚点】约【相对距离】，宽约【相对尺度】；【颜色/明度/表面】，线条从【起点】沿【骨相方向】至【终点】；常态【可见性】，在【剧情触发】时【变化顺序与亮度】，其余五官与皮肤纹理保持不变。` 从本库现取具体设计填入、删除不适用项，负向只列本设计风险，如换边、随机增生、遮眼、贴片悬浮或法纹常态误发光。

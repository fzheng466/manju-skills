# 剧集结构、对白与表演

完整单集累计90-180秒。按试读、动作、反应和转场估时，不能以空镜凑时长。无法承载时增加有效事件、合并场次或拆集。

每场先完成场次卡：

| 项目 | 内容 |
|---|---|
| 时间地点 | 集号、场号、内外、地点、日夜和状态版本 |
| 进入状态 | 可见人物、目标、位置、道具、关系、光线、环境动态 |
| 目的与阻碍 | 谁要什么，谁或什么阻止，代价是什么 |
| 行动链 | 触发、行动、反馈、策略变化、结果 |
| 情绪与关系 | 起点、触发、压制或释放、终点 |
| 离开状态 | 人物、道具、伤损、能力、环境和声音的可继承状态 |

每句对白先写意图，例如试探、掩饰、索取、拒绝、施压、安抚、拖延或承认。再写听者何时反应、关系如何变化。台词表记录稳定ID、说者听者、画内或画外、冻结原句、触发、表演、听者反应和结果。

说明信息应发生在人物争取、隐瞒、验证、误解或付代价时。潜台词从角色目标和限制中产生，必须能由回避、停顿、换题、动作停止、选择或后果读出。

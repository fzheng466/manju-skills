# 渠道能力面谈（调用 skill 的第一步）

在写任何视频提示词或提交生成之前执行。能力事实分三层，生效值取最严：

```
effective = model baseline ∩ channel profile ∩ project constraints
```

档案放在 `$MANJU_HOME/channels/<channel_id>.json`（默认 `~/.manju/channels`），不进 skill 仓库，不存密钥。

## 流程

1. 选渠道：已有档案列表，或新建。
2. 已有且未过期 → 显示摘要卡，问「仍然准确吗？」
   - 是 → 跳过面谈
   - 有过期项或用户说有变化 → 只问那些项
3. 新渠道 → 最多 3 轮表单（第 3 轮默认跳过）。
4. 计算生效能力，输出编译预览（拆几段、裁哪些参考、声音是否改后期）。
5. 用户确认 → 写入 `effective-capability.lock.json` → 才允许编译。

画幅冲突（项目 16:9、渠道只有 9:16）**拦截**，让用户三选一：换渠道 / 整项目改竖屏重编 / 单独做竖屏衍生版。不要偷偷改正片比例。

## 第 1 轮（必问，一张表）

| ID | 问法 | 选项 |
|---|---|---|
| Q1 | 给这个渠道起个名字 | 填空 |
| Q2 | 这次用哪个模型 | H3 / Seedance 2.0 / Seedance 2.5 |
| Q3 | 单次生成时长 | ≤5s / ≤10s / ≤15s / ≤30s / 自定义 / 不确定 |
| Q4 | 画幅（可多选） | 16:9 / 9:16 / 1:1 / 跟随首帧 / 不确定 |

## 第 2 轮（输入能力）

| ID | 问法 | 选项 |
|---|---|---|
| Q5 | 一次最多几张参考图 | 0 / 1 / 2 / 3–4 / 5–9 / 10+ / 不确定 |
| Q6 | 首尾帧 | 都不支持 / 只首帧 / 首尾都支持 / 不确定 |
| Q7 | 参考视频或音频 | 都不行 / 只能视频 / 只能音频 / 都可以 / 不确定 |
| Q8 | 生成视频带声音吗 | 不带 / 只有环境音 / 能台词口型 / 不确定 |

不支持的模式不要显示（选了 H3 就不要问 50 张参考）。

## 第 3 轮（默认跳过）

Q9 延长/续写（默认不支持）· Q10 分辨率（unknown 不影响编译）· Q11 提示词字数 · Q12 计费（unknown 可编译但阻断提交）· Q13 并发（默认串行）· Q14 内容限制 · Q15 负向提示词字段。

跳过时一律用最保守默认值。

## 少问的规则

- 已有档案只弹摘要卡。
- ttl：时长/参考数 30 天，画幅 90 天。
- 本次用不到的能力不问（没有续镜就不问首尾帧）。
- 提交失败能识别原因时，把该项标 `failed` 并写入真实上限。

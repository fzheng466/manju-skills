# 特效事件与可见因果

特效服务于故事信息、动作结果或人物能力识别。它不代替 Seedance 接口能力描述，也不承诺模型具备真实 Niagara 粒子系统或逐参数模拟。

## 效果卡

对持续跨镜的法术、异能、法器激活、护盾或规则异常建立稳定效果ID，记录叙事功能、触发源和空间锚点、核心形体、必要辅助层、生命周期、方向/速度/碰撞规则、颜色与边界、环境响应、`visibility`（owner_only|scene_visible）、身边态档位（presence/readable/fullscreen）及下一镜要继承的 `fx_state`。owner_only 特效在非持有者入画并被说话时必须收起。

从“征兆—聚集—成形—传播—接触/作用—衰减—残留/消失”选择实际可见阶段。每次特效保留一个主形体，辅助层必须承担可辨职责；粒子不能遮住脸、关键手势、攻击目标或接触证据。

## 编写顺序

写清触发者和来源点；主形体如何出现；沿何路径和方向移动；何时接触哪个目标；目标和环境产生什么反馈；如何衰减；末态留下什么。声音与可见事件同步：聚集声跟随聚集，掠过声跟随传播，冲击声只在接触时发生，余响对应实际残留。

同一时间段里人物主动作、特效主运动、镜头运动只允许一个成为主要运动；其他运动降为辅助，复杂时拆镜。玄幻元素按能力机制选择形体，不只是更换颜色；现实/校园/宫廷场景没有超自然事件时，不自动添加粒子和泛光。

## 跨镜检查

连续性账本继承触发源、阶段、主形体、运动方向、作用范围、命中状态、环境损伤、受光方向、残留和声音尾部。视频续接锚点若需要素材输入，只能按当前锁定版本能力选择来源和绑定方式。

审片检查源头/目标/路径是否易读、主形体是否被遮挡、接触和环境反馈是否同步、色彩是否混淆角色能力，以及跨片段状态是否成立。失败时定位触发、形体、时序、范围或遮挡问题，做最小返修。

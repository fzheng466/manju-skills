# 角色类型、气质与全套造型库

## 1. 用途与硬规则

### 1.0 未指定角色层级时的默认

如果用户没有明确写“配角”“NPC”“路人”“侍从”等角色层级词，默认按男主/女主的高精美、高完成度标准建立 Look Card。默认人物需要清晰骨相、精致妆发、完整衣层、可读材质、成套饰品和稳定识别点；不得因为用户没写“主角”就降成粗麻烂布、破旧单层素衣或无设计感的普通路人。粗粝、破损、低材质等级须有资源限制、职业功能、剧情状态或世界条件作为依据。

用户明确说“玄幻修仙”“仙侠”或“修真”时，默认进入仙侠高精美方向：服装采用有剪裁和层次的门派/修行服制，写清精致面料、织物垂坠、灵纹层级、玉石/金属/织物分材质、发冠/簪饰固定点、法器挂点和与修行阶段相应的状态。

玄幻修仙/仙侠/修真的男主、女主必须达到题材下限，且下限为默认开启、不可削减：①服装结构达到“结构丰富度多路径达标”——重工多层叠、半透纱罩层次、高开衩+披帛飘带、抹胸+外纱外套、腰封+腿饰/绑腿结构、大氅披风+内层结构中任一路径成立即可，**不设固定层数下限，也不得为凑层数强加无露出关系的衣层**（判定与槽位见 `xianxia-manju-costume-library.md` 第2、5节）；②主衣在领缘、袖缘、裙门、下摆等定点位置有可描述的工艺（盘金绣、织金、暗纹提花、缂丝感纹样、滚边等），不得写成“无纹样”“仅同色暗纹”；③必须成套头面（任选载体系族：冠族、钗簪族、额面族、束发族、垂饰族、自然族——见 `xianxia-manju-costume-library.md` §2.8，须写明主件与固定结构，载体按发型联动，件数自由）与成套腰部承载（腰封/腰带+腰佩玉/系带法器），不得只有一支簪子称为“唯一主饰”；④配色按主色+辅色+强调色+金属色分层，且明确玉石/金属/织物三类材质；⑤鞋履与腿足结构独立选择并写清（鞋型/鞋底、开衩高度、腿环/绑带/足环等都可为空但须写明），不得静默省略；⑥落地门派/修行阶段相应的灵纹或法器挂点。“克制、素雅、清冷”只能作为气质与装饰密度方向，用于降低装饰密度与色彩对比，不得取消精致面料、分层剪裁、定点工艺和成套配饰；粗麻短褂、破布长袍、农民化素衣只在凡俗、外门、受伤、逃亡等剧情明确写出的降级状态中出现。

玄幻修仙/仙侠/修真题材的造型必须按 `xianxia-manju-costume-library.md` 的九槽组合生成（廓形、纱质面料、层搭、露肤与开衩、外披肩部、鞋履、腿足点缀、头面腰佩、驱动来源），并按角色分支（仙子/圣女/女宗主/剑修/仙君/魔君/妖皇/妖姬等）选择倾向组合。该题材按 AI 漫剧定位设计：允许夸张、高华丽与非物理的飘带、纱罩、开衩、腿环、足环、悬浮表现，**不做汉服形制考据**，也不得用“仙气飘飘、华丽、高级”等形容词替代具体的纱质、开衩、悬垂与配色结构。同一作品内的同类角色必须满足该库第4节的结构层差异化硬约束，不得只换配色与花纹。

本库把人物身份、剧情功能和观众识别转成可直接绘制的整套角色造型。它不是服装名词清单。人物资产提示词必须先确定角色类型，再依本库选定一套完整造型；不得让模型只凭“女主、男主、明星、仙侠、甜美、贵气”等标签自行补全。服装、头发、鞋袜、饰品和角色气质共同构成一套视觉设计。

每个重要角色必须形成以下完整 Look Card，所有项均填写；确实不适用时写明原因，不可留给图像模型猜：

1. 角色身份、剧情功能、公开身份/私下身份、年龄感、阶层与行动需求。
2. 气质关键词转为可见行为：站姿、肩颈、重心、视线、表情张力、动作速度与空间占用。
3. 头发：发型、发长、分缝、束点、刘海/鬓发、发色与渐变分区、发饰固定方式。脸型五官另按 `face-archetype-library.md` 锁定。
4. 上身完整层次：贴身内层/衬衫或中衣、主上衣、外套/外袍/甲胄；逐层写领型、肩型、袖型、衣长、闭合方式和露出关系。
5. 下身结构必须明确二选一或明确叠搭：裤装写腰位、裆/腿型、裤长、裤口与内外层；裙装写腰位、裙型、裙长、褶量/分片、里层或安全结构、活动余量。裙裤/甲裙需说明从正侧背如何辨认。
6. 腰部、肩背、腕部与手部穿戴件：腰封/皮带、护腕、手套、披肩/披风等，写扣合与受力点及人物自身左右。人物四视图资产板双手空置，不挂手提包、手持武器或临时剧情道具；剧情用挂具和持物关系另在道具/分镜记录。
7. 鞋履：鞋型、鞋头、鞋面、鞋底/跟高、闭合结构、材质和与裤脚/裙摆关系。
8. 袜类/腿部层：袜高、透明度/厚度、织法、袜口/固定方式、与鞋口衔接。裸腿也明确写“裸腿，无袜”，不可静默遗漏。
9. 饰品成套：头饰、耳饰、颈饰、胸饰、腰佩、腕饰、戒指、背负或肩背包具按角色需要逐件取舍；写数量、材料、连接点、长度终点及左右位置。饰品必须有固定结构，不能要求角色手拿包具或饰品。
10. 主辅色、色域比例、材质响应、工艺/图案位置和穿着状态（洁净、工作磨损、战损、礼仪完整等）。

默认不使用现实品牌标识、无剧情依据的校徽/军衔/勋章、无功能的公文包、无用途的多层饰品。反向提示只拦本角色实际风险，不用负向词代替正向设计。

## 2. 角色类型的构造方式

### 2.1 身份不是单一服装标签

服装不得由题材直接决定。每名角色按以下相互独立的维度组合：`世界条件 × 社会身份/职业 × 剧情功能 × 角色层级 × 气质 × 个人审美 × 关系阶段 × 当前场景 × 行动需求 × 天气/危险 × 当前状态`。题材只提供客观限制，例如末世的资源与防护、灵异副本的规则和污染、校园的制度与年龄、仙侠的门派与修行体系；它不规定角色一定穿什么风格。

同一种气质、身份或审美可以出现在不同题材中：甜妹可以进入灵异副本，明星可以经历末世，御姐可以是校园教师或仙门师姐；同一题材也必须容纳主角、配角、反派、学生、明星、医者、工匠、贵族、普通人等多种角色。关系类型同样独立于题材：甜宠、虐恋、竞争、亲情或无恋爱线均可与校园、娱乐圈、末世、仙侠等组合。

例如“娱乐圈女主”仍需继续判断演员/歌手/练习生/经纪人/制作人、工作现场/机场私服/品牌活动/戏中戏、初入行/走红/舆论危机/关系公开；“末世明星”先保留其公众身份、个人审美和镜头辨识度，再叠加当前资源、防护与磨损；“灵异甜妹”保留甜系搭配逻辑，再按副本规则调整鞋履、携行物、污染与可行动性。相同人物在不同场景可有不同造型版本，每个版本仍须形成从妆发到鞋袜的完整 Look Card。

### 2.2 多轴搭配编译顺序

生成完整造型时依次回答，任何一轴都不能覆盖其他轴：

1. **世界约束**：年代、科技/法术水平、资源、制度、天气、危险与禁用物。只确定能否存在和必须具备的功能。
2. **身份与生活方式**：职业、阶层、公开/私下身份、收入或资源来源、日常动作。决定衣物来源、维护程度和携行结构。
3. **剧情功能与关系阶段**：主角/配角/对手、初遇/暧昧/热恋/决裂/重逢、潜伏/逃亡/公开活动等。决定本套衣装要传达的信息。
4. **气质与个人审美**：甜美、清冷、明艳、甜酷、知性、运动、华丽、复古、亚文化等可以跨题材选择。决定轮廓、色彩、妆发与装饰语言。
5. **场景和动作**：地点、礼仪、奔跑、战斗、劳动、舞台、拍摄、调查等。决定活动余量、鞋底、袖摆、裙裤与固定结构。
6. **角色视觉层级**：主角提高辨识度与焦点；配角保留美感和完整度但降低至少两项竞争变量。
7. **全身闭环**：把发型发色、妆容、内搭、主上衣、外层、裤/裙/裙裤、腰肩腕结构、袜/腿部层、鞋履、饰品、包具/道具、配色材质编成一套，逐项检查互相呼应和实际连接。

若结果仅凭题材或气质标签套用固定服装，而未核对角色和场合，判定为标签替代设计。校园项目明确设定制服时应使用该制服；未设定制服时不能擅自编造统一校服。

每套造型先定服装方向和造型强度：日常、精致、舞台化或礼仪级。在现代都市、校园、职场、运动等现实日常题材中，主角身份提高的是造型辨识度与完成度，不自动提高层数、装饰密度、鞋底厚度或露肤程度，戏剧化剪裁与华丽装饰由人物审美、场合或剧情支持；此条不适用于玄幻修仙、仙侠、修真、古风宫廷等非现实题材的男主/女主，其装饰层数、工艺密度与成套饰品按 §1.0 的题材下限默认开启。先确定完整服装，再按季节、校规、活动和视觉比例分别决定裸腿、短袜、长袜或连裤袜，以及薄底鞋、普通鞋或厚底鞋；不得把某种鞋袜当作女性主角的默认件。

### 2.3 气质转译

| 气质方向 | 站姿、视线和动作 | 造型轮廓的设计作用 |
| --- | --- | --- |
| 明亮亲和 | 肩颈放松，视线直接，动作开放但不过度摆拍 | 轻/中等肩部结构、柔和领口、可活动的层次与有温度的颜色 |
| 娇憨灵动 | 重心轻、手部动作小而快，表情反应清楚 | 轻盈剪影、清晰腰线、短外层或轻叠层；避免儿童比例 |
| 清冷疏离 | 轴线稳定、动作少、视线停留长 | 纵向线条、低彩度主色与少量高识别点、明确领肩结构；“克制”指降低装饰密度与色彩对比，不降低精致面料、分层剪裁、定点工艺与成套配饰等级（玄幻修仙/古风宫廷主角须满足 §1.0 题材下限） |
| 明艳强势 | 占据空间、肩线打开、目光正面、动作干脆 | 强对比色块、利落腰线、明确轮廓、装饰集中在脸/肩/腰其中一至两处 |
| 温柔知性 | 肩背舒展、手势有节制、视线能回应他人 | 软硬材质平衡、层次清楚而不堆叠、低对比色和精致配件 |
| 野心/攻击性 | 重心向前、下颌与视线稳定、动作路径短 | 锐利剪裁、硬质边缘、功能性扣具或甲片、强弱色块有主次 |
| 尊贵统御 | 站立垂直、动作幅度小但落点明确、视线控制场域 | 纵向/放射性结构、稳定肩背、完整仪式层级、冠/腰/鞋形成身份闭环 |
| 疲惫/受创 | 肌肉张力下降或单侧保护，目光迟滞 | 不改变基础身份轮廓；用污渍、褶皱、缺件和局部破损呈现状态 |

一名角色只选一条主气质和最多两条修饰方向。服装要支持剧情行动，不能因“强势女性”自动套西装、因“温柔女性”自动套白裙，或因“男主”自动套黑大衣。

### 2.4 主角、配角与视觉层级

所有角色都按本库建立完整 Look Card；“配角”不等于简陋、丑化或套用无设计感的NPC模板。配角应当好看、身份清楚、造型完整，但在同一场景的第一眼识别上比主角低一层。

- **主角**：为脸部记忆点、整体剪影、主辅色关系、材质反差和一至两个标志性造型焦点分配更高辨识度。服装可有更鲜明的剪裁、层叠、装饰、材质混搭和不寻常比例；每个夸张元素须服务身份、性格、剧情状态或镜头识别，并保持全身搭配完整、结构可读。
- **配角**：仍明确脸型骨相、发型发色、全套服装、鞋袜和饰品；与主角共享世界审美和制作精度，但降低轮廓独特度、装饰密度、色彩对比或焦点数量中的至少两项。配角可精致、俊美、时尚，不使用“普通、路人、丑、廉价”替代设计。
- **重要对手/反派**：可在其主场、身份揭示或关键冲突镜头短暂形成视觉竞争；主角的系列识别点仍稳定，避免每个新角色都用更大、更亮、更繁复的设计夺走全剧焦点。

层级按叙事焦点执行，不按角色善恶、性别或戏份简单分配。制作提示词前记录角色层级、主要辨识抓手及相对主角降低/突出的视觉变量。

## 3. 世界约束与角色搭配接口

以下各节只描述题材会追加的世界约束、常见身份接口和行动条件，不为题材绑定唯一人物类型、气质、脸型或服装。使用时先完成2.2节多轴组合，再从对应题材节选取本角色当场实际生效的限制。表中出现的角色位是可选示例而非角色清单；可以增加任意符合故事事实的职业、审美和关系类型。

### 3.1 种田、经营与生活成长

| 角色位 | 轮廓与完整搭配方向 |
| --- | --- |
| 女性主角/经营者 | 以便于劳动和生活移动的上衣、围裙/短褂或外搭、明确的裤装或收束裙装、适合泥土/湿地的鞋靴为一套；袜/绑腿、袖口收束、发束方式和工具袋按劳动岗位确定。成长后保留一个识别色/发饰/腰件，提升布料和剪裁，不凭空换成华服。 |
| 男性主角/劳动或经营者 | 里衣、耐磨短褂/夹袄、长裤或绑腿裤、腰带/工具挂点、劳作鞋靴、头巾/束发配成套；体力劳动者需可卷袖、蹲跪与负重。富足后变化落在面料、合身度和配件，不脱离职业功能。 |
| 家族长辈、雇工、商贩 | 按年龄、工作、收入和天气区分剪裁、补丁、磨损、头发整理与鞋底；不把全村人画成同款粗布套装。 |

### 3.2 末世、生存与废土

| 角色位 | 轮廓与完整搭配方向 |
| --- | --- |
| 女性/男性生存主角 | 贴身排汗层、耐磨长袖或软壳外层、可屈膝裤装、腰带与分区收纳、手套/护膝、袜和能抓地且封闭的鞋靴形成完整行动系统；写明轻装/负重版本、天气层和破损位置。性感、时尚或军感仅在有角色/资源依据时加入。 |
| 医疗/维修/侦察角色 | 以职业识别色、工具挂点、袖口/裤口处理、口罩/护目或医疗携行位置区分；鞋袜和手套对应场景危险。 |
| 反派组织/领袖 | 通过相对完整度、统一装备来源、标志部位和剪影建立组织权力；个体领袖可有更高材质等级，不能仅靠通体黑皮衣。 |

### 3.3 灵异、规则怪谈与恐怖

| 角色位 | 轮廓与完整搭配方向 |
| --- | --- |
| 普通人/调查者 | 先定真实职业和场景服装，再以湿痕、灰尘、局部错位或不合时宜的小细节制造异常；服装仍要完整写上衣、下装、鞋袜、包/工具和头发状态。 |
| 规则执行者/异常实体 | 选择可远距离识别的固定轮廓（制服、旧礼服、病患服、工作装等），写清年代感、版型、鞋、袜、领口、纽扣、发线和不对称异常。异常点须少而稳定、可在多镜重复，不把全身随机破烂当恐怖设计。 |
| 逃生/战斗状态 | 与普通基准套装比较，只改变实际受损/沾染/缺失部位，记录发生顺序；不无缘无故换装或变色。 |

### 3.4 都市言情：豪门、校园、虐恋与娱乐圈

本题材的服装结构、面料、层搭、露肤与开衩、鞋履、腿部层与配饰承载按 `modern-manju-costume-library.md` 的九槽系统与角色分支（清冷千金/温柔初恋/明艳主角/学院/职场精英/霸总权贵/温柔男友/偶像艺人/街头轻亚/都市异能/晚宴礼服）取词；下表只给角色位的整体方向。

都市漫剧可以按人物和场合选择现实日常、精致时装、略夸张造型或舞台礼仪造型。主角感可以来自合身的制服、鲜明骨相、妆发、配色和姿态；在都市现实题材中，戏剧剪裁、夸张廓形、丰富叠层、珠宝或非日常材质在人物审美与场景需要时加入——此限制只约束都市现实题材，玄幻修仙、仙侠、修真、古风宫廷等非现实题材的男主/女主按 §1.0 的题材下限执行，不受此限制。完整 Look Card 仍写清上衣各层、裤/裙/裙裤、腰肩腕结构、腿部层、鞋履、发型发色、妆容和配饰。

同场主配角遵循2.4节视觉层级。主角可以更强剪影、更复杂搭配或更鲜明色彩组织；配角仍须有风格和完成度，但避免同时复制主角的标志发型、核心配色、主饰品和高密度装饰。豪门、校园、虐恋、娱乐圈属于社会环境、关系机制或职业背景，可以彼此组合，也可以叠加末世、灵异、异能等世界条件；不得把它们视为互斥衣柜。

## 6. Look Card 决策与审核

本节字段检查后必须执行 [整套审美与冲突审核](character-styling-review.md)。衣层、鞋袜和饰品按整套设计选择；不为填字段增加实物，不随机组合库条目。

1. 在同一作品角色表中记录每人的 `role_archetype`、身份阶层、年龄感、体态轮廓、主气质、识别色、发型轮廓、服装剪影、主饰品和鞋型。男女主不能仅靠换性别复用同一套模板。
2. 每次为资产图选唯一的当前服装版本；若角色存在多个场景造型，逐套登记为状态变体，不把多套同时塞进四视图板。
3. 先完成整套视觉决策，再从 `palette-costume-jewelry.md`、发型/发色库、眼妆/面印库选择具体结构和词项。参考库细节必须绑定到一个实体位置，不整库堆叠。
4. 四视图逐项核对：衣层顺序、裤/裙结构、裤脚/裙摆、鞋袜、左右饰品、肩背包带、发束与发色渐变拓扑一致；背面补足后片、腰后闭合、鞋跟和发饰连接。武器不进入人物基准板。
5. 硬性完整度检查：未写上衣层次、未定裤/裙结构、未写鞋、未说明袜/腿部层、未处理配饰与发型其中任何一项，提示词不得标为完成。
6. 交叉组合检查：随机把角色的气质/职业与题材互换（如灵异甜妹、末世明星、校园虐恋），规则仍应能产出合理完整造型；若题材表直接覆盖角色审美或关系阶段，退回2.2重新编译。
7. 校园角色检查：确认校服/私服设定、季节与校规；逐项审视腿部层和鞋型是否有依据。若只因为“清冷、忧郁、女主”就加入黑丝袜、厚底大头鞋或戏剧化披肩，退回重选。
8. 四视图资产板检查：正面、45度、背面均双手空置，手指自然可见；角色不握、抱、提、举任何物件。剧情道具和持物手在分镜中单独绑定。

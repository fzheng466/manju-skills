# 玄幻仙侠武打动作提示词

## 适用范围

用于玄幻、仙侠、高武等以兵器、术法和身体动作推进剧情的漫剧镜头。此类流程不以多格剧情故事板图作为默认步骤，不要求故事板生图，也不把模型支持多图输入当作制作故事板的理由。预演改用可逐项核对的动作状态表和细节提示词。只有用户明确要求故事板图时，才走独立逐张生图与费用确认流程。

## 编写目标

提示词要让模型能看清楚“谁在什么位置，为何先动，朝哪里动，另一方如何应对，在哪里接触，冲击造成什么结果，角色最后停在哪里”。镜头服务于剧情因果与角色表演；特效、武器展示和运镜不能挤掉动作因果。

每个镜头围绕一个可读的攻防交换或一段有起因和结果的连续动作链。动作节点数量按实际镜长和可读性决定，不设置固定每秒动作数。内容过多时拆成相邻镜头或生成段，明确承接状态，不用加速、跳切或连续特写掩盖缺失动作。

## 动作提示词信息表

编写前逐项从剧本和资产中提取；剧情没有提供的事实标为待定，不擅自加伤亡、招式、道具或胜负。

| 项 | 必须具体说明 |
|---|---|
| 镜头目的 | 本镜推进哪一条剧情信息、哪方暂时占主动；观众应看懂什么 |
| 场景坐标 | 固定世界轴、进出方向、阵心/崖边/建筑等锚点、可行动区域和危险边界 |
| 起始状态 | 每名角色的画面左右、彼此距离、身体朝向、脚位、重心、持物手、兵器方向、视线目标 |
| 动作发起 | 谁先动、动机、哪只手/哪件法器启动、从身体哪个位置开始 |
| 动作路径 | 起点、经过角色或空间哪一侧、轨迹方向/高度/弧线、速度变化、到达目标或停止的位置 |
| 对手应对 | 对手何时察觉、先做什么防御或闪避、身体/脚步如何配合；应对不得早于攻击发生 |
| 接触与受力 | 精确接触部位、兵器夹角、谁承受冲击、冲击往哪边传、重心和支撑脚如何变化 |
| 结果状态 | 是否命中、格挡、偏转、卸力、后退或脱手；伤势只按剧本写；明确双方新站位和下一动作条件 |
| 微表情 | 触发点、眼神目标、眉眼/呼吸/唇部的可见变化、持续时间和恢复状态；避免只写“震惊/愤怒” |
| 仙术特效 | 发源点、聚能形态、主轮廓、运动路径、速度、接触对象、环境反馈、衰减/残留；明确不能遮挡的信息 |
| 摄影机 | 景别、机位高低与朝向、跟随对象、移动路径、速度、停止位置；每次运动要服务当前信息 |
| 声音与对白 | 台词逐字、说话者、停顿/重音/情绪；兵器、脚步、法术声按实际触发顺序；不让环境声盖住台词 |
| 镜尾接缝 | 角色位置、朝向、脚步重心、握持手、兵器状态、特效残留、场景损毁；下一镜从此状态继续 |

## 武打连贯性与力量传导

### Beat 级别的空间位置追踪

每一段连续的攻防交换（Beat）开始前，必须明确：
- 双方距离（近身/一步/两步/三步外；近身=0.5米内，一步=0.8-1.2米，两步=1.5-2.5米）
- 画面左右关系（主角在左/右，对手在左/右）
- 身体朝向（正面对正面/侧对正/背对等；用钟表方位描述）
- 重心位置（前脚/后脚/中立；支撑脚是左/右）
- 兵器状态（握持手、刃尖指向、与身体相对位置）

每次攻击、格挡、闪避后，上述五项必须更新；下一个 Beat 从更新后的状态开始，不能从上一次的初始状态重新开始。

### 力量物理模型

**冲击传导链**
- 攻击发起点（手腕/肩/腰/腿）→ 兵器接触点 → 对手接触点 → 对手身体吸收/转移路径 → 最终稳定状态
- 每一环必须可视化：挥击时肩部先转、兵器随后、击中后对手身体某部分承受冲击、冲击沿脊柱/四肢传导、最终通过脚步卸力或身体后退

**连击逻辑**
- 第一击结束时攻击者的兵器位置、身体重心、支撑脚决定了第二击的起手方式
- 禁止"连续三斩"而不说明每斩之间兵器如何回到起手位置
- 连击节奏公式：攻击1(0.8-1.2s) → 收势/转换(0.3-0.6s) → 攻击2(0.8-1.2s)
- 如果省略转换过程，必须用"借力回旋""顺势横扫"等说明兵器路径的连续性

**格挡后的力量去向**
- 硬格挡：冲击沿防守兵器传到双手→肩部→脚步，防守者后退或下沉
- 卸力格挡:接触瞬间旋转兵器/身体,冲击被引导到侧方,防守者横移或转身
- 反弹格挡:用兵器坚硬部位精确迎击,攻击者兵器被弹开,防守者几乎不移动

每次格挡必须选择一种,并描述对应的身体响应;不能"格挡成功"后双方都静止。

### 连贯性检查清单

提交前逐项核对:
1. 每个 Beat 开始时五项状态(距离/左右/朝向/重心/兵器)已明确
2. 每次攻击/格挡/闪避后,五项状态有明确更新
3. 连击时,兵器从上一击结束位置到下一击起手位置有明确路径(或明确说明"借力""顺势")
4. 每次冲击有明确的传导链(发起→接触→吸收→稳定)
5. 格挡类型(硬格/卸力/反弹)与身体响应一致
6. 禁止瞬移(角色突然出现在不同位置而无移动过程)
7. 禁止隔空接触(兵器未到达对手身体就产生受击效果)
8. 禁止无来源受伤(角色受伤但攻击未命中)
9. 禁止静止受击(角色被击中但身体无任何冲击反应)

## 多人破围与包围圈处理

### 包围圈的建立与维持

**初始包围状态描述**
- 主角位置:画面中心偏下,占比15-25%
- 敌人数量:3-8人(3人=三角包围,4-5人=半圆/全圆,6-8人=双层圆)
- 敌人分布:用钟表方位(12点/3点/6点/9点方向)或角度(正前/左前45°/右后120°等)明确每个敌人位置
- 每个敌人占比:8-15%(主要威胁),5-10%(次要威胁)
- 包围半径:所有敌人到主角的距离应相近(误差不超过1米),否则不是包围而是列队

**压力感的视觉表达**
- 至少3个敌人同时出现在画面中(单镜只拍1-2个敌人会让包围感消失)
- 主角视线扫视多个目标(通过头部转动/眼神移动表现)
- 多个敌人同时做威胁动作(举兵器/前倾/叫喊),但不同时攻击

### 破围的动作组织

**三步破围标准流程**

1. **锁定突破口(0-2秒)**
   - 主角视线锁定包围圈中某个敌人(标记为"目标A")
   - 目标A的位置应在画面可见范围(不能突然攻击画面外的敌人)
   - 其他敌人保持威胁姿态但未启动攻击

2. **爆发突破(2-5秒)**
   - 主角向目标A发起快速攻击(冲刺/跃起/法术爆发)
   - 攻击路径明确:从当前位置→目标A位置,说明经过哪些敌人之间的间隙
   - 目标A的应对:格挡/闪避/被击退,其身体移动方向应背离包围圈中心(即主角"推开"了包围圈)
   - 其他敌人反应:最近的1-2人启动追击,但因距离/反应时间未能阻止

3. **脱离与重组(5-8秒)**
   - 主角新位置:已不在包围圈中心,移动到某个敌人身后或侧翼
   - 敌人重组:原本的包围圈被打破,敌人转身/移动试图重建包围或改为列队攻击
   - 空间关系更新:明确主角与每个敌人的新距离/新方位

**禁止事项**
- 禁止"主角旋转攻击,同时击退周围所有敌人"(物理上不可能同时接触所有方向)
- 禁止"包围圈突然消失,下一镜只剩1对1"(其他敌人去向不明)
- 禁止"主角在包围圈中心连续击败多人"(应先破围再逐个击败)

### 多方向连续攻击的时序管理

当主角面对来自不同方向的连续攻击时:

**攻击顺序公式**
- 第一攻击:来自主角正前或侧前(视线可及范围),主角格挡/闪避
- 第二攻击:来自主角侧后或正后(视线盲区),通过声音/气流/第三者提醒让主角察觉
- 第三攻击:来自新的方向,此时主角已移动到新位置

**时间间隔控制**
- 攻击1启动 → 攻击1结束:0.8-1.5秒
- 攻击1结束 → 攻击2启动:0.3-0.8秒(给主角反应时间)
- 攻击2结束 → 攻击3启动:0.5-1.0秒

**空间更新强制要求**
- 每次攻击结束后,必须更新主角位置(格挡后后退/闪避后侧移/反击后前进)
- 每次更新后,重新标注所有敌人的方位(因为主角移动了,相对方位改变)
- 每个敌人的攻击方向必须指向主角当前位置,不能指向主角上一个位置

**多方向攻击检查清单**
1. 每次攻击的发起者位置已明确标注(钟表方位/角度/画面左右)
2. 主角察觉方式已说明(直接看到/听到/感知/被提醒)
3. 主角应对后的新位置已更新
4. 下一个攻击者的方位基于主角新位置重新标注
5. 同时发起的攻击不超过2个(超过2个在物理上无法分别应对)

## 打斗场景快速运镜参数规范

### Partial Cam（部分摄影机）

**适用场景**
- 近身肉搏中捕捉局部发力细节（拳头握紧、肌肉绷紧、脚步蹬地）
- 兵器交锋的接触瞬间（刀刃碰撞、火花飞溅、力量传导）
- 特写级别的面部反应（瞳孔收缩、汗珠滑落、咬牙）

**参数范围**
- 画面裁切：聚焦身体某个部位占画面60-90%
- 保留空间感：必须包含至少一个空间锚点（对手兵器边缘/地面/墙体）防止失去方向感
- 时长控制：0.5-1.5秒（过长会让观众失去整体空间感）

**与打斗节奏协调**
- 在攻击接触瞬间切入，捕捉冲击细节
- 在受力传导完成前切出，回到wider shot展示后果
- 禁止连续使用超过2次（会导致空间混乱）

### Whip Pan（快速摇镜）

**适用场景**
- 快速转移视线焦点（从攻击者→被攻击者）
- 表现角色突然察觉威胁（听到背后脚步声→快速转头）
- 连接两个同时发生的动作（A出招→B应对）

**参数范围**
- 旋转速度：120-240°/秒
- 旋转角度：30-180°（超过180°会让观众迷失方向）
- 运动轨迹：水平摇（最常用）/垂直摇（表现高度差）/斜向摇（跟随斜向攻击）
- 模糊处理：运动中间帧自然模糊，起止帧清晰

**与打斗节奏协调**
- 攻击发起时启动，攻击命中前完成
- 配合角色视线移动（角色转头→摄影机whip pan）
- 禁止在角色静止时使用（缺乏动机）

### 离地20厘米Low-Level Track（低位跟踪）

**适用场景**
- 地面冲刺、滑步、扫堂腿等低姿态动作
- 表现地面冲击（脚步踩裂地砖、尘土飞扬）
- 营造压迫感（从低处仰视角色，增强力量感）

**参数范围**
- 摄影机高度：离地15-30厘米
- 移动速度：匹配角色移动速度（慢走0.5m/s，冲刺3-5m/s）
- 跟随距离：保持角色在画面中占40-60%
- 倾斜角度：轻微仰角5-15°

**与打斗节奏协调**
- 在角色发起冲刺时启动跟踪
- 在接触/停止前0.3-0.5秒减速，让观众预判接触
- 跟踪中可包含地面碎石/水花/特效粒子增强速度感

### 快速环绕（Orbiting）

**适用场景**
- 展示1v多包围态势（摄影机绕主角旋转，依次带入周围敌人）
- 双人对峙中的紧张升级（环绕展示双方表情与武器）
- 终结技/大招的蓄力阶段（环绕展示能量汇聚）

**参数范围**
- 环绕半径：1.5-3米（过近会贴脸，过远会失去细节）
- 环绕速度：30-90°/秒（慢速=紧张蓄力，快速=动态展示）
- 环绕角度：60-180°（完整360°较少用，容易重复）
- 摄影机高度：与角色眼睛平齐或略高10-20cm

**与打斗节奏协调**
- 在蓄力/对峙阶段使用（动作暂停的窗口期）
- 环绕过程中至少展示2-3个关键信息点（角色表情→武器状态→敌人反应）
- 环绕结束时摄影机应facing下一个动作的发起方向

### Top Down（俯视视角）

**适用场景**
- 展示复杂阵法/战场布局（多人站位、包围圈形态）
- 范围攻击/法术扩散效果（以施法者为中心的圆形冲击波）
- 角色被击倒/坠落瞬间（俯视强化失败感）

**参数范围**
- 俯视角度：45-90°（45°=半俯视仍可见表情，90°=纯顶视仅见轮廓）
- 摄影机高度：3-8米（根据需要展示的范围调整）
- 画面覆盖范围：单人特写3x3米，小队5x5米，大场面10x10米

**与打斗节奏协调**
- 在空间关系改变时使用（包围→破围，散乱→结阵）
- 持续时间1-3秒（过长会削弱角色表演）
- 常作为段落转场（远景建立→俯视展示布局→切回近景动作）

### Dolly Zoom（推拉变焦）

**适用场景**
- 角色意识到重大威胁（察觉身后偷袭、发现致命破绽）
- 关键信息揭示（敌人真实身份、隐藏武器）
- 心理冲击时刻（盟友背叛、绝招被破解）

**参数范围**
- 焦距变化：广角35mm→长焦70mm或反向
- 同步推拉：摄影机前进速度与焦距变化同步，保持主体大小不变
- 背景压缩/扩张：背景产生视觉扭曲，营造不稳定感
- 时长：1.5-3秒（过快会让观众不适）

**与打斗节奏协调**
- 在动作暂停的瞬间使用（攻击刚停、察觉未动）
- 不在快速运动中使用（会叠加眩晕感）
- 通常单独成镜，前后镜用静态/缓慢运镜过渡

### 打斗运镜选择决策树

1. **需要展示什么信息？**
   - 局部细节 → Partial Cam
   - 整体布局 → Top Down
   - 快速反应 → Whip Pan
   - 力量冲击 → Low-Level Track
   - 空间关系 → Orbiting
   - 心理冲击 → Dolly Zoom

2. **当前打斗节奏状态？**
   - 蓄力/对峙（静态） → Orbiting / Dolly Zoom
   - 爆发攻击（动态） → Low-Level Track / Whip Pan
   - 接触瞬间（峰值） → Partial Cam
   - 战术转换（过渡） → Top Down

3. **禁止组合**
   - Whip Pan + Dolly Zoom（双重视觉扭曲）
   - 连续3次以上Partial Cam（空间迷失）
   - Orbiting中嵌套Whip Pan（运动冲突）

## 大招与特效参数化表现

### 能量碰撞参数化

**轻碰撞（试探/格挡）**
- 接触面积：5-15cm直径
- 粒子数量：20-50颗
- 扩散范围：0.3-0.8米半径
- 光强度：局部照亮，不影响整体曝光
- 声音响度：清脆短促，2-5dB高于环境音
- 持续时间：0.2-0.5秒
- 残留效果：接触点轻微焦痕/冰霜，3-5秒内淡出

**重碰撞（全力攻击/终结技对撞）**
- 接触面积：30-80cm直径
- 粒子数量：200-500颗
- 扩散范围：2-5米半径
- 光强度：瞬间过曝（0.1-0.2秒），然后快速恢复
- 冲击波：可见的球形/环形波纹向外扩张
- 声音响度：低频轰鸣，15-25dB高于环境音
- 持续时间：0.8-1.5秒（能量消散过程）
- 残留效果：地面龟裂/冰墙/焦黑，持续到镜头结束
- 环境响应：周围物体（碎石/水/布料）被冲击波推动

### 法器表现标准

**法器激活三阶段**

1. **唤醒阶段（0.3-0.8秒）**
   - 法器本体某个部位开始发光（剑刃/宝珠/符纹）
   - 光点从小到大（初始2-5cm→扩展到10-20cm）
   - 低频嗡鸣声从无到有
   - 角色握持手有可见的力量传导（手指发光/青筋浮现）

2. **聚能阶段（0.5-1.5秒）**
   - 能量在法器周围汇聚成可见形态（光环/气旋/符阵）
   - 聚能范围：近身法器0.5-1米，远程法器1-3米
   - 粒子运动方向：从周围向法器汇聚
   - 环境响应：附近物体轻微震动，灰尘/水滴/布料被吸引
   - 角色表情：专注/咬牙/瞳孔发光

3. **释放阶段（瞬间0.1-0.3秒）**
   - 聚集的能量沿确定方向爆发
   - 爆发轨迹：直线/弧线/散射（必须有明确几何形状）
   - 法器本体光芒达到峰值，然后快速回落
   - 反作用力：角色身体/衣袖向后（能量守恒）

**法器类型对照表**

| 法器类型 | 唤醒时长 | 聚能范围 | 释放形态 | 典型颜色 |
|---|---|---|---|---|
| 剑类 | 0.3-0.5s | 剑身+0.5m | 剑气弧/直线斩击波 | 青/银/金 |
| 法杖/珠 | 0.5-0.8s | 1-2m球形 | 光束/火球/冰锥 | 蓝/红/白 |
| 符箓 | 0.3-0.6s | 符纸+0.3m | 符阵展开/符光射线 | 金/红 |
| 阵法 | 0.8-1.5s | 3-5m平面 | 地面光纹/立柱光束 | 青/紫 |

### 特效叠加规范

**单镜特效层级上限**
- 主特效（大招/核心法术）：1个
- 次要特效（环境响应/余波）：2-3个
- 装饰特效（灵力外溢/武器光芒）：3-5个

**特效优先级规则**
1. 角色面部表情（最高优先级，绝不遮挡）
2. 攻击接触点/命中点（必须可见）
3. 主特效核心形态（大招主体）
4. 环境响应（地面龟裂/冲击波）
5. 装饰特效（最低优先级，必要时省略）

**特效分层描述模板**
```
前景层：角色+武器+近身粒子（清晰锐利）
中景层：法术主体+冲击波（半透明70-85%）
背景层：环境光效+远处粒子（半透明40-60%）
```

### 环境破坏持续性

**破坏等级与可见时长**

| 破坏等级 | 造成条件 | 可见范围 | 持续时长 | 视觉表现 |
|---|---|---|---|---|
| 轻度 | 试探攻击/轻功落地 | 0.5-1m | 2-5秒后淡出 | 地面浅裂纹/薄冰/轻微凹陷 |
| 中度 | 全力攻击/法术击中 | 1-3m | 镜头结束前可见 | 地砖碎裂/冰墙/焦黑/水坑 |
| 重度 | 大招/合击/爆炸 | 3-8m | 跨镜持续 | 深坑/崩塌/熔岩/冰封 |

**环境破坏连续性强制规则**
- 本镜造成的破坏，下一镜开始时必须可见
- 破坏位置必须与造成破坏的攻击位置一致
- 多次攻击的破坏应累积（第一次裂纹→第二次扩大→第三次崩塌）
- 禁止破坏凭空消失或突然出现

### 粒子衰减标准

**粒子生命周期模型**

1. **生成阶段（0.1-0.2秒）**
   - 粒子从源点爆发
   - 初始速度最快（3-8m/s）
   - 不透明度100%
   - 尺寸最大

2. **运动阶段（0.3-1.0秒）**
   - 速度逐渐衰减（每秒-30%速度）
   - 不透明度保持80-100%
   - 尺寸保持或略微缩小

3. **消散阶段（0.5-1.5秒）**
   - 速度降至初始的10-20%
   - 不透明度线性降低（100%→0%）
   - 尺寸缩小至初始的30-50%
   - 粒子颜色从亮色→暗色（火焰：橙红→暗红→黑烟）

**粒子消散禁止事项**
- 禁止粒子突然消失（必须有0.3秒以上淡出）
- 禁止粒子反向运动（除非有明确的吸力源）
- 禁止粒子静止悬浮（必须受重力影响或有上升/下降趋势）

### 特效参数化检查清单

提交前逐项核对：
1. 每个特效有明确的发源点（法器部位/角色手势/阵眼）
2. 特效运动路径已明确（起点→轨迹→终点/消散位置）
3. 特效层级已分配（前/中/背景），不遮挡优先级更高的信息
4. 能量碰撞级别已选择（轻碰撞/重碰撞），参数匹配
5. 法器激活三阶段已完整（唤醒→聚能→释放）
6. 环境破坏等级已标注，下一镜连续性已确认
7. 粒子生命周期已描述（生成→运动→消散）
8. 特效颜色与法器/角色属性一致（冰=蓝白，火=橙红，雷=紫蓝）
9. 特效声音已标注（类型/响度/触发时刻）

## 攻防动作的时序写法

用有先后的自然语言或时间段描述动作，避免把多个动作并列成同时发生。一次清晰的攻防交换通常依次写：

1. **蓄势与读取**：角色观察目标、收紧握持、转肩或调整前后脚；只保留剧情能看懂的准备动作。
2. **发动与逼近**：写清发力部位、动作方向、兵器刃尖/杆尾/环刃的路径，以及攻击对象。
3. **察觉与应对**：防守方先看到或感到攻击，按可见路径格挡、闪避、卸力或反击；明确移动幅度和落脚点。
4. **接触或擦过**：说明接触位置和角度，或说明攻击如何擦过目标；让碰撞点清晰可见。
5. **冲击反馈**：写双方身体惯性、兵器震颤、衣袖/发尾、地面尘屑或阵纹的响应，反馈方向与受力相符。
6. **收势与新局面**：写最终距离、朝向、重心、持物手、兵器位置和下一方能够采取的动作。

不是每个镜头都要完整呈现六步；拆镜后必须让前镜的末态成为后镜的首态。禁止瞬移、隔空接触、无来源受伤、受击者静止不动、攻击者未收招即跳到下一动作、同一人一镜中持物手变换而无动作交代。

## 仙器、法术与粒子细节

特效按事件链描述：法器具体部位触发 → 能量聚集 → 轮廓成形 → 沿确定路径运动 → 命中或被拦截 → 角色/地面/建筑响应 → 粒子衰减或留下状态。冰、火、雷、剑气等效果分别说明：

- **源头**：哪一块刃、晶核、符纹或手势发出；没有源头的粒子不出现。
- **轮廓和材质**：剑弧、羽刃、环形波、丝带状能流、碎晶等具体形状；透明度、边缘硬度、明暗分层和粒子尺度。
- **路径与速度**：朝向、弧线/直线/环绕的中心、速度变化和停止/命中位置。
- **接触反馈**：碰撞点、飞散方向、两种能量是否分流、目标表面反应及照亮范围。
- **消散与留痕**：尾迹如何从末端消退；是否留下冰痕、焦痕、裂纹、余光或烟尘，持续到何时。
- **信息保护**：角色脸、握持手、兵器接触点、阵眼和关键台词口型必须可读；特效不遮住故事侧重点。

特效可以华丽，但要能追踪源头和作用对象。不要用“铺满全场”“能量对波”“炫酷爆炸”代替具体事件；Niagara术语可辅助设计发射器、轨迹、尺度、生命周期与碰撞反馈，不得写成模型一定支持的参数接口。

## 表演、视线和运镜

表演必须由事件触发。例如：听见阵眼异响后先停半拍，瞳孔移向晶核，眉心收紧，握枪的手指压实；确认裂隙扩大后才转头并出声。把可见动作与可听语气分开写。微表情要能在当前景别读出；极小变化需要近景才可读，不要同时要求远景全身和不可见的细微眼部表演。

先定观众此刻需要观察谁。双人对手戏可用双人中景交代空间关系，再在关键攻防中短暂跟随主动角色；防守者的反应应保留在同一镜内或由有因果的切镜承接。运镜写起点、路径、主体、速度和停点；打斗复杂时优先稳定或短程跟拍，不为“燃”而无故环绕、快速推拉、反复特写、越轴或改变地理方向。

## 可直接填充的提示词骨架

【输出基准】16:9横屏；锁定项目风格、光色与媒介；本镜时长按已核验的当前模型能力填写。
【真实参考映射】逐张列文件和用途：角色图锁脸/妆发/服装；场景图锁固定空间；法器图锁结构；特效图锁效果来源与形态。写清每张图不控制什么。只列真实提交的输入。
【剧情目的】本镜必须让观众看懂的冲突、信息或关系变化。
【空间和起始状态】固定轴线、环境锚点、角色左右/距离/朝向/脚位/重心/持物手/视线。
【动作时序】按发生顺序写起手、发力、路径、对手察觉、格挡/闪避/接触、受力反馈和结束姿势；每一步说明动作主体。
【表演与台词】逐个写动作触发、眼神目标、微表情、呼吸和身体反应；对白原文逐字、停顿/重音/情绪及说话人。
【法术和环境反馈】明确法器发源点、效果轮廓、运动方向、接触对象、粒子反馈和衰减；环境只响应实际冲击。
【摄影机】说明景别、机位、跟随对象、移动路径/速度/停点；不需要移动时明确稳定。
【声音】环境底噪、动作声、法术声、对白分别注明触发时刻和远近层次。
【末态和下一镜】准确写左右位置、身体朝向、重心、持物状态、空间损毁、特效残留与可衔接的首动作。

模板是检查信息完整性的脚手架，不要求把栏目标题原样粘贴给模型。最终提示词使用直接、可视、无冲突的自然语言；避免同一段同时要求静止/高速、近景/完整全身、角色停留/持续移动或两种相反的运镜。

## 提交前核对

- 观众能指出当前动作由谁发起、目标是谁/什么、冲突结果是什么。
- 左右关系、世界轴、路径和落脚点明确；本镜末态与下一镜首态一致。
- 攻防先后、命中/避让、接触点和受力方向一致，不把一连串招式压成一帧结果。
- 法器使用者、握持手、特效源头和移动方向始终对应。
- 表情与台词由可见事件触发，台词逐字一致，声音与动作时间对齐。
- 运镜能帮助看清剧情动作，没有无目的运动或装饰性特写。
- 提示词密度来自可执行细节，不是重复形容词；高于单个视频任务可读容量时拆镜/拆段并保留状态连续性。

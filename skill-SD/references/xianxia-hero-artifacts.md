# 玄幻修仙主角武器与法器资产设计

本参考用于玄幻、修仙、仙侠项目中的主角本命武器、核心法宝和具有持续剧情作用的关键道具。普通角色/NPC装备与武打道具继续使用常规资产要求，不自动套用高复杂度。描述重点是原创轮廓、炼制结构、纹路逻辑、灵性表现、使用状态和跨视图可读性；不以“仙气、神秘、华丽、特效拉满”等抽象词替代设计。

## 1. 先分道具等级和叙事职责

在资产提示词开头写明道具等级、持有者、使用方式、剧情功能和当前阶段。名称或品阶需来自项目设定；没有设定时可以提案，但要标为创作补全，不能伪称既定世界观。

| 类型 | 设计强度 | 识别重点 |
|---|---|---|
| 普通武器/NPC制式装备 | 朴素、耐用、易批量制造 | 制式轮廓、材料、握持/携带结构、磨损 |
| 修士常用法器 | 有一项清楚的灵性结构 | 器纹、灵材、启动点和一种克制的使用效果 |
| 重要角色专属法器 | 明确的独特剪影和身份印记 | 专属形制、锻造层次、核心灵材、识别纹样、收纳与战斗状态 |
| 男女主本命法宝/命器 | 高辨识、高完成度，贯穿角色成长 | 独一轮廓、完整炼制逻辑、与功法/命格的关系、平时/蓄势/全开状态、损伤与进阶版本 |

主角本命法器不得沿用普通NPC武器的简化写法。先确定它在角色登场、交手和全开三个距离下的可辨剪影，再写实体与法术如何共同构成形体。用户说“仙气”时，转为轮廓轻重、色温、材质、纹路流向、灵气运动和光照影响；不得默认白玉、金边、蓝色光效或莲花纹。

### 2.1 形制不受现实兵器限制

先判断器物属于手持实体、御空器群、半实体灵构，还是有收束/展开两种形态的复合命器。主角级可采用分叉戟、异形长剑、环刃、悬浮剑阵、骨翼状刃组、重叠法环、器灵化身等，但必须选一个清楚的主体轮廓；不得把普通刀剑贴上发光纹路就称为本命仙器。三叉戟可写中央主刃与两侧弧刃的高差、空腔和内向/外向走势；飞剑阵可写母剑、子剑数量、排列轴线和收束点。所有漂浮部件都说明是实体碎片、能量凝形还是幻影，以及由哪个阵核维持、与主体保持何种相对位置。

现实锻造与承力只约束确实要握持、碰撞和收纳的实体部分。法术维持的断刃、空隙、悬环、反重力部件允许违反现实力学；改为说明炼器规则、稳定状态、启动条件和失效后如何落位。不能为了“可制造”把修仙命器改写成现实钢制兵器，也不能让特效遮住唯一识别形体。

## 2. 主角法器的设计签名

先用一段短句提炼三个相互支持的设计签名：

1. **形制签名**：远看一眼能认出的整体轮廓、比例、刃/杆/环结构或悬浮关系。将修长/厚重、直线/曲线、对称/偏心、完整/断裂等轴线组合成有辨识度的形。
2. **炼制签名**：材料从何而来、核心与外层如何复合、锻造/淬炼/铭刻留下什么可见证据。可以是折叠锻接、夹层异金属、陨晶嵌芯、灵木包覆、玉髓导槽、熔蚀凹纹、锤痕与淬火色，但按世界观择用，不能每件都罗列。
3. **灵性签名**：器物如何感知持有者、储存/导引/释放灵力；灵力沿什么结构运行，在启动前后发生什么变化。优先让法术效果从器物结构发出，而非给全物件套光晕。

三个签名应能从轮廓图、材质近景和启动状态中辨认。至少安排一个原创部位作为主识别点，说明其精确位置、形状、材质、与周边部件的连接以及功能。

## 3. 器物结构、炼材与锻造痕迹

### 3.1 先描述实体锚点，再描述灵构与灵光

按器型把物件拆成可见、可制造或符合本作炼器逻辑的部件。剑类至少考虑：剑尖、刃区、剑脊、凹槽/导灵槽、刃面、剑根、护手、镡心、柄茎、缠柄、剑首、鞘体、鞘口、鞘箍、悬挂点。其他器型拆成相应的功能部件，例如枪头、枪缨、杆节、法环内外环、伞骨与伞面、琴弦与共鸣腔、镜背与镜钮、印纽与印面。

说明长度/宽度/厚度关系、截面、握持与携行锚点、活动件和视觉重心。实体件说明连接与承力；御空件说明阵心、悬浮间距、相对轨道和收束方式。尺寸可以用整体比例表达，如主刃长约占展开高度七成；不要为追求精细杜撰无用的绝对尺寸。细节视图必须是主视图同一物件真实可见的部位。

按器型选择其最能识别的结构，不要把所有器型都套成“长条主体+符文+宝石”：

| 器型 | 优先交代的结构特征 |
|---|---|
| 剑/飞剑 | 刃形、剑脊与截面、剑根、护手、柄、剑鞘/御空关系；飞行时重心与姿态 |
| 刀 | 刀背厚度、刃弧、刀尖、护手、握柄和刀鞘；重心体现劈砍或快斩用途 |
| 枪/戟/三叉戟 | 主刃与侧刃高差、内外弧线、叉间留空、杆节、握持区、收束/展开状态；手持段交代受力，悬浮刃交代阵核 |
| 斧/钺 | 斧刃与斧眼、斧颈、柄芯、配重、兽面或几何装饰的铸造连接；不让装饰削弱承力结构 |
| 印/玺 | 印纽、印身、印面、边款/阵面、底部接触平面；镇压效果从印面或印纽阵核扩展 |
| 鼎/炉 | 器腹、口沿、耳、足、炉盖、气孔、内腔和承托；火候、烟气或丹光从具体开口逸出 |
| 塔/楼/玲珑器 | 层数、基座、檐角、窗孔、塔刹、收放/悬浮结构；法阵以器物中轴或层级展开 |
| 幡/旗/卷轴 | 杆/轴、幡面或卷面、系带、坠饰、纹面正反与迎风方向；阵纹投射范围和锚点 |
| 珠/环/镜 | 珠体内核与表面、环体内外轨、镜面与镜背/镜钮；核心、轨道、映照对象和投影平面 |
| 葫芦/瓶/壶 | 器腹比例、颈口、塞/盖、系绳、流口、内腔；吸纳/释放时的入口和方向 |
| 弓/弩/飞梭 | 弓臂与弓弦、机括与槽道、弹药/灵矢、梭体导流面和推进/制动结构 |
| 琴/尺/鞭/傀儡 | 弦与共鸣腔、刻度与端部、节段与连接、关节与灵线；效果由振动、节段、刻度或关节触发 |
| 剑阵/环阵/分体器 | 主体与子器数量、前后层级、阵心、轨道、静止间距、展开方向与回收位置；明确哪些轮廓是实体、哪些由灵力凝形 |

此表是检查清单，不是要求一件器物包含多种器型。武器类型和法器类型混合时，说明各结构如何拼接与协同。

### 3.2 炼材的层级与来源

主角级器物可由多种灵材复合，但需要写清材料层级和功能：

- **承力主体**：负责形体、硬度、重量与惯性，例如深海寒铁、星陨玄钢、古战场精金、灵木芯材、龙骨瓷等项目自定义材料。
- **导灵/储灵结构**：负责引导、蓄积或稳定灵力，例如沿脊灵髓、玉髓导槽、内嵌晶脉、空腔阵芯、环形灵石座。
- **表层与握持层**：刃面覆层、金属包边、柄绳、鲛革、木鞘、漆层、织物、玉饰等，说明耐磨、触感和受光差异。
- **核心灵材/器灵依托**：主晶、灵核、器灵寄居处或本命印记，注明埋入、包镶、贯穿、封存、铸合或后期开启的方式。

材料不必越多越好。每一种主材都要有颜色、纹理、表面反应和结构用途；不要把宝石清单当作炼制方案。实体材料交界处说明铸合、嵌槽、缠缚、铆接或阵纹锁合；非接触件说明灵力耦合、可见间隙及断能后的关系，避免拼贴感。

### 3.3 锻造细节与表面完成度

选择适合该器物的制作证据，并说明出现区域和强度：锤锻起伏、折叠钢层线、淬火水纹、夹钢界面、锻接焊线、冷作拉丝、錾刻、磨砺纹、熔蚀刻槽、釉化/结晶表层、灵火烧色、镶嵌边、鎏层磨损、阵纹填漆、铆接、丝缑/绳缠、包边和漆封。可选材料名包括玄铁、陨铁、沉银、铜精、寒铁、灵髓玉、灵木、兽骨、蛟鳞等架空灵材；每次按项目世界规则选用并说明颜色、纹理、用途和连接关系，不把材料名堆成清单。主角法器可以有精工与古老残痕并存，但要解释哪些是原始炼成、哪些是后续修复/战损/进阶形成。

避免通体光滑的普通钢器只加表面浮雕；避免所有位置都同样精细。刃面留出能看清材料和反光的区域，纹样沿着器物结构与受力/导灵方向布局。

纹样原型可选云雷、回纹、菱格、卷草、莲瓣、兽面、龙/凤/夔龙、山川、星宿、潮汐等，但先核对它与世界观、器物身份和具体时代/地域设定是否相容。现实器物原型只作造型或工艺参照，不声称虚构法器等同某件文物；不因“传统感”而默认给每件武器加龙纹、莲花或饕餮。

## 4. 灵纹、符箓与法阵逻辑

### 4.1 纹路要有层级和走向

建立“主纹路—分支纹路—节点/符印”的层级。主纹沿器脊、杆芯、环轨或器物中轴贯穿；支纹朝主节点汇聚或从核心向外分流；节点布置在剑根、镡心、握柄尾端、法环交点、印纽等合理部位。说明纹路是凹刻、阴刻、阳刻、嵌丝、填釉、裂隙、天然晶脉还是投影灵纹，不要把多种互斥做法混成一条。

纹样来源可以是宗门阵式、功法轨迹、持有者命纹、器灵铭文、古篆、星宿/山川/潮汐/雷火等抽象体系。除非项目明确，避免生成可读乱码汉字；可描述为不含可读文字的符号化篆纹、几何阵轨或象征刻痕。纹路需要方向、重复节奏、疏密、转折和终点，不能随机铺满表面。

### 4.2 多种纹样服务同一母题

可以组合一种主体母题和若干辅助结构，但需让它们形成同一套视觉语法。例如“山脊主线 + 云雷分支 + 三处封灵节点”，或“月相环轨 + 潮汐刻度 + 镜心阵核”。主纹负责远看识别，细纹负责近看工艺，节点负责表现启动。

辅助母题可以跨器身、护手、鞘体和挂件，但需按部件变形或截断，呈现工匠依结构布局，而非复制贴图。正反面、收纳态和释放态的纹路位置与连接关系保持一致。

## 5. 仙气与特效表现

### 5.1 区分常态、蓄势、全开

主角法器至少设计适用的状态差异。静态资产板可用同一物件的状态小图呈现，但按主要器型和生成工具布局能力控制数量，不能为了炫技挤满不清楚的格子。

- **常态/收敛态**：本体轮廓、材料和刻纹清晰；灵纹可以完全熄灭或仅有局部余辉。
- **蓄势态**：光从核心节点依次沿主纹、支纹向外传递，说明顺序、颜色、亮度变化和停止位置；实体结构仍可读。
- **全开/战斗态**：在本体基础上增加一种主效果和少量配套效果，例如刃外气刃、环绕轨迹、局部结晶、符印投影、灵焰薄层或空间折射；说明方向、范围、形状和主体/背景如何受光。
- **形态转换**：若常态与战斗态形制不同，逐段说明哪一实体件打开、哪一灵构凝成、部件数量和相对位置如何变化；各状态保留同一阵核、主材或专属纹样作为身份锚点。
- **损伤/进阶态**：只在剧情需要时添加裂纹、缺口、重新锻补、灵核暴露或新增纹路；区分实体损坏与能量效果。

### 5.2 让特效从结构中发生

每个特效回答：能量从哪里来、沿哪里走、如何成形、向哪里释放、留下何种余波。把粒子限定为有方向、有尺寸层级和疏密变化的少量流体/尘屑/光屑；灵雾要有流向和遮挡关系；光环、符阵或虚影要有几何中心、平面朝向和与器物连接的因果。说明特效亮度不淹没轮廓、纹路和主体材质。

修仙感可来自器物比例的轻逸、悬浮或御空状态、灵气流线、温润玉石与冷暖金属对照、符阵几何、尘光/雾流、灵焰/雷丝/水脉/花叶等元素，但每件法器选择与其功法对应的少量效果，不自动全加。避免只有“通体发光、仙气环绕、粒子爆炸”。

效果词库按视觉功能选择，不将所有类别叠加：

| 效果类别 | 可用表现 | 必须补充的控制信息 |
|---|---|---|
| 气息/雾流 | 薄雾、云气吞吐、灵气丝线、局部霞光、冷暖气流 | 来源、流向、浓淡、遮挡关系和覆盖范围 |
| 本体灵光 | 玉质内透、刃缘冷光、金属反射、节点呼吸光、符纹明灭 | 发光部位、颜色、亮度、常态是否可见及对实体材质的影响 |
| 元素附着 | 灵焰、霜晶、雷丝、风刃、水脉、藤蔓、星尘、暗煞 | 与功法/属性的关系、附着位置、运动方向、是否改变实体形状 |
| 轨迹与投影 | 剑气弧线、光轨、环形阵纹、符印投影、器灵虚影 | 几何中心、平面朝向、长度/半径、速度方向和消散方式 |
| 环境反馈 | 切开雾层、霜尘落下、细石悬起、地面阵纹亮起、附近布料受风 | 影响对象、范围、强弱和持续时间；资产静态图只展示有助于读懂效果的反馈 |

仙气效果可以选择“主效果一项 + 配套效果零至两项”，不是强制数量模板。每项都须能追溯到器物的灵核、阵纹、元素属性或启动动作；高亮效果不可吞没轮廓、锻造纹理和纹路走向。纯器物资产图优先呈现常态本体，激活状态只作为受控的辅助展示。

## 6. 主角法器资产图版式

资产图固定16:9横屏，版式固定为左侧完整主武器大图、右侧局部细节图。主图与细节区比例按器型选择，不使用所有武器统一尺寸：

| 器型与主要识别需求 | 左侧主图 | 右侧细节区 | 构图重点 |
|---|---:|---:|---|
| 细长型：剑、枪、戟、棍、长柄法器、弓 | 56–62% | 38–44% | 保证全长入画，柄端与尖端留出安全边距；必要时沿画面对角线完整摆放，不能截断武器轮廓 |
| 宽展/重型：斧、盾、伞、扇、宽刃、展开环阵 | 60–68% | 32–40% | 给宽幅剪影留足横向空间，展开件、伞沿、刃翼或阵环不互相遮挡 |
| 短小但结构密集：短刃、印、珠、暗器、机关法器 | 48–56% | 44–52% | 主图仍清楚交代完整形制和握持尺度，右侧提供更大局部放大以解释核心结构 |
| 多组件/浮空器群 | 54–62% | 38–46% | 左侧锁定母体、子件数量和相对轨道；右侧只放大核心连接/阵核与子件接口，不重复铺满器群 |

以上为面积区间，不是精确裁切线。先按器物的实际外接轮廓、重要细节数量和生成工具的分栏稳定性选择区间；若完整剪影仍读不清，扩大主图并删减细节窗。画面宽度以主图/细节区稳定分栏，分隔清楚，不留大片无功能空白。主图始终是第一视觉，不能被细节窗、光效或标题压过。

右侧默认放2–3个局部细节视窗，只有确有不同识别任务时才增至4个；每窗使用稳定、互不重叠的边界，不以格数填满空间。优先从以下内容择取：武器头/刃部原创结构；器身关键连接、握持或承力接口；炼材层次、锻造痕迹与纹路；阵核、灵纹节点或启动结构；一个剧情必须识别的收纳/激活状态。每个细节窗只解释一项主要信息，至少要能看清结构或材质，不混成无焦点的细节拼贴。正/背/侧视用于结构一致性时，可以作为右侧细节窗，但不可取代左侧完整主图。

对应位置可用细线、无文字的小型定位点或细节窗顺序建立映射；如果图像模型容易生成乱码，采用“右侧由上至下依次放大主图上的【部位A】【部位B】【部位C】”的文字约束，不要求画标签、编号或连接线。主图和所有细节图必须是同一件器物、同一颜色、同一部件数量与结构；细节视图只展示主图中确实存在的部分。状态差异只有对资产识别或剧情必要时才占用细节窗，完整的常态/全开变化不清楚时另做状态资产，不缩小主图硬塞。

若模型容易把多格误生成为多件物品，减少辅助图并用连续描述替代；若特效会遮挡细节，分为本体设计板和效果状态板两张图只在用户明确需要或一张图确实不可读时提出，不默认加图消耗。

## 7. 主角级提示词编译清单

提示词按以下顺序具体成稿，删去不适用项：

1. 16:9版式、资产身份ID/名称、器物等级、持有者/用途、主图和辅助视图关系。
2. 一句话设计签名：远看轮廓 + 炼材特征 + 灵性来源/功法关系。
3. 整体形制、比例、重心、边缘与关键原创部件。
4. 分部件结构和材料层级；实体件写连接、承力和握持/携带方式，御空件写阵核、轨道与间距。
5. 锻造、淬炼、修复和表面工艺分别发生在哪些部位。
6. 主纹、支纹、节点的图案语法、走向、深浅和材质实现。
7. 核心、启用条件和灵力路径；常态、蓄势、全开状态变化。
8. 特效的源头、路径、形态、方向、范围、色光及对本体/背景的影响。
9. 同一物件跨视图锁定的轮廓、部件、纹路、颜色、尺寸和状态。
10. 负向词只列具体失败风险，如无归属的额外武器、阵核/子器数量漂移、随机文字、无规则悬浮、特效遮挡、错误材质、画面格数失控；不要把设计要求的悬浮灵构列为负向。

## 9. 原创约束

按本项目设定原创武器轮廓、专属设定和纹样组合，不照搬具体作者或素材作品的完整设计。品阶、灵材、器灵和炼制法以项目世界观为准。

## 10. 设计复核与可复用边界

编写主角法器时，先检查它是否能在一眼内区别于普通兵器：只换颜色、加发光符纹、挂宝石或追加粒子，都不构成新的专属形制。至少确定一个“主剪影差异”和一个“启动后仍保留的身份锚点”；例如错位双环围绕断刃、三叉侧刃形成不闭合的月牙空腔、母剑带有固定轨道的子刃。例子只说明设计逻辑，不作为固定款式。

法器设计按角色画像反推，而不是先罗列仙侠装饰：

| 角色/功法倾向 | 可优先探索的器型语法 | 应避免的错配 |
|---|---|---|
| 清正、守护、镇守宗门 | 轴线稳定、对称或有明确镇压基座；阵纹向地面/结界展开 | 只有飘带、花瓣和轻薄装饰，缺少镇守重量 |
| 凌厉剑修、快攻 | 窄而明确的攻击轴线、分段剑脊、可读的蓄势与出鞘路径 | 多个漂浮件遮住攻击方向，剪影远看像装饰品 |
| 魔尊、反派主角、侵蚀型功法 | 不完整/偏心/倒置结构、重心压迫、裂隙或吞噬式能量路径 | 仅把正派白银器改成黑红配色，缺少形制与运行逻辑差异 |
| 灵巧、幻术、空间/时间能力 | 轨道、镜面、环阵、折叠或错层结构，指出空间锚点和作用对象 | 无支点的任意悬浮、特效发生但没有目标或作用范围 |
| 音律、医修、召灵或非近战 | 依据设定从琴、铃、印、镜、幡、灯、炉、珠、伞等非刀剑器型扩展 | 为了“像武器”硬改成长剑，抹掉角色专长 |

以上是检索方向，不是角色标签模板；最终器型由角色经历、功法、剧情用途和世界观决定。禁止因为角色是反派就默认黑红、正派就默认白金；颜色与材料必须由阵营、属性、身份、使用环境和角色性格共同解释。

### 10.1 器型探索矩阵

用户只说“仙器/法器/很强/够炫”而未指定器型时，先在提示词阶段快速比较不少于三个差异显著的方向，再给出一个最符合角色和剧情的方案。比较维度至少包括：远景剪影、持握/御空方式、核心机制、激活轮廓、与角色服装/功法的视觉呼应。不要为每个备选方案分别生图，也不要把多种器型无逻辑拼成一件。

可探索方向包括传统兵器异形化（剑、戟、枪、弓、鞭、尺、扇）、宗门法器（印、鼎、塔、幡、镜、灯、炉）、环轨/星盘/天秤式阵器、飞剑母子器群、半实体灵构、器灵显形的本体化法宝。若作品目标是高颜值3D半写实国漫，最终描述应优先保证缩小至视频画面时仍能读出主轮廓、材质对比和唯一识别部位；显微级纹样属于近景细节，不可代替中景可辨结构。

### 10.2 战斗读取测试

完成资产词前，做一次不生成图片的文字检查：

1. **静止剪影**：遮住纹样和特效，能否仅凭轮廓区分此器与常规剑/戟/印？
2. **持用关系**：握持、悬浮、召回、收纳和失手时，主体及所有子件是否有清楚的相对关系？
3. **攻击因果**：蓄能从哪里开始，经过哪条结构，作用于哪个目标，留下何种结果？
4. **镜头可读性**：主识别部位是否会被手、袖、人物脸或高亮效果挡住？远景是否仍保留基本色块与运动方向？
5. **状态连续性**：常态、蓄势、命中、收束之间哪些部件变化，哪些锚点不变？

有任一项无法回答，就补足资产设定或缩减形态，不依赖视频提示词临场发明。

### 10.3 生成图的尺度控制

法器图需要首先展示完整主件。只有核心结构靠近景难以辨认时才设置局部细节区；不要同时塞入多个备选配色、多个角色的武器、无关灵兽和场景画面。若单张16:9板容纳不了“本体结构 + 可识别特效状态”，先用主资产板锁定本体；经用户确认确有必要后，再分别制作激活状态板，不把拆图列为自动必做项。所有辅助视图都应引用同一件法器的相同结构、颜色和零件数量。

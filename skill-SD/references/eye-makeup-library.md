# 人物眼妆设计库

用于3D半写实国漫的人物资产与状态变体。眼妆不替代眼型：先按 `face-design-and-opulence.md` 锁眼裂、眼距、眼睑、眉弓与瞳色，再选择妆法。女性、男性和中性角色均可按身份化妆；不是每个角色都需要眼影或睫毛强化。

## 1. 眼周分区与成稿字段

| 分区 | 设计维度 | 常见失误 |
|---|---|---|
| 眉 | 毛流、粗细、眉头浓淡、眉峰位置、眉尾方向和眉色 | 用画上去的黑色长条代替真实眉毛 |
| 上眼睑 | 打底色、褶皱深度、眼窝/眼尾加深范围、边界软硬 | 浓色铺满至眉毛导致眼窝发脏 |
| 上眼线 | 从内眼角/瞳孔上方/眼尾起笔、粗细、贴根程度、尾端长度与方向 | 所有角色都画同款长上挑黑眼线 |
| 下眼睑 | 睫毛根部阴影、眼尾三角区、下眼线长度、留白 | 深色连成闭合黑圈导致疲惫或显老 |
| 睫毛 | 上下密度、长度、卷翘、根根分明或簇感 | 假睫毛厚片遮盖眼型，男女角色同模板 |
| 卧蚕/泪沟 | 真实隆起、低饱和阴影、点状提亮、位置与宽度 | 画成白条加黑线，或误把泪沟当卧蚕 |
| 亮点 | 内眼角、瞳孔上方、眼尾或眉骨的细小反光/珠光 | 珠光和虹膜自发光混淆，强光吞没表情 |

写出眼影色相、明度/饱和度、晕染范围、眼线色与长度、睫毛强度、下眼睑处理、眉形及与肤色的对比。镜头能否看到妆色取决于画面大小：胸像可呈现细节；远景只保留眼尾方向与整体明暗，不靠额外特写强行展示妆容。

## 2. 角色与题材组合方向

| 方向 | 可用处理 | 避免 |
|---|---|---|
| 都市清透 | 浅奶茶/灰棕眼窝、贴根棕眼线、轻微睫毛、米色小面积提亮 | 全脸磨皮、过宽卧蚕 |
| 甜妹/校园日常 | 杏桃/浅粉只在眼尾与下眼睑少量出现，棕线短而柔，睫毛轻卷 | 把成年甜美画成幼儿脸；未成年角色成人化舞台妆 |
| 都市利落/御姐 | 灰棕/玫瑰棕眼尾收束、细长眼线、清楚眉尾，适度眼窝层次 | 黑烟熏、厚假睫毛和职业老气感自动绑定 |
| 宫廷仪典 | 胭脂、赭红、茶棕或金棕与礼服色呼应；上眼尾与下眼尾有节制的色阶 | 一整片亮红盖满眼周，错把现代珠片贴成历史妆 |
| 仙门清冷 | 冷灰棕/青灰/浅烟紫薄晕染，眼尾极细线，局部微珠光 | 默认银白发配冰蓝眼影，整张脸失去血色 |
| 妖系/魔尊 | 赤棕、乌紫、灰黑或铜红集中眼尾和眼下，线条可更锐；眉眼仍保留本体结构 | 纯黑闭眼圈、发光眼球遮住表演 |
| 高武战斗 | 低脱妆风险的贴根眼线和眉形，汗湿/烟尘在剧情后加 | 战斗中妆面突然完整重置或无故换色 |
| 灵异异化 | 常态低对比；触发时仅局部眼周阴影、毛细血色或符纹反馈 | 把异常状态误写为每镜恒定的黑眼眶 |
| 舞台/COS/未来 | 可提高色彩纯度、几何边界、偏光或局部亮片，明确场合与材质 | 把舞台妆自动迁移到日常人物资产 |

上述方向可用于任何性别表达。男主眼妆可为无可见眼影、细贴根眼线、灰棕眼窝塑形，或剧情指定的红棕下眼睑；需要“邪魅”时先从眼型、视线和微表情刻画，不靠通体浓妆。

## 3. 色彩与眼型适配

暖肤与暖衣可选杏茶、铜棕、玫瑰棕、朱砂薄晕；冷肤与冷衣可选灰棕、烟紫、青灰、冷玫瑰；深肤不自动用浅白打底，可选暖铜、深梅、咖棕、旧金局部高光。用色不等于阵营，必须与角色肤色、虹膜、发色和服装分层，避免眼影与额印同色同亮度抢焦点。

圆眼强调外眼尾方向但不凭眼线改变眼球大小；狭长眼保留上眼睑留白，不画到无法辨认眼形；内双/单眼皮可用睫毛根部和眼尾三角区建立层次，避免大块眼影在睁眼时消失；深眼窝需控制暗色范围，防止疲惫。现有眼型如狐狸眼、丹凤眼仅为轮廓描述，眼妆不能把所有人复制成同一上挑角度。

## 4. 四视图、表演与状态

角色卡记录 `brow_shape / shadow_base / shadow_outer / liner_start_end / lower_lid / lash / shimmer / intensity / state`。资产板左侧胸像呈现最完整的妆面；全身视图保留可见色区和眉眼走向。正面与45度不能出现不同颜色或眼线方向；背面不显示脸但不得在后续反打中重置妆容。哭泣、脱妆、雨湿、血泪、入魔、神格激活是单独状态，写触发时间、变化部位和恢复方式。额印或眼周符纹按 `facial-markings-library.md` 登记，不能与眼影混为同一层。

句式骨架（占位，不得照抄）：`【眉形/毛流】；上眼睑【颜色、区域、边界】，眼尾【第二色与范围】；【色】眼线从【位置】贴根延至【位置】，尾端【方向/长度】；下眼睑【】，睫毛【】，局部提亮【】；常态/战斗态【变化】。` 从本库现取具体设计填入后删除空项，不把类别表整段送入模型。

# 动作、声音与剪辑执行手册

本手册补充模型无关的导演事实。最终视频提示词由当前锁定版本的编译规则转换；不要把本文件的栏目名或内部检查词直接粘进模型正文。

## 动作设计

### 把意图改成可见因果

每个主要动作至少交代：动作发起者、目标、路径、接触/避让、受力反馈、结束姿态，以及动作造成的空间或道具变化。简单动作可以合并节拍；打斗、法术和多人动作应按可理解的先后顺序拆开，避免同一时刻写互相矛盾的运动。

近战节拍推荐记录为：

1. **预备**：脚位、重心、握持与攻击方向。
2. **发动**：具体肢体或兵器沿何路径移动，速度与幅度如何。
3. **防守**：格挡、偏移、卸力、躲避或反击，明确由谁完成。
4. **接触**：接触点、双方身体位置、武器方向和可读的碰撞结果。
5. **受力**：重心、衣摆、尘土、地面或兵器如何回应；只写实际会发生的反馈。
6. **收势**：两人新的距离、朝向、持物手、平衡和是否受伤。

不是每个短镜头都要包含全部六步；整段动作链必须有起因和结果。武器轨迹要与角色左右手、站位和镜头轴线相符。多人战斗先决定谁攻击、谁防守、谁等待、谁退场，避免全员同时无目的挥动。

### 玄幻法术与特效

把特效写成有来源、有形态、有方向、有作用对象的事件：施法动作或器物触发 → 能量聚集 → 成形 → 沿路径传播 → 接触目标 → 目标/环境响应 → 能量消散或留下可见状态。注明颜色、透明度、边缘、粒子尺度、亮度、速度、覆盖范围和照亮/投影的对象；只保留帮助读懂剧情的特效层。

光必须有明确发光体和受光体。法术光若照亮脸、衣料、地面或烟尘，写清方向和反射变化。常规玉石、金属和宝石按材料自身质感呈现，不自动发光。多个特效相撞时给出空间层次和碰撞顺序，不用“能量对波”“华丽爆炸”替代物理结果。

## 声音设计

先把声音事件记在镜头/时间线上，再按实际生成能力分配到画面生成、单独音频、配音或后期轨道。区分：

- 画内对白、画外旁白/内心声、非语言人声；
- 场景底噪、环境变化、动作/碰撞/法术声、设备播放声；
- 画内音乐来源与非画内配乐；
- 音乐入点、出点、淡入淡出、跨镜桥接和静默。

声音描述至少包含声源、动作/触发、质地、距离/空间、强弱变化、持续长度和尾音。声音必须对应画面事件；例如落地声应有接触时点，门响须有开合动作。无声也可以是有意设计，但不要在提示词中重复写空泛“无任何声音”。

每个 utterance 建立稳定ID，冻结原句后不得为了口型、时长或押节奏改写。不同镜头上的文本切片应按时间拼回原句。记录发声主体、画内可见性、语气/语速、起止时间、是否重叠以及听者反应。配音试读后才可把估算时长改为实测。

## 对白与口型

画内发声时，画面应支持可见发声者和相称的嘴部运动；镜头不需要口型时可用反应镜头、背影或画外发声，并明确声源。OS/VO不等于画内对白：记录角色是否可见、嘴是否应动、声音来自叙述还是当前场景外。台词跨镜时标明句子切分和接缝，不能重复整句或丢失半句。

语气用可听见的特征表达：情绪方向、力度、音色质地、节奏/停顿。画面动作仍写身体和表情，不把“低哑、冷声、嘶吼”等声音属性写成脸部视觉事实。避免一条台词同时要求互相矛盾的语速和情绪。

## 剪辑与节奏

分镜的时间码以整集时间线为准；生成 job 的本地时间另列。交接点写出前镜末态、后镜首态、切换依据和允许变化。可以用动作匹配、视线匹配、声音桥、反应镜头、建立镜头、遮挡转场或明确时空跳切。没有叙事目的的转场不强加。

切点应落在可理解的动作/台词/信息节点。镜头时长由对白试读、动作完成、反应停留和转场空间共同决定。节奏需要快慢变化，但不要为了统一“每镜几秒”破坏表演，也不要拉长空镜补足规划时长。跨任务片段须重新说明首帧空间和动作状态，不假设模型记得前一段。

## 执行表字段

每个声音/剪辑事件可记录：`event_id, shot_id, timeline_start, timeline_end, source, category, content_or_text, level_intent, transition, diegetic, generation_owner, asset_id, status, review_note`。字段可按项目简化，但不得将计划中的声音写成已生成音轨。

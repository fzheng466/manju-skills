# 配色、服装与饰品描述库

本文件用于角色、场景与道具资产提示词。以下词汇是可组合的描述资源，不是固定调色盘、朝代考据结论或全量清单。每次只选能说明角色身份、气质、地域、情节功能和材质的项目；未说明的设计由项目设定决定，不自动补成“白衣金冠仙女”。

## 1. 配色描述方法

### 1.1 先定色彩角色

先用一句话说明色彩设计的叙事目的：显贵、亲和、冷峻、明艳、沉静、危险、神圣、世俗、年轻、历经风霜，或其他项目需要的气质。再确定主色、辅色、强调色、金属色、肤色衬托色与背景分离色。色彩不承担固定的善恶、性格或阶级含义；含义由本作规则决定。

为每个颜色落点写明：色名 + 冷暖/偏色 + 明度/饱和度倾向 + 覆盖部位/面积 + 材料表现。例如“低饱和青黛蓝用于外袍大面积，衣褶处转深，丝缎高光呈窄长冷亮带”；“朱砂只用于腰间印记和内裙露出的窄边，面积很小，哑光织物”。

65/25/10 只是一种快速起稿的估算，不是配色标准或上限。仪典服、层叠礼服、异域服装、宗门制服或剧情指定设计可以采用更多色阶与强调色；需要写清视觉顺序、出现部位和相邻关系。比例按画面实际视觉面积判断，不能把刺绣颜色误当成与整件外袍同等面积。头饰、主衣、内衬、裙摆、鞋履和背景分别核对，避免无意的色彩失控。

当角色需要建立可复用色卡时，为每个关键颜色记录：色名/色值参考、色相倾向、冷暖与底调、明度、饱和度、承担面积、落位、材质、受光后的变化、与相邻颜色的关系。色值用于团队沟通和相对区分，不要求生成模型逐像素匹配。需要精确色值时可记录 HEX、RGB 或实体布料/材质参考，并注明参考条件。

### 1.2 色彩维度

| 维度 | 可用描述 | 提示词中需落到 |
|---|---|---|
| 色相 | 红、橙、黄、黄绿、青绿、蓝、蓝紫、紫、红紫及综合色 | 具体衣层、配饰、光源或背景 |
| 冷暖 | 冷调、暖调、中性；偏蓝、偏黄、偏红、偏绿 | 皮肤、白色、灰色和金属最容易出现偏色处 |
| 明度 | 高明度、浅色、中明度、深色、近黑 | 哪些区域明亮、哪些区域承担轮廓和层次 |
| 饱和度 | 鲜明、纯度高、柔和、灰化、低饱和、局部高饱和 | 主色与强调色的强弱关系 |
| 明暗对比 | 柔和邻近、清晰分层、强明暗、局部反差 | 对比发生在哪两层或哪一处细节 |
| 面积关系 | 大面积主色、中面积辅色、小面积强调色 | 具体服装部位与大致占比 |
| 材料响应 | 吸光、漫反射、窄高光、透光、半透明、内透、金属反射 | 材质本身，不用另一种颜色词代替 |

肤色、妆色、发色、衣料染色、刺绣线色、金属、宝石、环境光应分别记录。补充底调时可写偏黄、偏红、偏青、偏灰、偏紫；补充明度时可写亮部/中间色/阴影色；补充饱和度时可写鲜艳、柔和、灰化或局部提纯。避免把光照染色误写成物体固有色。

“仙气”“贵气”“清冷”不能代替色彩选择。说明色彩如何衬脸、分层、识别身份或呼应道具。冷暖色可共存，写明主次与交界，避免模型把全图做成单色滤镜。

### 1.4 金属、宝石与透明色

金属可选亮银、旧银、银鎏金、淡金、香槟金、赤金、古金、乌金、铜金、錾花银、局部鎏金。写明金属用于冠托、簪杆、链节、扣件、滚边或垂饰；描述镜面、拉丝、錾刻、镂空、氧化、磨损及高光范围。不要把“金色”同时铺满头冠、衣料、珠链和背景光。

宝石可按颜色、透明度、切面、尺寸、镶嵌方式描述：鸽血红宝、石榴红尖晶、蓝宝、青金石、绿松石、翡翠、白玉、青玉、紫晶、珍珠、琥珀、玛瑙、水晶。具体宝石名称只在设定需要时使用；否则写颜色和材质外观即可。说明主石位置、爪托/包镶/托底、陪石数量与反光强度。

薄纱、珠母、釉彩和半透明宝石可写透光色、边缘色、叠层后加深的颜色及受光方向。区分透明、半透明、磨砂、乳浊与镜面，不要用“通透发光”代替材质。非剧情法器不自动自发光。

### 1.5 可选配色关系

- 同色渐层：同一色相由浅至深，靠材质、明度和织纹分层，适合安静、统一的设计。
- 邻近色：例如青绿、蓝绿、青蓝相邻，选一色主导，其余控制面积，适合柔和过渡。
- 冷暖对照：例如冷青主衣搭暖朱砂小饰，或暖绛主裙搭冷青玉，注明面积和视觉重心。
- 互补对照：红与青绿、橙与蓝、黄与紫。降低其中一色饱和度或缩小强调色面积，避免两色同面积互相争抢。
- 明暗对照：浅衣深发、深袍浅纹、深底浅玉；明确轮廓和脸部是否仍清楚。
- 金属/宝石点睛：先定主衣色，再选一个金属主调和一枚主石色，次级珠宝不逐件加新色。

配色关系是设计选项，不代表各色固定情绪或身份含义。若一个方案使用三种以上高饱和主色，说明各自面积、部位和视觉顺序。

### 1.6 配色方案方向起点（可替换，非角色模板）

这些是起点，不是角色模板。可替换任一颜色；先服从世界观、人物身份和剧情需要。

| 方向 | 主色/辅色/强调色示例 | 视觉重点 |
|---|---|---|
| 月白青玉 | 月白、青玉、淡金 | 清润柔和，金色只留冠托与衣缘 |
| 绛红玄金 | 深绛、墨黑、旧金 | 强对比与威仪，金纹集中在肩、腰、袖口 |
| 霜蓝银白 | 冰蓝、银白、蓝黑 | 冷冽轻透，深色用于发饰与轮廓 |
| 松绿赤金 | 松绿、暖象牙、赤金 | 沉稳华贵，以红金小件打破大面积绿 |
| 霞粉乌金 | 灰粉、乌金、藕紫 | 柔中带锋，黑金控制在冠饰和腰封 |
| 紫绀珍珠 | 绛紫、珍珠白、银灰 | 神秘高贵，紫色分明暗层而非整套纯紫 |
| 杏金朱砂 | 杏金、朱砂、茶褐 | 温暖明艳，朱砂用于内层和核心饰件 |
| 玄青珊瑚 | 玄青、珊瑚红、哑银 | 清冷底色配小面积鲜明点色 |

不得仅因角色是公主就使用白/蓝/金；不得仅因仙侠就降低饱和度。需要清冷、明艳、华贵、素雅或异域感时，分别明确色相、明度、饱和度、金属色和面积关系。角色身份不能替代配色选择，示例方案也不能成为角色类别的默认模板。**同一作品的同类角色（例如两名仙子、两名千金）不得复用同一行示例方案，也不得按"清冷→冷白蓝、明艳→暖金红"的惯例自动二选一**：至少一人的主色族、金属色与强调色应来自不同行，避免全剧配色收敛到两类固定组合。示例方案中的色名只是起点，可整行替换或跨行重组。

## 2. 服装剪影与结构词汇

服装先定时代/架空体系、身份场合、活动需求、轮廓和遮露范围；随后从内向外逐层描述。名称用作款式线索，不能单靠名词保证严格历史复原。明确朝代/制度考据时，先核对款式年代、穿着层次与礼制；架空仙侠则按本作世界规则组合并保持前后一致。

### 2.1 领、襟、肩与腰

领口可选交领右衽、对襟、立领、圆领、袒领、竖领、护领、云肩式覆盖、披领；补充领高、开口深浅、叠压方向、滚边颜色、暗纹和扣结位置。涉及特定历史样式时核验名称与时期，不将现代盘扣、交领、立领混作同一时代的默认套装。

腰部可选高腰、自然腰、低腰、宽腰封、软带、革带、叠系宫绦、玉带、暗扣束腰。写清腰线位置、收束程度、衣带从哪侧绕、结/扣在哪里、垂饰落点。束腰不能改变身体比例或遮掉行动所需结构。

肩部可用窄肩线、叠肩、云肩、披帛、披帛绕臂、短披风、长斗篷、肩甲/仪仗性肩饰。写明承重点和固定方式，避免悬浮、穿模或左右不对称但无设定依据。

### 2.2 袖型

窄袖、箭袖、收口袖、直袖、琵琶袖、垂胡袖、宽袖、广袖、垂袖、水袖、半臂、披帛式长袖、叠袖。描述袖根宽度、袖长、袖口形状、内外袖层、开衩、垂坠、活动余量和袖缘纹样。人物资产板保持双手空置，袖口自然垂落；剧情镜头需持物或行动时，再说明袖子是否收束、挽起或由另一只手提拢。

### 2.3 上衣、袍服与外层

内衣/中衣可选窄袖中衣、交领衫、抹胸/诃子式内搭、短襦、长衫；外层可选襦、袄、褙子、半臂、袍、袄裙、长衣、披风、斗篷、礼服外袍、轻纱罩衣。描述衣长、前后开衩、袖身比例、衣襟闭合、内衬露出宽度、活动时衣摆路径。

名物的时代和地区含义可能不同。把“内层/中层/外层”作为结构描述时，同时写出可见的衣片，不要只交付服装史名词列表。

### 2.4 裙、裤与下装

裙装可按设计选单片围裳、褶裙、百迭裙、间色裙、马面裙、破裙、襦裙式组合、长裙、拖尾礼裙。描述裙腰位置、裙门/裙片、褶量、前后长度、内外裙层、行走开合和裙摆重量。马面裙等有明确结构的款式写出裙门、侧褶、腰头和系带，不把它当成任意百褶长裙。

裤装可选窄腿裤、宽腿裤、束脚裤、袴式下装、裙裤式层叠；描述裆/腿部活动、裤脚和外罩层。骑乘、舞剑、步行或礼仪场合的下装结构服从动作与剧情。

### 2.5 服装面料与工艺

面料可选绫、罗、绸、缎、绢、纱、绡、绉、锦、织金、提花、刺绣绸、毛呢、皮革、毡、棉麻等视觉类别。需要历史准确时核实具体时期与用法。写出重量、垂坠、透光、褶皱尺度、表面纹理及磨损状态。

工艺可选平绣、盘金绣、打籽绣、缂丝感纹样、织金、暗纹提花、滚边、镶条、拼色、钉珠、珠绣、贴补、压褶、盘扣、镂空和包边。注明工艺对应的衣片、图案尺寸、线色、疏密及是否凸起；按分区控制密度，不要求全身每处同等重工，但玄幻修仙、仙侠、修真、古风宫廷的男主/女主，其主衣、冠饰与腰佩必须落在高密度工艺区，不得整件降为无工艺素衣。

## 3. 现代服装、鞋袜与造型方向

本节用于现代都市、校园、职场、运动、舞台/COS及当代日常角色。先锁地域/年代、年龄、季节、学校或单位着装制度、场合、人物职业与活动需求，再选款式及日常、精致、舞台化或礼仪级造型强度。在现代现实题材中，华丽和夸张是可选强度，简洁合身的制服也可以通过剪裁、配色、妆发和人物姿态形成主角辨识度；本条不适用于玄幻修仙、仙侠、修真、古风宫廷等非现实题材的男主/女主，其华丽度按 `character-archetype-wardrobe-library.md` §1.0 的题材下限执行，属默认配置。明确校服或制服是项目设定还是私服造型；不要仅凭“JK”“商务”“运动风”等标签让模型自行决定剪裁、露肤、标识和配件。现代服装按真实衣片、穿着层次、合身度、面料和使用状态描述，不套用古装的内中外袍、冠饰和玉佩结构。

### 3.1 现代男装与女装轮廓

以下是可选款式方向；性别不限制穿着选择。描述中性版型、宽松度、肩线、腰线、衣长、裤型和动作余量，避免只写“帅气/时尚/高级”。

| 场合 | 上装与外层方向 | 下装与结构重点 |
|---|---|---|
| 日常休闲 | T恤、Polo衫、衬衫、针织衫、卫衣、连帽衫、开衫、牛仔夹克、教练夹克、工装外套、风衣、短款羽绒服 | 直筒/锥形牛仔裤、休闲西裤、工装裤、束脚裤、短裤、半身裙、连衣裙；写腰头、裤脚/裙长、口袋和层搭边界 |
| 商务/通勤 | 单排或双排扣西装、成套西服、衬衫、针织内搭、西裤、马甲、风衣、大衣；注明结构化肩型、驳领、扣数、开衩与合体程度 | 西裤裤线、裙装长度、腰头、内搭露出量；领带/领结、皮带、表带和公文包按职位及场景选用，不自动给每人配全套 |
| 运动/户外 | 速干T恤、训练背心、运动内衣、拉链运动外套、连帽训练衫、球队/训练服、冲锋衣、软壳、羽绒层 | 运动短裤、紧身裤、束脚训练裤、户外长裤；说明弹力、透气网眼、拼接区、反光条、护具、拉链口袋及运动时的活动余量 |
| 校园/社团 | 已设定制服时先写制服衬衫、领型、针织背心/开衫或制服外套的实际层次与穿法；无制服时才从针织衫、衬衫、卫衣、棒球外套等选择私服；社团活动另记换装 | 制服裤/裙、百褶裙、直筒裤或运动裤按学校设定选；写版型、长度、季节层搭和校徽是否存在，不能凭“校园”自动加校徽、水手领或领结 |

### 3.2 甜系角色与整套穿搭判断

"甜妹"描述的是造型气质，不是固定年龄或单一身材。先按角色设定区分：娇小轻盈型可用较短衣长、圆润领型、明确腰线和轻量配饰；成熟甜美型可用合体针织、衬衫、伞裙或低跟鞋，减少幼态配件；活泼运动型可用卫衣/短外套、百褶裙或运动短裤；精致爱穿搭型可组合短开衫/小外套、蕾丝或荷叶边内搭、A字裙/百褶裙。鞋袜随后按制服规则、季节、活动和个人审美独立选定，平底、薄底、厚底均不由甜美气质自动决定。以上为方向，不根据"甜妹"自动推定娇小、未成年或露肤程度。

每套搭配先定一个视觉主题和一件主单品，再配鞋袜、发饰、包袋与首饰。注明裙长/裤长、腰线、露肤范围、层搭边界、配件落点和走动时的活动余量。可选轻甜学院风、复古娃娃风、软糯针织风、街头甜酷、运动甜系等方向；同一套最多选一条主方向，可用一两处辅元素，不把JK领结、洛丽塔裙撑、运动鞋和COS盔甲混成无主题拼贴。娇小体型写真实成人比例与合身剪裁；“幼态”只描述角色设定允许的脸部软组织和妆造克制，不将未成年人塑造成成人性感造型。

### 3.3 JK与洛丽塔服饰

学院制服先以项目设定的制服体系为准：西式衬衫加针织背心/开衫及制服外套、运动校服、院系礼服等可分别成立；领型、领带/领结是否存在、外套剪裁、袖口、校徽/校章是否存在、裙腰与褶量、裤型、鞋袜均须统一。JK风只是其中一种可选审美，不能替代所有学院制服。地区与学校设定优先；成人角色可以穿时装化制服，但用户要求学生制服时不擅自改成不对称时装或礼服。未成年角色按年龄与场景保持合宜穿着，不成人化呈现。

洛丽塔服饰按风格主题（甜系、古典、哥特、和风等由项目选择）、裙撑体积、上身版型、领口/袖型、腰线、裙长、裙摆层次、蕾丝/织带/印花分区、头饰和袜鞋配套描述。重点写层与层的边界、花边宽度、印花密度、蝴蝶结固定位置及布料重量；不将“洛丽塔”简单等同于超短裙、夸张蕾丝或儿童化脸妆。

甜系洛丽塔可选象牙白/浅粉/薄荷绿等低至中饱和主色，配水果、糖果、玩偶或小花印花、同主题头箍/发夹、提花或蕾丝袜、圆头玛丽珍鞋；古典洛丽塔可选灰粉、茶棕、墨绿、酒红等沉稳色，配细密织纹、窄花边、发箍/小帽与皮鞋；哥特洛丽塔可选黑/深酒红/冷白对比，明确蕾丝层次、十字/玫瑰等项目允许的装饰母题和鞋靴结构。每套只选符合角色的主题，写清裙撑与衬裙支撑、袖口和领口边饰、腰间蝴蝶结固定点以及鞋袜呼应，不以装饰数量代替剪裁设计。

### 3.4 鞋履与袜类

鞋先按制服规则、年龄、地面、步行或运动需求选功能和鞋型，再定鞋头及鞋底厚度。可选窄圆头或杏仁头平底制服皮鞋、薄底乐福鞋、简洁低帮帆布鞋、低帮运动鞋、平底玛丽珍、短靴，也可在造型需要时选厚底鞋、大圆头鞋或舞台鞋。大头、厚底、高跟均无默认优先级。写鞋头、鞋底厚度/跟高、鞋面材料、闭合方式、鞋口和磨损；口语或地区款名（如“腰子鞋”）有多种指代时，按参考图确认结构。四视图中左右脚同款且鞋底完整可见。

腿部层先在光腿、短袜、中筒袜、长袜和连裤袜之间作独立决定，再与鞋履配套；不能因裙装、清冷气质或女主身份自动选黑丝袜。光腿需写自然腿部肤色、肤理、季节和鞋口衔接；穿袜则写袜口高度、颜色、厚度、不透明度、纱线纹理及与裙摆/鞋面的交界。学院制服可按项目设定搭配光腿加平底皮鞋、白色短袜加制服皮鞋、罗纹中筒袜加帆布鞋等；黑丝、白丝、过膝袜、渔网袜也都是有着装依据或个人审美依据时才选的方案。一次只确定一种主腿部处理，不为填字段额外加袜。

袜类按覆盖范围、织法材质、色彩拓扑、袜口装饰与鞋履连接组合；下列为开放选项，不是每套造型都要用袜子。

| 维度 | 可选设计与成稿要求 |
| --- | --- |
| 覆盖范围 | 隐形船袜、踝下袜、踝袜/短白袜、堆堆袜、小腿中筒袜、膝下袜、及膝袜（袜口在膝盖下缘）、过膝袜（袜口在膝盖上方）、长筒袜（至大腿）、连裤袜、连脚或踩脚打底袜；区别及膝与过膝的位置，写两腿同高及鞋口交界。 |

### 3.5 现代发型、妆面与配件

发型与发色分别按 [人物发型结构库](hair-style-library.md) 和 [人物发色库](hair-color-library.md) 编译；本节只负责它们与现代服装、鞋袜、包袋及场合的搭配。按脸型、职业、年龄和生活习惯选择，不把流行发型平均分给所有角色。写清发夹、发箍、皮筋、耳机、眼镜、帽子如何佩戴及正侧背可见性。

#### 妆容方向

妆容必须单独写眉、底妆、眼妆、腮红、唇妆和可见肤质，并按年龄感与服装主题选方向；眼周分区按 [人物眼妆库](eye-makeup-library.md) 编译，额彩/面纹按 [脸部印花库](facial-markings-library.md) 另行锁定。不能用“甜美妆”“精致妆”代替细节。

| 方向 | 妆面描述维度 |
|---|---|
| 日常清甜 | 轻薄保留纹理的底妆；自然毛流眉；贴根细眼线或不明显眼线；米杏/浅蜜桃眼影；少量卧蚕提亮；腮红落在苹果肌并向外晕开；豆沙粉/蜜桃色润泽唇 |
| 娇俏可爱 | 柔和平眉或浅弧眉；圆润眼形靠细致睫毛和内眼角提亮呈现，不夸张放大瞳孔；鼻尖/面中少量暖粉；水润但边界清楚的珊瑚粉唇；保留角色年龄感，不默认婴儿肥、过浓卧蚕或幼儿妆 |
| 成熟甜美 | 眉峰略清晰；眼尾短而柔和的上扬线条；低饱和玫瑰棕眼影；面颊修容轻薄；唇色可选玫瑰豆沙/莓果粉，边缘细致；避免统一做成学生妆 |
| JK/校园妆 | 自然肤质与淡眉；低饱和眼影、短眼线、轻扫腮红和柔和唇色；与制服/校规设定相符；未成年角色保持日常、非成人化妆感 |
| 洛丽塔妆 | 根据甜系/古典/哥特主题调整色温与强调色；甜系可用蜜桃/玫瑰色和轻柔睫毛，古典用茶棕/干燥玫瑰色，哥特用冷灰/酒红作局部眼唇重点；底妆和腮红仍保持肌理与克制，避免把角色做成娃娃面具 |

底妆明确哑光/自然光泽/局部水光及遮瑕程度；眼妆写色区、边界、眼线长度、睫毛浓度和下眼睑处理；腮红写色相、落点、范围和饱和度；唇妆写形状修饰、颜色、边缘与光泽。不同角色可共享妆容方向但必须调整五官结构、色区和强度，避免模板化网红脸。

现代配色沿用本库第1节，但按衣物分区记录：主色落在外套/套装主体，辅色落在内搭/裤裙，强调色落在鞋带、包袋、袜口、领带或小面积图案；记录冷暖、明度、饱和度、面料响应和与肤色/背景的分离。可选中性色通勤、低饱和大地色、运动高可视撞色、单色层次、丹宁蓝配暖白、深色底配荧光小面积标识等方向，均需服从职业、品牌/队伍设定和剧情，不默认为固定模板。

现代配件按人物和用途选择：手表、眼镜、耳钉/耳环、项链、皮带、领带、丝巾、背包、托特包、公文包、运动腰包、发夹、耳机、徽章、手机壳。说明佩戴位置、材质、闭合/肩带方向、人物自身左右和与衣服的接触关系。商标、校徽、队徽、可读文字只有用户提供或剧情指定时才写入；否则使用无品牌纯色/抽象标记，避免随机乱码。

仙侠配色按所属宗门、修行属性及地景区分：玉白/青碧/哑银可显清润，玄青/朱砂/旧金可显凌厉，烟紫/灰银/冷月白可显幽玄，赭金/茶褐/墨绿可显山门古意；都要把主色落实到衣层。法术色不自动等于衣服固有色。法宝与衣饰共享一个识别母题即可，避免全身每件物品都发光。

战装先定身份、阵营、常态/战斗态与动作方式，再选袍、甲或甲袍混搭。甲袍可用柔软内衫承接肩背甲片，腰甲分片覆盖腰侧，外袍在前后开衩；轻甲突出肩、前臂、小腿的线条，重甲突出胸甲、护肩和胫甲的重量。实体甲片写材料厚薄、搭接、铰接与内衬；灵力护甲写阵核、悬浮间距、触发条件和失效后状态。披风、长发、飘带与命器运动轨迹须互不遮挡。华丽主角战装的复杂度放在头肩、胸腰、袖口/甲缘、武器挂点等识别区，其他衣片保留可读材质，不把所有区域画成同一密度的金纹。

#### 修仙战袍与铠甲的生产级描述字段

平台公开的仙侠角色案例常把角色身份、发型妆面、内层袍服、金属甲片、披风/轻纱、腰间配件、武器及四视图要求放在同一套设定里；优点是视觉信息完整，常见风险则是把装饰、甲片和特效一并堆满，导致角色剪影趋同、结构含混或不利于连续镜头复现。编写本项目资产时，应抽取字段而非复刻案例文案。

修仙角色穿战袍、战甲或铠甲时，至少逐项确定：

1. **人设与战斗任务**：身份、阵营、功法/灵根属性、近战/远程/御器/守阵职责、当前战斗状态、所需机动性。
2. **远景剪影**：肩宽与肩甲轮廓、腰线、衣摆/裙甲长度、披风或披帛外轮廓、头冠/发型与武器间距；注明对称或不对称及原因。
3. **穿着层级**：贴身内衣/护体软甲 → 中层战袍或袍裤 → 外层甲胄/披帛/披风；写清穿套顺序、连接点和覆盖边界，避免各层悬空或互相穿模。
4. **甲片分区**：胸甲/护心、肩甲、臂甲、腰甲、裙甲/战裙、护胫、手套/护腕分别说明形状、左右差异、厚度层级及固定方式。关节处写分片、叠片或软甲，不画成无法活动的一整块盔甲。
5. **功法与防护机制**：实体甲承担碰撞的区域、阵纹护盾覆盖的区域、灵力甲片/法相何时显现；写明启动源、覆盖路径、亮起次序、熄灭/受损状态。静态资产不自动添加攻击特效。
6. **材质和工艺**：织物、皮革、金属、玉/晶、骨/鳞、灵力构件落到具体部位；区分锻压、錾刻、浮雕、镶嵌、织金、刺绣、漆封、磨损与战损，不把全身统一描述成“金属光泽”。
7. **人设配色落位**：主色、辅色、强调色、金属色分别对应内层/外袍/甲片/纹样/宝石/发饰；注明面积层级、明度与饱和度、冷暖关系和受光变化。阵营色、功法属性色和角色识别色有冲突时，明确主次，不以全图滤镜代替服装配色。
8. **饰品与携行点**：发冠/额饰、面纹、护心阵核、门派印记、腰牌、命器挂点、符袋、披风扣等写明固定位置、连接方式及正背视图可见性；避免战斗中悬空、左右漂移或重复生成。
9. **正侧背可核验性**：正面展示领口、护心/胸甲、腰封和前裙甲；侧面展示甲片厚度、肩臂活动区和衣袍层数；背面展示肩甲连接、后腰固定、披风/长发路径、背甲与后裙甲。人物四视图双手空置，武器握点另由道具资产与分镜核验。左右均以角色自身为准，背视不得镜像换边。

身份、阵营与功法只提供设计依据，不直接决定颜色。反派不默认黑红，正派不默认白金；可从冰银/雾蓝、青金/玉白、玄黑/旧金/暗绯、苍青/玉白/乌银、绛红/墨黑/赤铜、深紫/冷银/幽青、骨白/灰绿/古铜等关系中选择，但需说明每种颜色落在哪个衣层或部件。

- 主色负责远景大块识别；辅色用于内层、袍摆或甲片分区；强调色限制在阵核、宝石、门派印、纹样节点等焦点。
- 金属色分别写亮金、旧金、冷银、乌银或赤铜所在部位及表面状态，不把所有甲片、扣件和刺绣统一画成高亮金色。
- 战损只落在实际受力和接触区域，且要与镜头阶段对应；基准资产不得提前带入剧情损伤。
- 激活色只出现在灵纹、护心阵核、甲片缝隙或灵力凝形区域，写明亮度、传播路径、受光物和影响范围，保持材质底色可读。
- 发型、冠饰、面纹/印记和战装可共享身份母题，但只设一处主识别区，其余部位作低密度呼应。

同一阵营通过剪影和穿着方式区分角色：指挥者可强调稳定中轴和肩胸标记；游击者强调收袖、非对称轻甲与低反光材质；护阵者强调承力腰封、护心阵和稳定下摆；远程御器者保留肩臂活动空间与明确挂载/召回点。具体设计必须服从项目设定，不将这些方向固化为职业制服。

若角色具有日常、战斗、全力激活、破甲/重伤等多个状态，单张资产板只锁一种明确状态；后续状态变体只改变设定中允许变化的部位。脸、发型、主色逻辑、甲片锚点和非剧情损伤保持稳定。剧情中的灵甲显现需与实体穿戴甲区分，并在分镜中继承其激活和消散状态。


配色不按善恶固定黑白。为每名角色从势力色、个人命器色、修行属性和场景背景中选主辅关系：主衣/主甲色约定大面积身份，内层或披帛给出第二层明度，纹样金属与灵力激活色只占局部。可用玄黑配暗赤与乌金、冰青配霜白与沉银、深紫配冷灰与赤铜、墨绿配玉白与旧金、月白配深青与晶蓝等作为起点，实际成稿必须写明各色所在部件及光照下变化。法术光源与服装染色分开，避免一层全图色滤镜吞没脸和甲片。

妆面随角色身份选择清透日常、仪典、战斗或异化状态。女性和男性都可使用低对比眼窝晕染、贴根眼线、眉骨提亮、眼尾色斑或下眼睑暗影；写颜色、边界与强度，避免一律浓烟熏或男角一律素面。额印、眼下纹、颧侧符纹、唇角裂纹、颈侧鳞纹等只选与功法相关的一处或一组，记准确落点、纹线方向、常态颜色、启动时变化和左右。战损、灰烬、血痕只出现在剧情触发后，不能混入未受伤的基准四视图。发色、束发及后脑结构依 `visual-assets.md` 的角色身份卡锁定，不能让战斗态随意换发型。

### 4.2 虚构古风宫廷：华丽礼服与常服

先建立本作的等级标记：谁能使用哪些冠形、纹样、宝石、织金面积、拖尾和佩饰数量。华丽靠剪裁层次、精细工艺、宝石组合及主次分区表达，不能靠通体金光或满身同密度刺绣。设定为架空宫廷时，可混合古风视觉语汇，但同一王朝的衣襟、冠制、扣件和等级色应自洽。

| 身份/场合 | 女性服装与妆发 | 男性服装与妆发 | 饰品结构 |
|---|---|---|---|
| 公主主角常态造型 | 架空宫廷的主角日常也需显出宗室等级：从高辨识冠饰、立体肩袖/云肩外层、宽幅多片裙摆、分区重工刺绣、成组玉石珠宝、明确腰部主饰中选至少三项，分别落在可见部位。廓形、织物与工艺承担贵气，配色不限制红金；年轻公主可用灵动发型、明亮配色和轻盈材质保留少女感 | 王爷/世子常态造型以肩线、腰封、织金裁片、冠形和成套佩玉区分宗室身份，不用普通窄袖长袍直接代替主角礼服设计 | 头面有清楚主件与辅件，腰佩固定于腰环；首饰数量和尺寸匹配等级，避免只剩一两枚小花簪和日常耳坠 |

宫廷华服可用胭脂红配香槟金和玉白、深绛配玄黑和旧金、孔雀蓝配银鎏金与珊瑚红、松绿配珍珠白与赤金、烟紫配乌金与月白、暖杏金配朱砂和茶褐。为每一色写衣层落点；金线用于领缘、肩背、袖口和裙门等视觉重点，低装饰区保留织物本身。头面可组合凤鸟/花枝冠、发钗、步摇、额坠、耳坠和璎珞；男性可组合冠梁、簪、额带、领扣、佩玉、腰链和戒指。每件说明尺寸、连接方式、垂落终点，避免四视图换边。

### 4.3 现代都市

在第3节款式库基础上，女性按角色场合组合连衣裙/半裙/裤装、针织/衬衫/短外套/风衣与鞋袜；可选清透日常、甜酷、街头、通勤、晚宴、舞台、运动等造型。裙装写腰线、裙长、褶量及行动余量；西装写肩型、驳领、腰身和衣长；不因女主有主见就自动穿职业套装。妆面分别写眉、眼、颊、唇和肤质，首饰可选耳圈、耳钉、锁骨链、叠链、戒指、腕表、发夹、胸针，说明金银色与扣件呼应。

男性也按场合成套设计：休闲可选T恤/针织、衬衫或棒球外套搭直筒牛仔裤与运动鞋；都市精英可用非成套西装外套、细针织、合身西裤和乐福鞋；正式场合用有结构的西装/大衣、衬衫、皮鞋与表；运动户外用速干层、软壳、训练裤及稳定鞋底。细写肩线、领口、袖口、裤褶、面料与穿着状态。手表、皮带、眼镜、耳钉、项链、袖扣、戒指和包袋按角色选取，不把领带、公文包和全套商务首饰默认加给男主。

现代配色可按人物衣橱延续：海军蓝/炭灰/奶油白适合克制日常；深莓红/靛蓝/暖象牙可做年轻主角识别色；橄榄绿/沙色/乌木黑偏户外；鸽灰/雾紫/银色偏冷调精致；巧克力棕/燕麦/酒红偏暖调。写明服装固有色、皮革和金属表面响应，避免用全图滤镜代替服装配色。

### 4.4 高武武侠

区分练武日常、江湖行走、门派身份和高强度交手。女性可用交领窄袖上衣、束腰、裤裙或分片裙、护腕和软底靴；需要轻功时明确裙片开合、内裤装和落地鞋底。男性可用短打、束袖长袍、半臂、护肩、革带、护胫与靴；门派高手可提高面料、刺绣和刀剑挂具等级，但不让披风、流苏遮住握柄。两者均写持武器手、拔取路径、衣摆受力及收势后的状态。

配色可依据门派与地域选择墨蓝/铁灰/旧银、赭石/麻白/深棕、绛红/玄黑/古铜、竹青/玉白/乌金等组合；泥、雨、尘和刀痕只落在真实接触区域。饰品以武器挂具、护腕扣、束发件、令牌、药囊、玉佩和护身符为主，说明固定位置和战斗中是否摇摆。高武能量纹只在功法触发时沿经脉、兵器刻纹或衣缘短暂显露，并给受光反馈，不把所有常服画成发光战甲。

### 4.5 灵异、规则怪谈与恐怖暗色风

先确定角色是普通人、调查者、仪式执行者还是受异常影响者，再给衣物明确现实用途。女性与男性都可从日常衬衣、毛衣、风衣、工装外套、制服或雨衣组合；写穿旧程度、领口扣合、袖口磨损、鞋底水迹及随身照明/证件的真实挂点。调查者装备需能行动与取用，异常状态只改变剧情触发的局部，例如湿痕、镜像错位、织物逆风、袖口灰烬，不让整套衣服无缘由破败。

暗色不是纯黑一片。可用煤黑/蓝黑/铅灰分层，旧纸白或病黄作信息点，锈红/暗朱砂作低面积危险提示，冷青绿/灰紫用于异常光和环境反射。脸、手、关键线索与背景留足明度差；黑色衣料区分粗棉、湿呢、油亮皮革、透明雨衣。首饰或随身物可选旧怀表、钥匙串、护符、念珠、胸针、耳坠、工牌、戒指；只在已定世界规则允许时加入符文、封印或超自然发光，并写触发条件与失效状态。

## 5. 纹样与装饰设计

### 5.1 母题及层级

通常先选一个主母题，再按礼制、地域、家族、宗门或剧情增加辅助母题；数量随设计复杂度决定，不设固定上限。可选：凤鸟、鸾鸟、鹤、蝶、莲、牡丹、海棠、兰、竹、梅、松、祥云、卷草、海水江崖、山石、星月、雷纹、回纹、几何纹、瑞兽、器物纹、家族徽记、宗门印记、个人信物。多个母题并用时，分配主次和衣片区域，避免所有纹样同尺寸、同亮度、同密度。某纹样若带有等级/制度意味，作品设定或考据先确认。

主母题放在最重要的一至两个区域，如胸襟、肩背、裙门、披帛端或冠心；辅助纹样用于袖口、腰封、裙缘等次级区域。说明纹样是满地、团花、折枝、连续边饰、暗纹还是局部章纹，说明朝向和重复间距。

### 5.2 图案工艺落位

凤纹可拆为冠、翎、尾羽、颈部和回旋走线；花卉可拆为花头、叶片、藤蔓和枝梗；云纹说明旋卷方向与连续边界。分别写明绣线、珠片、金属丝、织纹、印染、浮雕或镂空，避免同一图案同时被描述为刺绣、金属甲片和透明光效。

花纹与服装裁片对应：领缘沿领口走、袖缘沿袖口走、衣襟沿闭合边走、裙门围绕中心片布局、背部纹样跨缝连续。四视图中图案可见范围和方向保持一致；被遮挡的图案不需要在前视强行露出。

## 6. 饰品类别、结构与连接

饰品按“佩戴位置 → 主体 → 固定结构 → 连接件 → 垂坠终点 → 材质/颜色 → 视角可见性”描述。首饰要能佩戴和承重，发冠、链条、珠串与流苏须有明确固定点。

### 6.1 头面与发饰

可选冠、冠梁、冠翅、额饰、花钿、华胜、步摇、发钗、发簪、梳背、挑心、分心、钿花、珠花、网梳、发带、发绳、额链、珠串和飘带。词汇只表示可选结构，历史使用须按年代核验。

逐件说明：发髻/束发位置；冠底、梳齿、簪杆或发针插入点；主饰位于额前、头顶、鬓侧或后脑；链节由何处悬接；左右是否对称；步摇/流苏长度及落到肩、胸、背哪一层。正面、侧面、背面共享同一套固定结构，不镜像换边、不凭空增删簪子。
男冠可细分冠座、冠梁、束发环、簪孔、横簪、冠心、后垂链与固定发网；女冠可细分冠底、花枝、凤蝶翼片、挑心、侧钗、后脑串珠和流苏。选用重工结构时说明哪一层承重、哪一件可摆动，避免把冠、额链和飘带画成彼此不连接的悬浮件。现代发饰另可选鲨鱼夹、抓夹、丝绒发圈、宽窄发箍、发卡和头巾，标明固定处与背视位置。

### 6.2 耳饰、颈饰与胸饰

耳饰可选耳钉、耳坠、耳环、耳珰、长链坠、流苏耳饰。写耳垂/耳廓固定方式、托座、主石、链节、珠数、末端高度及动作时摆幅。

颈饰可选贴颈项圈、短项链、长链、叠链、璎珞、项圈式玉饰、锁骨链。写项链是否贴颈、落在锁骨/胸口/衣襟何处，扣合点、中心坠和链条层次。胸饰可选胸针、压襟、禁步、璎珞中心饰、衣襟坠；写明钩挂/缝附/穿链的位置，不能无固定点悬浮。
华丽礼服可按主石、陪石、珠串和金属托座分层；选用珐琅、烧蓝、花丝、錾刻、点翠视觉或贝母镶片时，写明工艺只落在饰品哪一面。现代角色可选耳骨夹、细链、吊坠、领针、领带夹、袖扣与口袋巾；领针和袖扣须与衣领、袖口的实际结构相接。

### 6.3 腰、臂、手腕与手持配件

腰饰可选宫绦、玉佩、香囊、荷包、禁步、腰链、牌饰、玉带钩、佩刀/佩剑挂具。写挂在人物自身左/右腰、带扣/挂环、垂坠长度、重量与行走时摆动，避免盖住腰封主纹样。

臂腕可选臂钏、臂环、护腕、腕镯、手串、指环、护甲。写佩戴层次、松紧、开口方向、左右手和是否遮挡袖口。人物四视图双手空置；手持物的握持手、握柄/提环/扇骨位置只在剧情道具和分镜中描述。
现代男士与中性造型还可选表盘/表带、皮带扣、戒指、手链、眼镜框、钥匙扣、斜挎包和背包；说明表戴哪只手、肩带跨哪侧、包体落点及材质。宫廷和仙侠的腰链、宫绦、禁步、香囊、令牌、佩玉需要逐件说明挂环顺序与垂坠高度。

### 6.4 足饰与鞋履

可选翘头履、弓鞋、云头履、靴、绣鞋、软底履、绑带鞋、护胫。描述鞋头轮廓、鞋面材料、鞋底高度、鞋口、绣纹和袜/裤脚的覆盖关系。侧视、背视中的鞋履结构一致；全身构图露出鞋履。

### 6.5 饰品层级与数量控制

按视觉层级划分识别主饰、次级配饰和连接/固定件。数量没有固定上限：日常装束可精简，公主礼服、册封仪典、祭礼或高阶宗门盛装可繁复叠戴。繁复设计仍需注明各层位置、尺寸、亮度、材质和承重点，让冠心、耳饰、胸饰、腰佩等主次可读；每件饰品写出佩戴结构，不把珠宝清单当作佩戴设计。

如果多个饰品抢焦点，保留最能表达身份或剧情的主件，降低其余饰品尺寸、亮度、色彩或数量。重量大的冠饰与宝石需要冠托、簪脚、底托或衣料承重点；长链不能无端悬空，玉佩要有系挂处，步摇要有可摆动连接。

## 7. 四视图统一检查

提示词写完逐项核对：

- 主色在胸像、前视、45°侧向视图和背视中落在相同衣层；不让侧背面自行变色。
- 内搭、中层、外袍、腰封、下装、披帛、鞋履的前后连接关系清楚。
- 发冠的主件、簪脚、链节、流苏和发髻固定方式跨视图一致；人物自身左右不因背视而换边。
- 纹样沿服装裁片连续，遮挡关系自然；不复制成多套冠饰或多件同款佩玉。
- 材质颜色来自染色、纤维反射、金属反光、宝石本色或光源之一，描述来源；普通物件不自行发光。
- 主饰、辅饰、强调色有明确层级；背景与肤色、浅色衣料和冠饰之间有足够分离度。

```text
【角色气质与身份】年龄感、身份、轮廓、姿态和本作身份依据。
【面容】脸型、眉眼鼻唇、肤色、妆面强度和皮肤质感。
【配色方案】色彩目的；主色/辅色/强调色/金属色；冷暖、明度、饱和度、面积比例及具体落位。
【发型与头面】发髻、发束、冠/钗/步摇的固定点、连接、左右与垂坠终点。
【服装结构】内层→中层→外层；领襟、肩、袖、腰、裙/裤、披帛、鞋履的轮廓和活动结构。
【纹样与工艺】主母题、辅助母题、图案所在裁片、刺绣/织纹/镶边工艺与疏密。
【饰品结构】头、耳、颈胸、腰、臂腕、足饰；连接点、数量、长度、材质与左右。人物四视图无手持物。
【材质与受光】丝、缎、纱、锦、金属、玉、宝石的表面反应；主辅光和明暗层次。
【跨视图锁定】面容、衣层、色位、纹样、左右挂点和首饰结构保持一致。
【负向提示】只列本资产的实际风险，例如多余视图、配色跨视角漂移、发冠悬浮、裙摆/鞋履裁切、错误左右、文字水印。
```

# 漫剧场景方向与提示词词库

本参考用于16:9横屏漫剧的场景资产和场景提示词。按项目题材选择方向，再用具体地点、年代、地域、空间关系、剧情状态替换通用词。词表是可选语言资源，不是固定美术模板；不要在一张图里堆叠互相冲突的年代、地域、材质或光源。

## 1. 场景提示词的共同骨架

每条场景提示词围绕以下信息写成完整可见的空间，而不是只给“高级、宏大、电影感、氛围感”：

1. **场景身份**：项目/场景ID、时代或科技阶段、地点功能、内外景、昼夜季节、当前剧情状态。明确哪些是项目事实，哪些是设计补全。
2. **空间几何**：空间边界、长宽高、层数、入口出口、门窗/廊道/楼梯/桥面位置、前中后景关系、主要通行路径、可见与不可见区域。需要连续走位时固定空间坐标与轴线。
3. **构图锚点**：主视觉物、固定地标、可读的前景遮挡、中景行动区、远景层次、镜头视线高度和主体留白。场景资产图以清楚展示空间为先；镜头提示词按叙事目的重新选景别与机位。
4. **建筑与陈设**：主体结构、构件尺寸/比例、固定装饰、可移动陈设、剧情道具、表面状态；说明物件在空间中的位置、朝向和相互关系。
5. **材料与工艺**：主要材质、次要材质、连接和施工痕迹、磨损/维护状态、粗糙度/反射/透光方式。用可见表面证据替代“真实高级”。
6. **色彩系统**：主色、辅助色、局部强调色、冷暖与底调、明度/饱和度、各色出现区域，以及它们与人物服装和剧情重点的分离关系。场景调色不应抹掉固有物色。
7. **光线与空气**：主要发光体、方向、高度、软硬、色温、阴影边缘、受光面、反光面、可见光束/雾尘的来源及范围。写清天气、烟、雨、雪、霾等如何影响可视距离和表面湿度。
8. **生活/事件痕迹**：使用频率留下的磨损、清洁程度、物品摆放、近期事件造成的变化。痕迹要有位置和因果，不平均铺满全场。
9. **人物可用性**：入口、站位、坐立面、遮挡物、动作空间、镜头视线、人物尺寸参照和互动对象。母场景图通常不烘焙人物，除非人群本身是场景固定构成。
10. **跨镜连续性**：固定结构和地标锁定；变化状态单列为版本。标注机位、朝向、时间、天气、灯光、损坏和临时道具差异。

### 情绪目标转成可见线索

先确定场景在本段剧情中的情绪任务，再挑2至3个互相支持的空间/光线/使用痕迹来表达；情绪词只作方向，不代替可见内容。例如“疏离”可用宽阔但空置的候车区、人物活动区之间的玻璃隔断、远处冷白顶灯；“心动”可用两人视线之间未被杂物打断的窗边桌、傍晚侧光落在桌面而不是全场铺粉色滤镜；“危机逼近”可用被逐段切断的走廊照明、通向盲区的开放门扇、地面新鲜拖痕。依据剧情选择，不把雨夜、夕阳、雾、樱花、血迹或灵异符号当成固定情绪快捷键。

构图可安排前景框景/遮挡、中景叙事主体、远景环境轮廓，但不强制三层齐全，也不默认虚化前景或加入人影、车流。若前景不承担空间层次或叙事功能，保持干净；资产基准图优先看清固定结构，镜头图再按景别与情绪安排景深。

每个场景选少量可辨识细节，优先选能说明地点、使用者或事件的元素，而不是机械凑满道具数量。细节须有明确落点及状态，例如磨亮的地铁扶手、被外卖袋压住的旧城小区门禁卡、雨伞在教室后门留下的水迹；不以“细节丰富”“电影感”代替物件和表面信息。

### 常用材质描述维度

石材写石种/色层、颗粒、风化、裂隙、凿痕、潮湿/粉化；木材写树种外观、纹理方向、拼板、榫卯/钉接、漆层、手摸磨亮处；金属写合金色、锻/铸/轧制纹、氧化、拉丝、锈迹、反射范围；玻璃写透明/磨砂/压花、厚薄、折射和污痕；织物写纤维、织法、垂坠、起球、褪色、积尘；混凝土/砖写浇筑缝、模板孔、砖缝、渗水、修补和粉尘。材质词必须落到物件或表面，不作全场统一滤镜。

### 灯光与色彩描述方式

使用“光源 → 方向/高度 → 色温/颜色 → 受光对象 → 阴影/反射结果”的顺序。例：窗外阴天漫射光从画面左侧进入，落在旧木桌和人物侧脸上，阴影边缘柔软；桌上暖色台灯只照亮桌面纸张和近处墙面。避免同时写“均匀无影”和“强烈戏剧阴影”，或同时指定互不相容的昼夜光源。

色彩用“颜色 + 底调/明度/饱和度 + 区域 + 材质响应”描述。色彩比例只作起稿工具；题材、人物服装、剧情重点和构图可要求更多色阶。HEX可用于团队记录，不保证生成像素精确。

## 2. 题材方向词库

### 2.1 现代都市

**先锁现实坐标**：城市级别、行政/商业/居住区域、季节、天气、建筑年代与维护状态、一天中的时间。现代感来自当代空间组织和真实使用痕迹，不等于玻璃幕墙、霓虹灯和雨夜的固定组合。

**外景锚点**：街道宽度与车道/人行道分隔、路口/高架/地铁口/商铺连续面、建筑退界、楼层高度、招牌尺度、树池/路灯/电箱/隔离栏、远处天际线。车辆与行人只在剧情需要时出现，并交代行驶方向、停靠位置和密度。

**室内锚点**：客厅的沙发—茶几—电视/窗户关系；办公室的工位—会议桌—玻璃隔断—出入口关系；医院/警局/商场等依功能布置服务台、候诊/排队区、功能门和导向标识。门、窗、柱、柜台、桌椅和人物可走区域须有明确相对位置。

**材料与生活痕迹**：清水混凝土、石材、金属、玻璃、复合板、墙漆、瓷砖、塑胶地板、布艺、屏幕玻璃；按场所选择。使用状态可见于地面鞋印、桌面杯印、扶手磨亮、玻璃指纹、外卖袋、整理中的文件、局部维修、空调冷凝水。只放剧情必要物，不自动铺满杂物。

**地域生活辨识度**：现代中国城市可按地点和人物生活方式选用电动车停放线、外卖取餐架、老小区晾衣杆、城中村窄巷、社区门禁、早餐铺蒸汽、地铁换乘导向等细节。此类元素是可选的地点线索，不必每个都市场景都塞入；说明其所在位置、数量或使用状态，避免标签化堆砌和无关人物抢焦点。

**色彩与光线**：办公区可选中性日光与低饱和灰/木色，家居可按角色关系选暖灯与窗外冷光，夜间商区可用招牌/车灯反射但控制色块数量。写明屏幕是否为主要光源及它照到谁/什么。

**可用表达**：通勤高峰/稀疏夜街、干燥午后/雨后潮湿路面、秩序严整/临时拥堵、有人居住的温暖细节/刚搬空的冷清感、商业繁华/旧城更新边缘。

**避免**：把所有都市背景做成赛博朋克；随机英文招牌和乱码文字；透视比例错误的高楼/街道；窗外景观与楼层不符；把同一空间家具和门窗位置随镜头改变。

### 2.2 古代宫廷

**先锁朝代/架空制度**：明确宫殿用途、仪典/居住/议政等级、建筑尺度、使用者身份和可进入区域。真实历史朝代细节需核验；架空设定标出自己的制度，不能把不同时代构件混成“泛古风”。

**外部空间锚点**：宫门、门阙、门钉/铺首（按考据）、门道、影壁、庭院、台基、丹陛/踏道、廊庑、殿身、屋顶、檐角、柱网、院落轴线、侍卫/仪仗站位。给出中轴、左右配殿、进入方向和视线终点；大殿不能只做无尺度的巨大空房。

**内部空间锚点**：御座/主位、屏风、宝座台阶、案几、香炉、帷幕、柱列、门窗、内外殿分区和侍从通路。礼仪陈设以身份和场合决定，固定陈设与当前仪典道具分开记录。

**结构、纹样与材料**：木构梁架、斗拱/铺作、柱础、榫卯、彩画、石阶、砖地、瓦面、织物帷幔、金属器皿、漆木与玉石。描述构件尺度、着色层次、彩画位置、漆面磨损、石刻风化、织物褶皱。龙凤、云纹、等级色彩和器用制度仅按项目身份/史实依据使用，不一律满殿鎏金。

**色彩与光线**：区分宫墙/木柱/屋顶/地面/织物/器皿的固有色。朱色、黛青、石绿、赭金、月白可作选项而非默认组合。日光从门窗或高窗进入，明确光束落在哪些台阶、柱面、御座和尘粒；烛火只照近处，不照亮整座宫殿。

**可用表达**：典礼前的肃穆整饬、退朝后的冷清空殿、雨打宫瓦、冬日积雪压檐、晨光穿过仪门、夜间宫灯形成间隔光斑、长期无人维护后的剥落与积尘。

**避免**：随意混用不同时代的屋顶、家具、服装配套与礼制；无支撑的超大殿堂；红金元素覆盖所有表面；重复门窗柱列造成无限长空间；错置轴线或礼仪主位。

### 2.3 玄幻修仙

**先锁世界规则**：宗门/仙府/洞天/坊市/秘境/凡人聚落/战场；所属势力、修行阶段、空间由谁营造、当前是否开启阵法。明确建筑是依山、悬空、洞窟内建、遗址改造还是天然地貌，不把所有仙境都做成白玉楼阁漂浮云海。

**先判定场景尺度**：大场景用于宗门全貌、仙界边界、山门攻防、群体阵法等需要看清势力规模和路径的戏；中场景用于殿前广场、桥、演武台、庭院等多人站位与攻防轴线；小场景用于洞府、廊下、阵眼、器物台等角色互动。尺度由当场戏的行动和信息决定，不为展示奇观把近身戏硬扩成全景。大景固定峰群、建筑群、云层/天象与入口关系；中景固定站位区、遮挡、退路和高差；小景固定门窗、桌台、触碰物与视线。三种尺度若属于同一场所，使用共同地标和路径串联，不能各自重造空间。

**仙界的非现世规则**：至少确定一项改变空间组织的超现实机制及其可见证据，例如仙力托起的峰屿与殿群、跨越断崖的云桥、灵脉牵引的环形水瀑、随阵法转动的星台、昼夜不同步的天幕。给出能量来源、作用范围、稳定边界和人如何到达；超现实建筑可以没有现实支柱，但必须有本作的灵力支撑规则与固定方位。奇观服务剧情路径和势力身份，不靠随机漂浮楼阁堆满背景。宗门山门须看得出门庭、通往主殿的路径、前后院/阶、侧翼殿阁或塔楼及与山势的关系，不以一座孤立石牌坊代表整个仙门。

**自然与建筑锚点**：峰体、崖壁、云海高度、山门、石阶、飞桥、栈道、瀑布、水潭、洞口、灵田、药圃、石碑、阵柱、楼阁、塔、殿宇、洞府门、禁制边界。标注空间高差、连接路径、悬空支撑/御空逻辑、远近山体尺度和人物可落脚区域。

**斗法调度**：在中/大场景标出入场口、守方阵位、阵眼、可破坏结构、撤退路径、制高点与双方交手的实际距离。先固定谁从何处入场、何处落脚、技能沿哪条线作用于哪一物；战斗状态图只改阵纹亮灭、结构损毁、烟尘和天气等事件变量，保留山体、宫殿群、台阶与方位。大范围法术可改变天象和空间，但须在状态版本中记录起因、边界和恢复/毁损结果。

**灵性结构**：聚灵阵/护山阵的阵心、阵线、节点、边界、启动部件和投射平面；灵泉/灵脉的源头、流向、显露范围；仙植/灵矿/法器的发光源和受光面。特效必须依附具体源头，普通石、木、玉不自行发光。

**建筑与材质**：因势就山的石构、木构殿宇、铁索桥、玉石镶嵌、铜制阵件、灵木梁柱、琉璃瓦、古旧砖石、苔藓与藤蔓。区分人工修建与自然侵蚀；新修仙府、古宗门遗迹、临时战场的维护状态不同。

**色彩与光线**：选择宗门/地域色彩系统，例如苍青岩壁配暖金灯火、朱砂阵纹配冷白雪雾、深紫夜空配翠绿灵泉；明确颜色来源及面积。云雾写高度、流向和透光层；月光/日光、灵阵光、火焰光分别指向不同受体。

**可用表达**：山门初启时阵纹由门额向两侧山壁传亮；灵泉在洞窟底部反射岩顶钟乳；雷劫云层压低远峰，闪电短暂照出崖阶轮廓；秘境入口折叠山壁与外部空间形成清晰边界。

**避免**：把楼阁、瀑布、云海、莲花、符文、光柱一次堆满；超现实建筑无能量规则或通行路线；雾遮掉关键地标；法阵无边界无节点；灵光不照亮环境却强称体积光；只有景观全貌而没有本场戏可用的站位与进退空间。

### 2.4 武侠江湖

**先锁地域与江湖身份**：城镇客栈、镖局、驿站、茶棚、山道、渡口、门派、义庄、牢狱、擂台、边塞关隘等；结合气候、交通、经济和势力关系决定建筑与陈设。武侠场景以人间可用空间为基础，奇观来自地形、险要和行动设计，不自动仙境化。

**空间锚点**：客栈柜台—酒桌—楼梯—后门；院落正厅—练武场—兵器架—侧门；山道弯折—崖边—遮蔽物—退路；渡口栈桥—船只—系缆桩—候船区。门窗、桌椅、梁柱、屏风、灶台和可翻越物需有明确位置，便于交代打斗与追逐路径。

**材料与使用痕迹**：粗木梁柱、旧砖墙、夯土、石板路、纸窗、竹帘、麻布、皮革、铁器、油灯、陶罐；出现方式服从地域与经济。刀痕、桌面缺口、修补木板、烟熏梁顶、泥脚印、酒渍、雨水从瓦缝滴落等痕迹应和剧情对应。

**色彩与光线**：木色、烟灰、褪色布幌、土红、青石、茶褐、冷月色等按场所取用。白日门窗光形成条状亮面；油灯/烛光只在近处形成暖色小光池；雨夜路面反光控制在实际湿润区域。

**可用表达**：酒客散尽后的客栈、晨雾中的山道、边镇风沙磨蚀的旗幡、夜渡船灯映水、门派练武场留下的脚印和兵器划痕。

**避免**：所有江湖空间都做破败酒馆；无行动空间的满屋桌椅；打斗路径被随机障碍堵死；人物比例与桌门窗不匹配；将古装场景混入现代灯具或不相容建筑构件。

### 2.5 末世灵异

**分开定义末世原因与灵异规则**：灾害类型（战争、疫灾、生态崩溃、能源失控等）、时间跨度、基础设施是否运行、幸存者如何使用空间；灵异现象的边界、触发条件、可观察迹象和对环境的影响。不要用“末世+恐怖”代替具体事件状态。

**空间锚点**：封锁线、避难所入口、楼梯间、防火门、断电走廊、临时医疗区、隔离室、废弃车站/医院/学校、补给点、观察窗、逃生路线、可封堵的门洞。明确安全区/危险区边界、可见出口与遮挡盲区。

**破坏状态**：玻璃破裂方向、门窗受损程度、坍塌承重结构、烟熏高度、水浸线、积灰/霉斑/血迹（只在剧情确需时）、临时加固方式、物资被取用后的空位。破坏有原因和尺度，避免每个表面同时破碎、锈蚀、烧焦和长满植物。

**灵异可视化**：影子方向与光源不一致、玻璃反射多出的人影、局部冷凝、墙面水痕逆向爬行、灯光间隔异常、雾中边界、空气折射、声音来源的空间暗示。超自然实体是否可见按故事规则决定；不可见时用可观测的环境响应表达，不任意添加鬼脸、符纸或血手印。

**色彩与光线**：低饱和灰绿、病黄荧光、锈红警示灯、冷月光、应急灯红色只作可选组合。写明灯具是否仍通电、闪烁频率/区域、光束被灰尘或雾如何散射、人物可视距离。黑暗中保留必要空间轮廓。

**可用表达**：应急灯照出刚拖过地面的水痕；封闭病区玻璃内侧凝雾，雾面有一条刚被手指划开的细线；地下通道远端的灯逐盏熄灭，出口指示仍亮；废楼藤蔓从破窗向有光处生长，内部楼梯仍可通行。

**避免**：无理由全场血迹和尸体；灵异现象无触发逻辑；过黑导致空间不可读；灾害状态跨镜无故变化；视觉噪点与漂浮粒子代替可辨空间锚点。

### 2.6 校园言情

**先锁教育阶段、地域与季节**：中学/大学/寄宿学校/艺校/职业校园，校规与活动方式不同；制服/校服只按故事设定，人物年龄须清楚。现代校园不自动添加日韩制服或樱花元素。

**校园外景锚点**：校门、门卫室、公告栏、主教学楼、连廊、操场、看台、跑道、树荫、食堂入口、自行车棚、湖边/天台（确认安全与可达性）、校车/公交站。标明从校门到关键地点的路径、可见楼层、树木季节与人物停留区域。

**室内锚点**：教室黑板/屏幕—讲台—课桌列—窗户—后门；图书馆书架—阅览桌—服务台—安静区；社团教室器材/作品—储物柜—出入口；食堂取餐线—餐桌区—回收处。人物互动需要明确桌间距离、可坐位置和视线方向。

**材质与生活细节**：粉笔灰、擦拭不均的黑板、课桌划痕、窗台灰、地砖磨损、海报胶痕、书包和水杯、排练用具、雨伞滴水、运动场橡胶颗粒。布置反映角色群体和当日事件，不随机加入大量可读文字。

**色彩与光线**：日光可在课桌和地面形成清楚窗格影；傍晚教室以斜射暖光配冷色走廊；雨天窗面水珠和室内反射降低对比；运动场按晴阴天气呈现天光与地面颜色。青春感来自光线、空间和人物行动，不靠粉色滤镜或过度柔焦。

**可用表达**：放学后只剩一排未关的窗、社团活动结束的空礼堂、雨停后的连廊、考试前安静的图书馆、运动会人群将要进场的看台。

**避免**：所有校园镜头都樱花飘落/夕阳逆光；楼层、走廊和窗外空间互相矛盾；教室桌椅堵住通道；把未成年人描写成成人化亲密场景；满墙乱码海报夺焦点。

### 2.7 未来科技

**先锁科技阶段与社会用途**：近未来、成熟太空时代、赛博社会、军事设施、科研站、轨道空间站、深空飞船、人工智能城市等。区分真实可见技术、项目设定科技和纯装饰界面；不要给每个空间都加全息屏、霓虹和悬浮车。

**空间锚点**：舱段、气闸、观察窗、维护通道、能源核心、实验台、冷却管路、服务器/计算阵列、安检门、垂直交通、无人机停靠点、机械臂工作范围。说明重力方向、舱门密封、压力区/洁净区、人物通行宽度、设备检修空间和安全标识位置。

**形体语言与材料**：结构采用模块化、可维护的重复单元；金属框架、复合材料板、陶瓷隔热层、透明显示面、柔性织物、发光导轨或线缆按功能分层。写面板接缝、固定件、散热孔、磨损/维修位置和反光粗糙度，避免所有表面无缝光滑。

**界面与发光**：界面只出现在实体屏幕、透明显示层或投影面上，限定尺寸、方向、内容类别和亮度；未经确认不生成可读文案。状态灯按设备功能分色，灯光照亮邻近结构；投影需有发射器、焦平面和遮挡关系。

**色彩与光线**：按组织/功能设定有限识别色，如冷白工作光、低饱和青绿状态光、琥珀警告光、局部红色故障灯。区分工作照明、屏幕光、外部星光/城市光和应急光；金属反射保持结构可读。

**可用表达**：维护舱内只有一段检修灯亮起；观察窗之外的行星弧面映在舱壁金属上；实验室洁净区与设备区用气闸和地面标记分隔；能源故障让导轨灯按区域逐段熄灭。

**避免**：无用途的密集面板和随机代码；违反重力的物件和线缆；发光边条铺满每个轮廓；不合理的观察窗/气闸；把星空背景直接当室内光源而没有受光反馈。

## 3. 场景版本、镜头适配与复用

场景资产按“项目/地点家族 → 区域 → 四向结构基准 → 状态变体 → 机位/镜头”登记。固定基准记录不可移动的结构、入口出口、地标、材质、主光源和颜色；状态变体只改剧情造成的部分，如昼夜、天气、开灯/断电、仪典布置、战损、灵阵开启、末世污染、设备故障。不得让版本变化意外改掉门窗、楼梯、家具和建筑尺度。

漫剧剧情场景默认按 `visual-assets.md` 制作一张16:9四向结构基准板，锁定同一地点的正向、左侧向、右侧向和反向；逐格核验固定地标、入口、柱列、地面走向、光源及遮挡是否属于同一个空间。用户明确指定时单次单方向场景可登记为单视点资产，超出可见范围前再补结构。顶视/轴测关系图用于多入口、跨层、遮挡交接、追逐/打斗或四向板不能说明路径的情况。

同一场景提示词按“基准结构不变 + 当前镜头状态差异”编写。每镜说明使用的机位和看到哪些固定锚点；不要求模型凭“同一场景”自动记忆未输入的图片。提示词要给出人物尺度参照、站位、动作区和视线终点。发生场景变化时记录场景版本，并检查受影响的镜头构图与连续性。

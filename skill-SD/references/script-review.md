# 剧本诊断与修订

## 审查范围

剧本冻结对白和资产前审查；已有剧本先诊断，再决定是否修订。单场只判定当前材料可证明的因果、表演与空间事实；缺少的前情列为待核，不按剧情漏洞下结论。多集审查读取当前集、已确认设定、前集结束状态及相关台账。

用户只要求诊断时，不覆盖原稿；用户要求改写时保存原稿版本并记录改动场次、原句、改后句和原因。冻结台词或用户锁定设定若冲突，先指出冲突并提出可选方案。

## 五项检查

1. **因果、时间与信息**：逐场记录触发、人物选择、直接结果和下一场承接；核对世界规则、事件耗时、伏笔与信息来源。反转若需要此前未建立的能力、证据或援手，指出缺失前置。前情缺失则标待核。
2. **人物与关系**：检查目标、风险、阻碍、策略、主动权及信任变化。背叛、亲近、退让或转向要有可见触发和过渡；对白核对说者意图、措辞、听者理解和回应。
3. **空间与状态**：跟踪人物在场性、出入场先后、场景锚点、视线、持物手，以及关键道具、伤损、服装和环境状态的变化。只记录影响剧情理解或接镜的状态。
4. **可视听表达**：将影响剧情的心理结论落实为观众可见或可听的行动、停顿、选择、道具变化、表情或声音。不得用无信息特写和运镜代替剧情。
5. **时长与制作**：完整单集和分镜总长为90–180秒；以对白试读、动作、停顿和转场估时。核对群像、空间、资产复用和特效负荷，不用空镜填时长。

## 证据化问题单

每条意见写 `问题ID / 严重度 / 场次和证据 / 已知前提 / 观众或制作后果 / 最小修补 / 受影响范围 / 复查结果`。P0为核心因果、信息来源或人物/道具凭空出现等阻断；P1为动机过渡、关键伏笔、可视听化或真实时长承载不足；P2为不改变剧情成立性的表演和节奏打磨。只报告材料能支持的结论，同根因合并并列出影响范围。

改写后向前核对前提、向后核对结果，并复查人物知识、关系、道具、对白和集内时间。冻结后为台词建立稳定ID并传递到镜头计划；不得在模型编译时润色或删改。

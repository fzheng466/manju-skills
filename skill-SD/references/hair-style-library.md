# 人物发型结构库

用于16:9、3D半写实国漫人物四视图。先按角色身份、题材、动作方式和头饰重量选发型，再把选中的结构写成一段能独立生图的描述。发型是发际线、分区、束点、辫/髻/披发、发尾和固定件的组合；不要只给“仙女发型”“高马尾”或某款流行名称。

## 1. 必填结构字段

| 字段 | 可用描述维度 | 四视图核验 |
|---|---|---|
| 发际与分缝 | 发际高低、额角弧度、美人尖有无；中分、偏分、无明显分缝 | 胸像与45度能见发际，背面不凭空改变分线 |
| 额前 | 露额、细碎刘海、八字刘海、侧分长刘海、齐刘海、碎发层 | 不遮挡骨相和眉眼识别点 |
| 顶区 | 贴头、自然蓬松、隆起发包、编发冠、分束盘绕 | 顶高来自发束结构，不是空心头盔 |
| 颞侧与鬓发 | 贴耳、挑起、两缕垂发、耳前卷束、侧辫 | 人物自身左右明确，45度视角对应 |
| 后脑与束点 | 枕骨低束、耳上半扎、头顶高束、双侧束点、后脑盘髻 | 背视看得见发圈、簪、发网或编结承托 |
| 主体与长度 | 贴颈、齐耳、锁骨、胸口、腰、臀；直/波浪/卷，发束粗细 | 四视图发量和终点一致，长度与衣领/披风不冲突 |
| 发尾与动势 | 齐切、羽毛层、外翻、内扣、自然尖束、渐薄 | 静态资产不把单次狂风定成永久结构 |

## 2. 古风、宫廷与仙侠结构

| 结构族 | 具体可选构造 | 适用与避错 |
|---|---|---|
| 半束半披 | 顶区一束盘成小髻/高束，余发沿背中线垂落；鬓侧留两缕 | 适合修士日常；换冠、换束点会改变身份，须登记版本 |
| 高马尾 | 顶后高束，发根以冠环或布带收紧，马尾从后脑向下展开 | 剑修和打斗；后背发束不能穿透披风与法器 |
| 低马尾/低髻 | 枕骨位置收束，余发可编成长辫或盘成扁髻 | 文士、谋士、日常；注意衣领与发髻高度 |
| 双环/双髻 | 头顶两侧各自分区扭成环或髻，后发可留披束 | 灵动角色；环的数量、大小和左右固定点必须一致 |
| 单环髻/回旋髻 | 主发束围绕中央发核盘成一层或多层闭环 | 仙府仪典；需说明发核、固定簪和内外层次 |
| 编辫盘髻 | 一条或多条辫子沿头顶/后脑盘绕，尾端藏入髻底 | 华丽宫廷；不能出现无源辫子或无限叠层 |
| 云鬟/高髻 | 顶部发包形成饱满轮廓，鬓侧与后脑发束向发包汇合 | 公主、神女仪典；重冠由发包、冠托和簪脚承重 |
| 侧髻/偏心盘发 | 发量集中人物自身一侧，另一侧保留贴头线条 | 个性化造型；背视不镜像换边 |
| 分股长辫 | 三股、鱼骨或绳辫，起点、股数、松紧、发尾系物明确 | 江湖、战斗；宽袖或肩甲不能吞掉辫子路径 |
| 战斗束发 | 额前收净、鬓发固定、后发束高或编结，冠饰简化但保留识别件 | 仙侠/高武动作戏；从日常到战斗须有可拍出的整理动作或状态版本 |

男、女和中性角色都可使用上述结构；根据脸型、身份与行动选择，不默认女性复杂高髻、男性半披长发。历史名词如飞仙髻、堕马髻、双丫髻只在已核对造型与时代时使用；架空宫廷直接描述可见结构，不冒充真实礼制。

## 3. 现代都市、校园与未来结构

| 长度/结构 | 变化维度 | 适用检查 |
|---|---|---|
| 短寸、板寸、渐层短发 | 顶区长度、侧后推剪高度、鬓角形、发旋 | 现代日常/运动；不要让不同视图侧边突然变长 |
| 偏分短发、纹理碎发、背头 | 分缝、刘海方向、发蜡光泽、后脑贴服程度 | 商务/都市；湿发与干发分版本 |
| 齐耳短发、波波头、狼尾、鲻鱼头 | 颈后长度、耳侧层次、发尾密度 | 青年角色；名称必须补可见剪裁 |
| 锁骨层次、中长C卷、长直发 | 层次起点、内扣/外翻、两侧修脸发束 | 都市女主常用，但须和其他角色拉开轮廓 |
| 高/低马尾、半扎、公主头、丸子头 | 束点、发圈、松紧、披发比例、后脑结构 | 校园/通勤/运动；头饰与肩带不能冲突 |
| 双马尾、双辫、拳击辫、侧编发 | 分线、辫股与发尾、左右对称或偏置 | 青年、运动或舞台；按角色年龄与场合控制成熟度 |
| 自然卷、螺旋卷、波浪卷 | 卷径、从耳上/耳下开始、蓬松度、湿度影响 | 不把卷发画成均匀塑料弹簧 |
| 剃侧、局部编发、挑染束、科技发饰 | 剃发边界、编发起点、电子件固定点 | 朋克/未来；先保证日常可维持的发型轮廓 |

## 4. 头饰与动态

头饰按“固定处 → 承重点 → 可摆件 → 垂落终点”描述。冠、簪、步摇、发带、绒花、抓夹、发箍、发圈和帽子从实际发束中生长或夹住发束，不能悬在发面上。重工头面留出发际、眼眉和面纹的可见区域。战斗/奔跑另记主发束惯性方向、碎发摆幅、发饰是否牢固、散发触发点；雨湿、烧焦、断发、散髻均属于状态变体。

## 5. 成稿与验收

按“发色与根尖分布 → 发际/分缝 → 额前/鬓侧 → 顶区/后脑 → 主体长度/发尾 → 固定件 → 背视和动作状态”写入人物正向提示词。负向只列当前造型的风险，如跨视图换束点、发冠无固定件、发尾穿透衣料、同一人变成两套长度。四视图左侧胸像须露清发际和主束点，背面须验证发髻与饰品的真实连接。

## 6. 扩展发型方向

名称只用来快速选方向；成稿仍需把可见结构说清。每个造型先选**主轮廓**（头顶高度、侧面体积、背后长度），再选**构造方式**（剪裁、盘绕、编结、束点、卷度），最后加一到两个稳定识别细节。不要把所有细节库叠在同一个角色头上。

### 6.1 长发剪裁与层次

| 方向 | 结构描述重点 | 人物造型效果 |
|---|---|---|
| 一刀切长直发 | 长度终点、发尾平齐度、发面厚度、分缝和脸侧两束 | 克制、端庄、图形轮廓强；易与其他角色区分 |
| U形/弧形后摆 | 背面中间最长、两侧逐渐缩短，写清后摆弧度 | 柔和、自然，利于背视呈现长发层次 |
| V形长发尾 | 后背中央尖落、两侧斜收，标明尖端长度与层次 | 锐利、精灵感或冷艳；防止生成过度夸张长拖尾 |
| 长层次羽毛剪 | 最高层从颧骨/下颌/锁骨起，末端细束外翻或内扣 | 轻盈、有风动感；侧脸框线明确 |
| 公主切/姬发式 | 前侧齐整长块从颧骨或下颌落下，后发保持不同长度 | 强面部框线、古典或次文化感；明确前侧块是否齐下巴/至胸 |
| 狼尾/鲻鱼层次 | 头顶短层、耳侧碎层、颈后长层的长度差 | 叛逆或行动型；需定义后颈尾束数量和边界 |
| 侧分幕帘长发 | 深侧分，前层形成弧形帘束，后发顺肩或收束 | 成熟、利落；不能让左右分量无故对称 |
| 卷度组合 | 根部直、耳下松卷/大波浪/螺旋卷，说明卷径与松紧变化 | 浪漫、华丽；避免从头顶到发尾均匀弹簧卷 |

### 6.2 束发、盘发与编结

| 方向 | 构造与固定点 | 可用场合 |
|---|---|---|
| 高束长马尾 | 后脑高位束点、束根绕发或冠环、马尾长度和层次、尾端形状 | 剑修、运动、行动型；突出运动轴线 |
| 双层马尾/分段马尾 | 一处主束点加下段二次束缚，写明束环数量和间距 | 贵族、舞台或奇幻人物；用少量束饰制造有序节奏 |
| 低位丝带马尾 | 枕骨下方束点、柔软发圈/丝带、颈背发束走向 | 温柔、文静、日常角色；适合古风公主/女主 |
| 高位半扎瀑布发 | 顶区收束成小髻/马尾，其余长发按外层覆盖束点 | 兼顾仪式感和长发轮廓；后视写清固定件露出程度 |
| 双侧对称编辫 | 两侧从太阳穴/耳上起编，股数、贴头长度、终止位置一致 | 少女、仪典、游牧/奇幻造型；左右结构精确对应 |
| 单侧瀑布辫 | 一侧贴头编结并将尾束并入披发，另一侧保留主脸框线 | 非对称、浪漫或精灵感；标明人物自身左右 |
| 鱼骨/绳索辫 | 股数、松紧、编纹粗细、起点与收尾环固定 | 仙侠、航海、野外行动；避免模型把纹理画成饰品而非头发 |
| 环绕冠辫 | 一条辫沿前额/头顶/后脑绕行，尾端在何处收进发髻 | 仪典与华丽角色；辫子是头发结构，冠饰另写 |
| 交叠发髻 | 先分出几股，再交叉绕过发核固定；写发核位置和簪脚方向 | 宫廷、仙府盛装；用可见层数控制繁复度 |
| 多节点盘绕长发 | 发束沿头顶和后脑连续盘绕成环/花瓣/结绳形，但保持单一可追踪发束路线 | 神女/高位角色；必须写明起点、绕行顺序、锚点和终点，避免无源发环 |
| 松散云髻 | 后脑体积松蓬，由内层发网/簪脚承托，鬓发柔软落下 | 文静、温柔、古风女主；冠饰重量落在发髻结构上 |
| 战斗辫髻 | 贴头编发收束到后脑/头顶，尾端藏入髻或固定于肩背 | 长发战斗角色；减少松散束缠绕武器与护甲的风险 |

### 6.3 刘海与面部框线组合

- **轻薄空气刘海**：额头可见度、刘海束数与两侧延伸长度明确；避免遮眉遮眼。
- **八字/幕帘刘海**：中间分缝，向两侧弯落；写结束在颧骨、下颌或锁骨的位置。
- **眉上短刘海**：整齐或碎剪边界、露额比例、与头顶轮廓关系明确；适合强个性，勿自动幼态化。
- **偏分斜刘海**：起分侧、跨额方向、长端是否并入鬓发；四视图人物自身左右一致。
- **无刘海露额**：露出发际、额头宽度和眉弓，适合显露冠饰或面部印记。
- **长鬓发/脸框束**：每侧束数、起点、贴脸或外翻弧线、终点、卷度；标注是否遮耳饰、面纹和下颌角。
- **双层脸框**：外层较短落于颧骨/下颌，内层更长至胸口；两束起点不同，不能误生成成一刀切齐发。

刘海和脸框发束会显著改变脸型观感。若需要明确脸宽或下颌线，胸像至少露出一侧完整颧颌轮廓；不要用两片厚发束把脸遮窄后再要求模型准确展示骨相。

### 6.4 仙侠、宫廷与角色身份的组合方向

| 人物气质/职责 | 可组合轮廓 | 需避免的固定模板 |
|---|---|---|
| 文静公主/温柔女主 | 中低盘髻或低位半扎 + 轻薄侧分刘海 + 背部柔顺长发 + 少量垂饰 | 过高硬冠、繁复战斗马尾、把柔和等同圆脸幼态 |
| 凌厉女剑修 | 高束马尾或战斗辫髻 + 收净额前 + 侧鬓短束 + 发尾层次 | 松散长发、飘带扫过剑路、发饰遮住眉眼 |
| 高阶仙门女修 | 低/中盘髻 + 环绕冠辫或单侧编结 + 发冠固定于发髻承重点 | 满头无锚点珠链、盘发遮住发冠结构 |
| 妖/魔/异化角色 | 偏心发髻、断续辫束、异长发尾或一侧剃/束发 | 只用黑红发色表达反派、随机破碎发束 |
| 贵公子/王族男性 | 半束长发、后脑低髻/高冠、整洁侧分或窄长鬓发 | 所有人统一银白半披长发、用头冠取代头发结构 |
| 少年/清爽角色 | 轻薄碎刘海、短层次、半扎或简洁束发 | 大量厚重装饰造成成熟年龄感错位 |

以上组合只用于启动设计判断。年龄、性格、文化/门派、面部轮廓和行动需求优先于性别套路。

### 6.5 3D半写实发丝的形体信息

发型结构需要能被3D渲染读出：主发团块决定轮廓，次级发束说明分区和重量，少量细发丝提供质感。提示词可写发根蓬松度、束面宽窄、束间阴影、发丝方向、发尾分叉/尖束、卷曲半径、发束交叠、耳后遮挡、枕骨体积和发旋位置。高光沿发束曲面走，不把头发处理成塑料片、金属丝或同一粗细的平行线。

强风、腾跃、打斗时，动态发束仍从原有发根和束点延伸。飘带、步摇、发尾的运动方向应区分，避免生成成一团；资产图用静态中性状态锁定结构，动态镜头再单独指定风向、惯性、回摆与遮挡。

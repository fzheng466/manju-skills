# 多风格视觉资产提示词模块

本文件用于人物、场景、法器和武器资产。本仓库只启用 AI 漫剧3D半写实分支；源文件中的其他媒介仅作对照，不自动选择或调用。它把风格、题材、环境、资产类型拆开，调用时只组合当前任务需要的短模块。国漫只是可选风格，不能默认写入所有资产。

## 2. 组合顺序

`资产类型 → 视觉风格 → 题材身份 → 环境状态 → 构图与一致性 → 负面约束`

- 视觉风格决定渲染、材质、线条和比例。
- 题材身份决定职业、社会语境、服装、道具和叙事功能。
- 环境状态决定空间、天气、时间、光线和磨损。
- 资产类型决定四视图、场景四向板或主图加细节窗。

## 3. 风格短模块

每次选一项主风格，最多加一项材质或渲染补充。具体人物编译按 `character-prompt-style-variants.md` 对应行完整应用，保留该行之后的题材默认和可选特征说明；完整交付格式读取 `visual-assets.md`。

| 名称 | 短提示词 |
|---|---|
| 高精度半写实 | 高精度三维半写实，美型结构，真实体积，细腻材质，电影级柔光 |
| 半写实人偶 | 半写实三维，人偶般精致五官，哑光细腻肌肤，修长协调比例 |
| 次世代游戏美型 | 次世代游戏角色美型，清晰骨相，PBR材质，克制高光，实时渲染质感 |
| 电影级写实奇幻 | 写实奇幻三维，真实材质与磨损，体积光，空间雾气，电影级布光 |
| 风格化三维 | 风格化三维，稳定夸张轮廓，简化材质层级，明确色块和剪影 |
| 动画渲染 | 三维动画渲染，干净色块，柔和边缘光，适度卡通比例 |
| 东方幻想三维 | 东方幻想三维，传统纹样结构化转译，玉石、金属、织物分材质 |
| 科幻工业三维 | 科幻工业三维，模块化结构，硬表面材质，功能灯带，磨损分区清晰 |
| 乙游美型三维 | 乙游美型三维，干净面部，服装剪裁清楚，柔和高光，低噪背景 |
| 定格手作质感 | 三维定格动画质感，手作材料，微小不规则，可见纹理和柔和景深 |

“最终幻想式”可转译为“史诗级高精度半写实、华丽奇幻材质、电影级光影”；BJD只在需要人偶质感时加入，不作为默认。

**人物资产图口径**：人物四视图的人物资产风格以项目视觉圣经或用户明确指定为准。`character-prompt-style-variants.md` §2 提供常用风格的增减示例；上表其他风格也可用于人物、场景、道具或法器，只要与已锁定的视觉基准相容。不要把示例表误当成封闭白名单，也不要把互斥风格同时写入一条提示词。

## 4. 人物短模板（仅起稿，不是提交成稿）

```text
生成一张16:9横屏人物四视图资产板：左侧约38%为同一角色的超大正面胸像，右侧并排正面全身、人物自身左转45度全身、背面全身；全身不裁切，双手自然空置。视觉风格：【从视觉风格模块选择一项】。人物身份：【年龄/职业/社会位置/剧情功能】；骨相与五官：【脸长宽、额颧颌关系、眉眼鼻唇、肤色、稳定识别点】；妆面/面纹：【眼妆、唇色、印记；无则写无】；发型发色：【发长、分区、分缝、束点、固定方式、发根/主体/发尾颜色】；完整服装：【内层→上衣主层→外层/甲胄→腰肩腕承载→裤/裙/裙裤→袜类/腿部层→鞋履】；饰品成套：【数量、材质、人物自身左右、连接点和长度终点】；体态气质：【站姿、重心、肩颈、视线、动作速度】；环境与光线：【影棚或当前环境、主光/轮廓光/色温】。保持同一骨相、发型发色、服装和配饰；不加入文字、水印、额外头像或剧情道具。
```

该短模板只能作为起稿入口，交付前必须先建立 `character_design_record`：记录实际读取并采用的 `character-archetype-wardrobe-library.md`、`face-archetype-library.md`、`hair-style-library.md`、`hair-color-library.md`、`eye-makeup-library.md`、`palette-costume-jewelry.md` 及按需读取的 `facial-markings-library.md` 条目、版本和舍弃理由。最终提示词逐字段从记录展开，不得以“参考发型库/完整穿搭/同上”代替具体设计。

题材只填身份和服装语境：玄幻可选门派、血脉、法器权限；武侠可选门派、兵器、行旅磨损；校园可选学段、校服制度、社团、季节；都市可选职业、阶层、通勤或社交场景。末世、宫廷、娱乐圈、赛博、民俗、悬疑等同样按变量组合。若严格看衣服侧缝或背部连接，再把45度替换为90度侧面，并在记录中注明原因。

## 5. 场景短模板

```text
生成一张16:9横屏场景四向基准板：同一地点的正向、左侧向、右侧向、反向；视觉风格：【风格】。地点功能：【空间用途和叙事功能】；固定结构：【入口、出口、地标、建筑/自然构件】；尺度：【大/中/小】；材质：【主要材质】；环境状态：【时间、天气、人员密度、损坏或整洁程度】；光线：【主光源、色温、雾和阴影】。四个方向保持边界、比例、地标和光源一致，不加入随机角色、文字或水印。
```

## 6. 法器与武器短模板

```text
生成一张16:9横屏【法器/仙器/武器】资产板：左侧占【比例】展示同一件物件的完整主图，右侧展示【2–3】个真实局部细节窗。视觉风格：【风格】；用途与持有者：【功能/身份】；核心轮廓：【长度、展开方式、独特剪影】；结构：【握持处、连接件、开合件、受力点】；材质：【金属/玉石/木/皮革/晶体】；纹样与加工：【刻纹、铸造、磨损】；状态：【常态或一种必要激活状态】。细节窗只放大主图已有部位，部件数量、颜色、方向和材质完全一致，不增加第二件完整物件。
```

法器按需追加“炼材来源、灵纹层级、灵力路径、启动反馈”；普通武器不强行加入仙术特效。先锁本体，再决定是否制作激活状态图。

## 7. 环境调用

| 环境 | 人物追加 | 场景追加 | 法器/武器追加 |
|---|---|---|---|
| 影棚设定 | 中性姿态、材质可读、空手 | 无角色、均匀背景 | 常态本体、少量细节窗 |
| 都市/校园 | 职业或学段、制服制度、生活物件 | 建筑尺度、生活痕迹、时间段 | 真实携带关系 |
| 古风/玄幻 | 门派、身份等级、服制、修行阶段 | 地貌、建筑体系、灵气来源 | 炼材、灵纹、启动逻辑 |
| 武侠/战斗 | 兵器习惯、磨损、行动服 | 路线、掩体、地面材质 | 重心、握持、刃口和伤痕 |
| 末世/灾变 | 防护、资源限制、污染状态 | 破坏层级、危险源、通行区域 | 临时改装、耐用性、功能状态 |
| 赛博/科幻 | 阵营、接口、功能服装 | 模块化建筑、灯带、信息屏 | 能源、散热、接口、硬表面 |

## 8. 生成前检查

1. 已选择风格，而不是默认写“国漫”。
2. 题材、环境和风格各自承担不同信息。
3. 人物四视图同脸、同服、同配饰且双手空置。
4. 场景有固定锚点和方向关系。
5. 法器/武器先有完整轮廓，再有局部细节和状态。
6. 删除与当前资产无关的长词、英文软件名和平台口号。

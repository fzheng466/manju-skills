# 故事开发与剧本冻结

## 按需求范围进入

- 单句、单镜、单条资产提示词或局部修改：只处理该单元，使用最小必要上下文；不要先建完整项目档案。
- 完整单集或剧本会诊：进入相关步骤，不强行要求重做用户已完成的故事开发或资产。
- 从灵感/小说开始的全流程：按需要依次做项目开发、分集/剧本、剧本诊断与修改、台词表演精修、资产、分镜、Seedance版本编译、生成/粗剪声音和最终审查。
- 用户要求完整流程时不得用“下一步可做”代替交付；若本轮范围只到提示词，就不声称完成生成、剪辑或配音。

常用节奏判断可在“电影式中速、短视频中高信息密度、高密度动作/强钩子、慢节奏但高信息”中选择或组合。平台节奏、前三秒任务、互动目标只有在用户给出平台/目标时才锁定；不得为了统一开场钩子、集长或镜数而改坏慢戏。

## 入口判断

- 一句构想/原创题材：先形成可验证的前提和世界规则，再写分集/剧本。
- 小说/长章节：只依据本轮实际收到的文本，建立覆盖锚点；不冒充知道未提供的后续。
- 已有剧本：先诊断并只修改用户指定范围；未经授权不重构剧情。
- 已冻结剧本/只要分镜：不改剧情、不删原台词，只将其拆为可执行视听单元。
- 多集项目：维护跨集人物/服装/关系/道具/伤损/信息状态；只先做用户要求的集数。

## 原文覆盖和开发材料

改编前把事件、信息揭露、人物选择、伏笔、反转及关键台词编号。覆盖表至少写：`source_anchor / preserved_event / episode_scene / change / rationale / fact_status`。事实状态分为原文明示、必要推断、可替换设计补全、未知。伏笔或人物关系不因镜头数缩减而消失。

原创提案以`主角想要什么 / 谁或什么阻止 / 失败代价 / 采取什么选择 / 结果变化`为主轴。世界规则必须能约束剧情事件；能力、物件或新身份不能只在反转时临时出现。

分集只在故事信息确实需要时制作。每集记录戏剧任务、主要冲突、选择/代价、收束或悬念、时长估计和来源覆盖；不预设每集必须60/90/180秒，也不强制“每三秒一个钩子”。

## 场次与剧本

每场写：场次ID、地点/区域、内外/时段、在场人物、起始状态、人物目标与阻碍、可见行动、逐字对白、信息/关系变化、情绪起点与转折、结束状态。主要情绪变化由事件、对白或人物选择触发；写清角色对外呈现的状态、实际泄露的反应和是否压住情绪，避免只贴“开心/愤怒/难过”等标签。情绪不变时不强造表情变化。镜头只能表现可见/可听事实；人物不能回应尚未知道的信息。

剧本样式：

```text
第X集｜集名｜规划时长（估算/确认）
场次 S01｜地点/区域｜内/外｜日/夜
在场：
起始状态：
情绪走向（起点→触发→变化/压制→结束）：
行动与画面：
人物名（动作｜发声方式｜语气）：原文台词。
OS/VO（发声者、画内是否可见、声音来源）：完整原文。
转折：
结束状态：
```

剧本阶段记录戏剧情绪和行为策略，不要求给每句台词编写完整微表情提示词。进入分镜后再把关键变化落实为可见信号与停留时间。

明确对白、OS、VO、画内播放设备中的台词、非语言发声。说话方式和话语内容分开；重复、停顿与没说出口的句子只有在剧情需要时保留。

剧本会诊用证据闭环：引用具体场次/原句或事件 → 说明观众可能误读及原因 → 标明严重度与最小修订方向。只报告有证据的问题；确实成立的段落直接说明成立理由，不凑问题清单。用户只要求诊断时不擅自改稿；用户要求修订时说明哪些建议已采纳以及未改动的核心因果。

对白精修按角色声纹维护差异：常用句长与词汇、称谓、句尾习惯、比喻来源、信息直率程度、冲突策略和语速停顿。潜台词用“角色当下目标/不肯明说的事/实际措辞/对方可见反应”分析。语气要有戏剧功能，区分麦克风能听到的声音质地和摄像机能看到的面部/肢体动作。

## 对白与时长

冻结后给每个语句建立稳定`utterance_id`，记录speaker、语种、完整文本、语气/音色依据、OS/VO/画内类别。分段只在语义和呼吸位置切；自动检查各镜按顺序拼接后完全匹配冻结文本。

时长以试读或实际配音为准。预估时记录语速区间、停顿、动作占用和转场预算；不要把统一字数/秒公式当作实测。超过单次模型任务长度时在语义落点拆job，台词不能通过加速硬塞。若用户要求固定时长与文本密度冲突，列出具体可行取舍。

## 诊断方式

每项意见给出“位置与原文证据 → 观众可能的误读/制作风险 → 最小改动 → 修订文本”。可以检查因果、人物动机、信息顺序、类型期待、节奏、可拍性、对白自然度和成本。没有证据不冒充专家身份或强行制造反对意见。

情绪曲线按场景转折标记压力、策略变化、释放和余波；不强制固定拍数。FACS只在需要解决的近景表演问题中使用，普通提示词优先写成可见的眉眼、嘴角、呼吸、手部和重心动作。

## 剧本冻结门

进入资产和分镜前确认：事件覆盖充分、人物所知自洽、对白无缺漏、关键信息与伏笔已定位、场次空间可拍、时长诚实标记、改编变更已记录。这里是制作门，不需要每项再向用户请求批准；仅实质分歧无法从材料判断时提问。

# Seedance 2.0 专属编译规则

版本说明：只使用 Seedance 2.0 对应的 provider 文档、输入结构和提示词；不要引用 Seedance 2.5 专属编译语法。

仅在项目已锁定 `seedance-2.0` 时读取。本文件只描述项目制作模式与提示词边界；具体 provider 的 `model_id`、字段名、输入上传位置、时长和费用须按本次服务文档/schema核实。一个项目和 job 不能混入 2.5 或 MiniMax H3 语法。

## 制作模式

本项目按本次 Seedance 2.0 provider 的已核验输入schema选择一种模式。以下是制作分类，不是 API 字段；不同接入的可选模式可能不同：

- `text_only`：没有图像、视频、音频参考输入。
- `reference_image`：一个或多个当前2.0接入明确支持的图像参考；每项登记用途、继承属性和不继承属性。
- `multimodal_reference`：仅当当前2.0接入明确支持时，按其2.0文档使用图像/视频/音频参考。逐项记录真实输入槽位；不套用2.5的标记、字段或素材额度。
- `frame_anchored`：仅当当前2.0接入明确提供首帧/尾帧控制时使用其2.0专用输入结构；首尾约束和普通参考是否能共存，以该接入文档为准，不能猜测。

这些名称是本项目的分类，不是已验证的 API 字段。Seedance 2.0的多模态参考、首尾帧、参考音频、声音生成、故事板输入、续写或视频编辑能力必须分别以当前2.0 provider 文档/schema为证；可用模式不应被旧快照预先禁用。不得使用2.5专属的字段或提示词标记，即使两版功能名称相似也要分别编译和验证。

当前工作副本没有足以固定 Seedance 2.0 全部 provider 时长范围的官方 schema 证据。每次提交前核对精确 model ID 的最短/最长时长、画幅、输入限制与费用；4–15秒仅作为便于剪辑的默认片段规划区间，不是模型硬限制。超出当前接入范围时按事件和动作相位拆段，不切换到2.5规避限制。

在动作复杂度上，2.0每个连续镜头优先一个主要动作和一条简单摄影机移动；避免同一镜内多次转向、升降、环绕和反向变焦的复合指令。若需要明确剪切而当前服务不能可靠执行硬切，把镜头拆成独立job并后期剪接。冲击力靠接触前的蓄势、清楚的接触点与受力结果表达，不写依赖2.5声音/画面通道的顿挫标记。2.0镜头仍须遵守通用分镜的人景比例、观察视点、焦点转移和切镜理由；单镜避免无因果复合运镜，不等于整段只能使用一种景别。玄幻仙侠武打按逐镜细节提示词执行，不以模型具备故事板相关能力作为默认采用多格图的理由。

本文件不把旧适配资料中的单图限制或媒体政策写成2.0永久能力。素材类型、数量、尺寸、上传政策、首尾帧和音频通道均需在生成前按当前2.0 provider核对。项目内部资产ID不等于平台输入槽位；只有真实上传且通过审核的素材才能在提示词中声明为已绑定。

社区教程页还将片段延长、视频拼接、局部修改和首尾帧列为2.0工作方向；它们不是所有2.0接入共有的操作。若当前2.0 provider确实提供某项功能，按2.0自己的输入、范围和费用规则单独建job；若不支持，回到已审核片段的后期剪辑，不引用2.5字段替代。

## 提示词组织

一个job写成自包含自然语言，明确：

1. **画面基准**：16:9横屏、项目已确认的媒介/渲染风格、主辅色、材质响应、光源方向和空间空气感。未定风格时先按题材提出合适方向，不默认国漫CG或写实。
2. **可见主体**：当前角色身份、参考图控制范围、服饰/道具状态、画面位置和朝向。不可只写“按角色卡”。
3. **空间与构图**：景别、机位高低/方向、前中后景锚点、人物相对位置、视线与留白。
4. **动作和摄影**：动作发起者、目标、路径、接触反馈、结束姿态；摄像机从何处沿什么路径移动到哪里。
5. **表演和对白**：可见的眼神/呼吸/手部/重心变化；原句逐字保留，语气用自然语言说明，不把台词翻译成镜头指令。
6. **声音意图**：需要的对白、动作声、环境声及情绪方向写清楚。只有当前2.0接入文档明确支持并且本job选择使用时，才按2.0的声音语法/音频输入方式编译；不要照抄2.5通道标记或虚构独立音频槽。
7. **段缝状态**：跨job连续时，写清首帧人物站位/姿态/持物、场景状态和动作从哪一相位继续。

提示词单独复制也能成立。凡当前任务没有提供或本job没有上传的图像，不能写成“参考图已锁定”。项目内部asset ID保留在外部清单，由真正上传的文件承担输入。

## 对白与声音

画内对白写清说话者、发声状态、可见口型、语气强度和节奏；画外声写明声音来源以及画中人物是否发声。语气信息是2.0与2.5都需要的文本内容，但它不等同于音色锁。语气信息保留在说话标记附近，画面动作只写可见身体变化。对白台词逐字对齐冻结剧本。

语气信息与可见身体变化分开写。声音/配乐默认用自然语言描述；只有当前2.0 schema/documentation证明存在对应能力时，才序列化为2.0原生格式或绑定音频参考。不得套用2.5的声音标记、音色参考或帧锚定输入格式。最终声音是否由视频模型生成、能否单独上传或后期替换，按本次工具证据确认。

## 输出草稿模板

```text
Seedance 2.0 | 16:9 | 当前项目视觉风格：填写锁定值 | 时长：按当前job填写

画面基准：……
参考图：实际上传的唯一参考图；控制人物身份/服饰……；不控制构图和动作。没有图时删去此行。
镜头：从……构图开始，主体位于……；镜头以……速度沿……路径移动，停在……。
动作与表演：……
对白：角色以……语气逐字说：“冻结原句”。
声音意图：用自然文字描述对白、环境和动作声……
结束状态：……
```

该模板是制作稿，不是API请求体。移除本job没有的素材段，填完具体内容再交付；不输出省略号占位符。音频参考和原生声音语法仅在2.0的当前接入被核实后使用；不借用2.5规则。

## 提交前门

- manifest锁定`seedance-2.0`且所有job一致。
- 模式属于本次已核验的Seedance 2.0输入方案，不含2.5字段/标记。
- 当前2.0 schema确认接收真实文件类型、时长、画幅、素材数量和声音设置，job没超核实上限。
- 图像实际可读且经过审核；提示词只声称本job真实收到的内容。
- 逐字台词回拼、段缝状态、动作因果和16:9输出要求均检查。
- 未经当前证据核验的参数不写入请求；没有调用接口时保持草稿状态。

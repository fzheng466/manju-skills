# AI漫剧3D半写实男主资产编译

## 1. 范围与入口

本文件补充男主的设计和审核，不替代本地迁入的模板。沿用 `visual-assets.md` 的16:9单张四视图：左侧超大正面胸像，右侧正面全身、人物自身左转45度全身、背面全身；纯白或淡灰单一无缝底、无文字、双手空置。造型与渲染分开决定：先编译 `character-archetype-wardrobe-library.md` 的 Look Card，按 `character-prompt-style-variants.md` 选择一条完整风格行，最后按统一格式展开，不能只把“女”改成“男”。

本地源规范已有仙君、魔君、妖皇及都市男性分支，本文件将这些分支接入男主提示词。新增编译规则属于设计补充；本次四平台检索未完成，不能声称它们得到四个平台共同验证，见 `asset-research-basis.md`。

## 2. 骨相、身体与面部完成度

男主必须明确外观年龄，分别选骨相、体态与气质。少年感不等于婴儿肥，成熟感不等于满脸皱纹，力量感不等于无限加宽肩膀；温润、冷峻、桀骜等气质用眉眼、视线与站姿表达，不固定映射某张脸。

| 部位 | 必须落到的可见结构 | 易漏项 |
|---|---|---|
| 骨相 | 脸长宽、额颧颌最宽点、颧颊软组织、下颌转折、下巴端型与侧面投射 | 只写剑眉星目、刀削脸、绝世美男 |
| 五官 | 眉走向、眼裂与眼睑、眼距、鼻根鼻背鼻尖鼻翼、口宽与上下唇关系 | 所有男主同款眯眼、尖下巴、高鼻梁 |
| 肤质与妆面 | 肤色底调、风格允许的纹理程度、眉眼与唇色处理；胡须有无及形状按年龄设定 | 男性默认零细节，或套女主浓妆后不核对 |
| 体态 | 肩宽与头宽关系、颈长、胸背厚度、腰胯、腿长、肌肉量及其在衣下的轮廓 | 每人健美巨肌、超宽倒三角、过长小头身 |
| 发型 | 发际线、分缝、鬓角、前侧后分区、束点、发尾、冠/发牌固定及背面接续 | 正面高马尾、背面散发；短发硬插长发簪 |

从骨相或发型中选稳定识别点，复述正、45度与背面可见关系；痣、疤、额印不是凑数量的默认项。眉眼妆与面纹按既有库取词，不能用性别跳过面部设计。BJD、韩系、国漫、奇幻、UE5各自沿用完整风格条件；不把一种风格的皮肤、关节或磨损词带到另一种风格。

## 3. 题材与男性造型分支

| 分支 | 调用源库 | 男主需展开的重点 |
|---|---|---|
| 仙君/仙尊 | `xianxia-manju-costume-library.md` §3 仙君行、§2九槽与§5达标路径 | 纵向衣身、领口、广袖/收袖、半透外罩层的露出、玉冠或发牌固定、成套腰部承载、裤脚与靴口关系；不能只剩白袍和一支簪 |
| 剑修/江湖少年 | 仙侠服饰库九槽、角色造型库武侠/仙侠分支 | 肩袖与手腕的行动余量、分片下摆与内裤结构、腰封、绑腿或护胫、鞋底；锋芒和轻便通过剪裁体现，保留主角工艺等级 |
| 魔君/魔尊 | 仙侠服饰库§3魔君行 | 锐利或不对称剪裁、外披与肩部连接、皮革与金属丝织物、腰牌和挂具、魔纹准确落点；不能用全黑全红替代设计 |
| 妖皇/异族男主 | 仙侠服饰库§3妖皇行 | 按源分支落实非人结构与服饰关系、角耳冠的固定、鳞羽/毛领/尾饰的来源和背面；不可用随机兽耳和灯光替代身份 |
| 都市权贵/精英 | `modern-manju-costume-library.md` §3男性分支、§2九槽 | 具体领驳、肩线、扣位、腰身、面料、内搭露出、裤型、鞋型、腕表/袖扣/戒指固定；场合与职业决定是否选西装 |
| 温柔男友/学院 | 都市服饰库温柔男友、学院与对应男性槽位 | 针织、衬衫或外套的实际款式与层差、裤腰裤脚、鞋袜；遵守已有校服设定，不自动制服或黑大衣 |
| 偶像/艺人/街头 | 都市服饰库艺人与街头分支 | 短长对比、面料拼接、金属或珠宝焦点、鞋履与裤型比例；舞台强度按角色场合选择，不以超大肩部体积代替精致 |

以上是取词入口，不是固定配色套餐。主色、辅色、强调色与金属色、发色、妆面分别从适用库选，不能让仙君全白、魔尊全黑、霸总一律黑西服。不同男主的骨相、剪影、层搭和鞋履按源库的差异化规则验收。

## 4. 男主华丽度与成套度

玄幻/仙侠/修真及古风宫廷男主，与女主执行同等级的主角完成度和既有题材下限，不能因写了“男性、禁欲、清冷、克制”而降成素衣配角。仙侠以源库§5的任一结构丰富度路径达标，不硬规定层数，也不把抹胸、裙型等某一条女装路径强加给男主。

男主的华丽必须具体落位：领缘/肩袖/衣襟/下摆的定点工艺；内外层的长短、透度与材质差；头面的主件与固定结构；腰封/腰带与玉佩或挂具的连接；肩背外披和腕部扣合；下装结构及靴鞋细节。主色、辅色、强调色、金属色和玉石/金属/织物分材质按源库填写。只有装饰位置、纹样、镶嵌或材料实际变化才算华丽，重复“高级、奢华、俊美、电影感”不算。

都市男主按源库的场合与强度选择，可精致日常、礼仪华丽或舞台微夸张，不强制古装头面或固定三层，也不因男性身份取消珠宝、腕饰与面料工艺。服装选型由人物和场景决定，华丽度不能把所有男主变成西装模特。

头饰与发型联动：披发可走发牌、发网、额饰或自然族，不强插簪；头面成套指主件和明确固定结构，不靠饰品件数。腰佩写人物自身左右、穿带/链扣连接、下垂终点；人物板只显示穿戴结构，空手，不手扶剑、不抱书、不提公文包。

## 5. 从记录展开成稿

男主使用 `visual-assets.md` 的统一完整格式，不再维护第二套四视图模板。逐字段从唯一 `character_design_record` 展开：身份年龄和角色层级→所选3D半写实风格及其完整条件→骨相五官/肤质妆面→体态比例→发型发色和前侧背固定→内层/主衣/外层→腰肩腕→明确裤或裙裤/下摆内外关系→腿部层与鞋履→配饰、颜色与工艺→站姿空手与四视角一致性。

最终成稿每个部件只有一个确定值，不留“任选/或/同上”。不适用的层记在设计记录中，不为填槽位硬加实物；图像正文只写实际可见结构。参考路径、角色ID、来源库、费用与API字段放在图外记录，不画成标题与色卡。负向项单列并遵守当前工具是否支持独立负向字段，不把一个角色的风险清单盲目复制给其他角色。

## 6. 审核补充

执行 `character-styling-review.md`，男主额外核对：左侧胸像能否区分于其他男主；肩颈胸背是否由体态设定支撑；裤型、鞋袜和背面是否写全；华丽是否有具体工艺、承载和材质层差；男主有没有无依据降成配角；风格行的可选条件有没有被误当强制默认；空手基准图有没有混入武器或剧情战损。确认设计记录与最终正负向词一致后再进入逐张生图流程。

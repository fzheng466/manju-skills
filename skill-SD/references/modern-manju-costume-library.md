# AI 漫剧都市现代服饰槽位组合库

本文件是都市/现代题材在 **AI 漫剧** 生产中的服饰设计库。它取代"现代=把现实日常服装照搬进提示词"的默认写法：角色造型由槽位组合生成，同类型角色的差异必须发生在**结构层**（廓形、面料、层搭、露肤与开衩、鞋履、腿部层），而不是只换配色和款式名。

## 0. 定位与硬规则

1. **本库服务 AI 漫剧都市题材，不做时装史与品牌考据。** 都市言情、豪门、职场、娱乐圈、校园、都市异能、轻亚文化等当代背景通用。目标不是"复原某年某季真实单品"，而是当代都市里夸张、高华丽、镜头可读的造型语言。
2. **允许的夸张范围**：夸张肩线与廓形、超长拖尾礼服、大面积缎面/丝绒/皮革高光泽材质、大体积珠宝与金属链条、非日常材质拼接、明确高开衩与露腿、腿环/腰链/臂环、光泽面料与哑光面料强对照、刻意非对称剪裁。这些是 AI 漫剧都市题材的常态选项，不是越界。
3. **不放弃精度**：夸张不等于堆料。每套仍须写清层与层的露出关系、面料与版型、鞋履结构、饰品左右与固定方式、包袋肩带方向，并按 `character-styling-review.md` 做冲突检查。
4. **不得靠风格形容词交货**：禁止只写"高级""漂亮""优雅""帅气""时尚""精英感""氛围感"。按小红书实采公式转译为具体设计：**颜色 ＋ 款式 ＋ 面料 ＋ 版型 ＋ 鞋包配饰 ＋ 画面要求**。
5. **换衣不换人**：同一角色的多套造型（通勤、约会、晚宴、私下）必须写明"保持参考人物的五官、发型和身材比例不变，仅调整服装与配饰"，生成后逐项核对五官与服装细节；不把"换装"做成"换人"。
6. **安全边界不放松**：露腿、高开衩、丝袜/网袜、贴身结构为**成年角色**的合法选项；学生与未成年角色、校园题材按学段、季节与场景保持合宜着装，不成人化呈现。
7. **取词纪律**：本库只给可组合的槽位选项与角色分支条件，不给固定成稿。每条提示词的选值应由角色身份、职业、阶层、场合、关系阶段与当前状态驱动，并逐项落位。
8. **本库不接管、也不锁定发型、发色、妆面、脸型骨相、配色色名与饰品材质**：这些仍由 `hair-style-library.md`、`hair-color-library.md`、`eye-makeup-library.md`、`face-archetype-library.md`、`palette-costume-jewelry.md` 与项目视觉圣经独立取词；§2.10 与 §3 中的示例色名、耳饰、发饰只是实采样例，不是指定值。**都市题材的华丽度不设题材下限**，可按项目需要从日常强度自由选到高华丽强度；本库只决定"服装结构与承载"的方向与取值范围。
9. **本库给方向，不设格式锁**：§3.1 的三段式命名、分节骨架与服装节顺序是小红书实采的**默认展开方向**；项目已有命名体系/提示词模板、或用户另有要求时，以其为准。真正必须做到的是质量门——九槽逐项落具体选值、同作同类角色结构差异化、不拿空形容词交货（见 §4、§5）。
10. **题材级类型默认（用户 2026-10 拍板，非本库自行硬编码）**：都市/现代题材的【风格类型】默认取 `高精度3D半写实BJD人偶`（定义见 `character-prompt-style-variants.md` §2 该行），与玄幻/古风题材的默认 `3D半写实国漫CG` 分档并存。该默认可由项目视觉圣经或用户指令覆盖，覆盖后全剧统一；本库只登记该默认的取词与写法（见 §6），不改动其他库的通用"不得默认写死"原则。
11. **都市女主级别可华丽、微夸张（用户规定，肯定式授权，非本库自设）**：本作都市题材的**女性主角/关键角色**可进入华丽档与**微夸张档**（§0 第2条所列夸张肩线与廓形、大体积珠宝、高光泽面料、明确高开衩与露腿、腿环/腰链、非对称剪裁等）。
12. **微夸张的定义与边界（用户 2026-10 明确，必须照此执行）**：微夸张指**在现代服饰语境里做得更华丽、更精致，用来把该角色凸显为主角或关键人物**——同等品类下材质更高级（真丝缎、粗花呢、羊绒、皮草领、珠光纱）、装饰更集中精致（成套珠宝、扣饰、滚边、刺绣、腰封）、剪裁更利落考究、比例更修长、配色对比更有掌控。**两条边界**：①**它没有美感豁免，更不是把服饰写丑**——严禁用怪异比例、畸形廓形、超大体积堆砌、无支撑的悬浮结构、夸张到失真的垫肩、失衡剪裁去换取"夸张"；每个夸张项都必须仍然合身、可穿用、好看，并服务"突出主角/关键人物"这一目的。②**它不是必需项**——日常、职场、校园、居家属克制写实档即可；未进入夸张档不构成未完成，不得为凑档位强行加夸张元素。
13. **场合驱动只调活跃强度，不锁品类与廓形**：场合（公开/通勤/约会/晚宴/舞台/私下）决定的是**造型强度与装饰密度**（日常强度／精致强度／礼仪强度／舞台强度），**不决定穿什么品类**。西装、成套西服、三件套属"职场精英"分支的工作现场造型，不因角色是豪门千金或"公开场合"就成为默认品类；千金公开造型可选小香风套装、毛呢/双面呢大衣＋缎面连衣长裙、针织开衫＋半裙、缎面西装裙、披肩式外搭等千金向品类。任何分支都不得把职业套装当作默认答案；反之亦然。

## 2. 槽位组合系统

九槽全部作答；不适用的槽写"无"并给一句原因。**不得为填槽强加实物**，也不得每个角色都落回同一组选值。

### 2.1 槽A 廓形与版型

写清肩线、腰位、衣长、摆幅、开衩与剪裁视觉重心；不要只写"西装/连衣裙/卫衣"。

| 方向 | 可选结构 |
|---|---|
| 女性·上装主导 | 微收腰短西装+高腰下装、Oversize 大廓形外套+紧身内搭、垫肩直角肩西装、落肩针织+高腰裤、短款外套+高腰长裤、抹胸/方领上衣+高腰下装 |
| 女性·连身 | 直身极简连衣裙、收腰A字连衣裙、紧身针织长裙、鱼尾拖摆长裙、开襟衬衫裙、非对称单肩礼服、前短后长裙 |
| 男性·上装主导 | 直身单排扣西装、双排扣宽肩西装、落肩长外套+修身内搭、宽松针织+垂感西裤、皮夹克+紧身牛仔裤、卫衣+束脚裤、衬衫+背带裤/工装 |
| 男性·整体式 | 成套西服三件套、长风衣+修身西裤、大衣+高领针织同色系、军装式短外套+成套裤装 |
| 剪裁变量 | 收腰/自然腰/低腰；直身/微收/宽摆/鱼尾/裹身；单开衩/双开衩/前开衩/高开衩；对称或刻意非对称；短款/常规/超长 |

### 2.2 槽B 面料与质地

面料按"光泽 × 厚薄 × 垂坠 × 织纹 × 弹性"五个维度选，不写品牌名。每种面料须落到具体衣层。

| 维度 | 可选 |
|---|---|
| 光泽 | 高光缎面、丝绒哑光、亮面皮革、珠光面料、金属感、哑光羊毛呢、平织棉、镜面光泽 |
| 厚薄与垂坠 | 轻薄雪纺/真丝、垂坠西装呢、中等针织、厚实羊毛/羽绒、挺括斜纹、有量感皮革 |
| 织纹 | 平纹、罗纹针织、细格/粗格、提花、蕾丝镂空、珠片/亮片、渐变染色、拼色拼接、压褶 |
| 处理方式 | 单层剪裁、内浅外深、同色异材质拼接、光泽哑光对照、磨边做旧、光泽涂层、非对称拼片 |
| 丝袜/袜类材质 | 见 `palette-costume-jewelry.md` §3.4 与 §2.7，本库只声明'选哪一层用' |

### 2.3 槽C 层搭方案

层数由设计决定，**不设固定下限**。每套至少给出一个可读的结构关系（层叠露出、开襟叠穿、长短错落等）。

- 单层剪裁（靠廓形和面料承担层次）
- 双层对照（内紧外松 / 内浅外深 / 光泽哑光对照）
- 三层叠穿（内搭+中层+外层，写清每层露出区域：领口、袖口、下摆、门襟）
- 衬衫+马甲+西装 / 针织+衬衫+大衣
- 抹胸或方领上衣+高腰下装+短外套
- 紧身内搭+Oversize 大廓形外套
- 长外套敞开叠穿（露出内层整条纵线）
- 前后异长叠穿（前短后长、后拖尾）

### 2.4 槽D 露肤度与开衩

逐点写清位置与程度，不要用"性感/端庄"替代。

| 露肤点位 | 可选处理 |
|---|---|
| 颈/锁骨 | 高领全封、圆领、方领、一字领、V 领、大翻领微敞、露锁骨斜襟 |
| 肩 | 全包肩、单肩、露双肩、垫肩造型、落肩、挖空肩 |
| 背 | 全露背、挖空式露背、露背+束带、全包 |
| 腰 | 侧腰挖空、短款露腰、束腰、全包 |
| 腿 | 长裤全覆盖、中长裙、及膝、短裙/短裤、开衩（膝上/大腿中/高开衩）、前开衩、双开衩 |
| 表现强度 | 端庄全覆盖 / 局部留白 / 若隐若现（镂空蕾丝/透纱） / 明确露腿 |

露肤是设计选项，不与性别、气质或"现代"绑定；同一角色不同场合版本可变（通勤全包、约会局部留白、晚宴高开衩）。

### 2.5 槽E 外层与肩部

微收腰短西装、Oversize 大廓形西装、长风衣、双面呢大衣、短款夹克、皮夹克、牛仔外套、工装外套、棒球外套、开衫、披肩/薄纱披覆（晚宴）、无外层（抹胸/单穿）。写明肩线形态（直角/落肩/自然）与敞开或闭合状态；禁止无固定点的悬浮披覆。

### 2.6 槽F 鞋履

鞋型、鞋头、鞋面、鞋底/跟高、闭合结构、材质、与裤脚/裙摆的关系逐项写清。

尖头细高跟、方头中跟、粗跟短靴、及踝靴、长筒靴、乐福鞋、牛津皮鞋、玛丽珍、芭蕾平底、尖头平底、低帮运动鞋、帆布鞋、厚底鞋、雪地靴/马丁靴（按季节与场合）。**高跟、厚底、大头、黑丝都不是默认件**；学生与校园题材按学制与活动选鞋，香水台/舞台鞋说明稳定性与活动余量。

### 2.7 槽G 腿部层与袜

腿部层与鞋型**独立决定**，再配套核对。写清覆盖高度、厚度、透明度、织法/渐变、袜口固定方式、与裙摆/鞋口的衔接关系。

光腿（写自然肤色、肤理、季节与鞋口关系）、隐形船袜、短袜、中筒袜、过膝袜、连裤袜、黑丝/肤色丝袜/网袜、打底裤、保暖抓绒。允许"裸腿，无袜"并明确写出。黑丝/白丝/过膝袜只在有穿着制度、场合或个人审美依据时选用；校园角色不得自动加黑丝或连裤袜。

### 2.8 槽H 头面、腰腕与配饰

- 头面/发饰：鲨鱼夹、抓夹、发箍、发卡、丝绒发圈、发带、贝雷帽/鸭舌帽/渔夫帽、眼镜（细框/粗框/无框）、耳饰（耳钉、圆环耳环、几何银耳环、珍珠耳坠、金色垂坠）。
- 腰部承载：腰带（细金扣/宽皮带/多扣战术腰带）、腰链、腰包、束腰。
- 腕臂：腕表、手链、手镯、戒指、臂环、手套（皮手套/分指手套）。
- 包袋：手提包、斜挎包、托特包、迷你手袋、公文包、运动腰包；写明肩带跨哪侧、包体落点与材质。
- 饰品成套：多层项链、领针、领带夹、袖扣、丝巾（写明前后披垂方向）、胸针。
- 每件写清佩戴位置、连接点、垂坠终点、材质、人物自身左右；**无品牌**，商标/校徽/队徽/可读文字只在用户提供或剧情指定时写入，否则用纯色或抽象标记。

### 2.9 槽I 驱动来源（先答这槽，再填前面八槽）

身份/职业、社会阶层与财富来源、公开或私下场合、关系阶段（陌生/暧昧/稳定/疏离/重逢）、时间与季节、天气、当前状态（通勤/加班/赶场/被偷拍/未完成妆发）。**同一角色在不同场合可有不同版本，但廓形方向、主色逻辑与识别点不得随机漂移。**

### 2.10 实采措辞样例（小红书 AI 漫剧，2026-10-15）

- 实采服装公式："颜色＋款式＋面料＋版型＋鞋包配饰＋画面要求"；实采示例："成年女性，身穿雾蓝色微收腰西装外套，内搭米白色缎面衬衫，搭配雾蓝色高腰阔腿西裤、浅色尖头鞋和简约手提包。面料垂坠，褶皱自然，整体干练利落。全身正面构图，头顶与鞋子完整入镜，白色背景，柔和光线，服装纹理清晰。"

- 男装冷淡精英措辞："风衣拉长纵向线条，衬得身形挺拔冷冽，宽肩撑起大衣，整体穿搭简约高级，都市冷峻精英感，气场压迫感强。"（"简约高级"仍须由具体面料/版型/配饰支撑，不得单独作为提示词交付。）

## 3. 角色分支

### 3.1 命名与分节骨架（实采，默认方向）

以下为小红书 AI 漫剧实采的**默认展开方向**，用于校准颗粒度与语感；项目已有命名体系/提示词模板或用户另有要求时以其为准，不按"未完成"处理。骨架叠加在 `character-prompt-style-variants.md` §1 基座十一槽位之上，只是服装节的展开参考，**不替代基座**。

- **命名惯例**：`【角色定位】·【配色】·【气质】` 三段式。都市示例（按实采用词重构，仅为示例、非指定值）："都市清冷千金 · 黑白分明 · 疏离矜贵"、"温柔初恋 · 米白桃粉 · 柔软治愈"、"明艳主角 · 酒红莓果 · 张扬锐利"、"盐系清冷少女 · 冷灰棕黑白 · 小众酷感"、"都市冷峻精英 · 黑灰冷调 · 压迫疏离"。定位词与配色词应与实际槽位选值自洽，不得标签化。
- **分节骨架**（两类实采骨架，按项目提示词长度选一种；与四视图基座槽位一一对应）：
  - 骨架 A（角色卡型）：基本信息（年龄/性别）→ 人物设定 → 性格气质 → 发型 → 头发质感 → 妆容（含耳饰）→ 上衣（内搭＋外层）→ 下装 → 鞋子 → 配饰 → 整体气质总结 → 负面提示词。
  - 骨架 B（造型稿型）：人物设定 → 五官细节 → 发型与穿搭 → 氛围与质感 → 画面要求。
- **服装节顺序**：主配色 → 上装款式与领口高度 → 内搭 → 外层与肩线 → 下装版型与长度 → 鞋 → 包 → 配饰成套 → 与发型/妆容的呼应 → 整体气质总结。
- **画面要求**：本项目固定 16:9 四视图（左侧超大正面胸像＋右侧正面/45°/背面全身）；**资产板背景固定为单一纯色无缝底——白底或淡灰底，这是硬项**（依据 `visual-assets.md` §四视图版式"背景用白/浅灰无缝底或低干扰纯色"），不随角色、场合或风格板变化：除该底色外不得出现环境场景、家具、道具、地面投影、渐变或第二背景色；宴会厅、会客厅、街景等环境只用于剧情镜头，不用于资产板。**画面内不得出现任何文字**（角色名、标签、色卡、说明、编号、尺寸标注、logo、水印、乱码标签），也不出现边框、标尺、分割线。光线按项目风格板（小红书样本常用"纯白/浅灰背景、柔和棚光、清透肤质"，可作风格板对照，不覆盖本项目版式）。

### 3.3 分支负向清单（按所选分支逐条写入【避免】）

- 通用：不要"高级/漂亮/优雅/帅气/时尚/精英感/氛围感"等无结构形容词；不要通体名牌或乱码文字；不要五种高饱和色等量竞争；不要四视图间五官漂移或换装。
- 清冷千金/精英：不要打光过曝导致缎面塑料感；不要所有角色都是纯黑。
- 温柔初恋/少年感：不要幼态化学生脸；不要细高跟与浓妝错配。
- 明艳主角/偶像/晚宴：不要为露而露导致焦点分散；不要无固定点的悬浮披覆与大体积珠宝。
- 校园/学生：不要成人化性感造型；不要无校服依据的日韩制服；不要默认黑丝或厚底大头鞋。
- 都市异能：不要在常态外观上常驻发光；不要异常点随机移动。

## 4. 结构层差异化硬约束

同作同类都市现代角色**至少四个槽位取不同选值**，且差异必须包含 **廓形、层搭、露肤处理、鞋履** 中的至少两项；只换配色与款式名（例如两套都是"黑西装+白衬衫+西裤+黑皮鞋"）判定不合格。

- 两名同阶层女主不得同时落在"收腰西装+高腰阔腿裤+细高跟"；至少一人在廓形（宽肩/落肩/大廓形）或层搭（三层叠穿/紧身内搭+大外套）或腿部层（裸腿/中筒袜/过膝袜）上分开。
- 两名同阶层男性不得同时落在"长风衣+衬衫+西裤+牛津鞋"；至少在肩线形态、外层类别（风衣/大衣/皮夹克/短夹克）、鞋履（牛津/乐福/切尔西/运动鞋）上分开。
- 同一角色的不同场合版本，变化必须发生在**层搭、露肤、鞋履、配饰成套度**上，而不是只换颜色；识别色与稳定识别点保持连续。
- 学生/配角不得复制主角的廓形、识别色、主鞋型与成套配饰等级。

## 5. 达标判定

- 九槽是否逐项落到具体选值（含"无"及原因）？
- 是否避免只写形容词，而给出"颜色＋款式＋面料＋版型＋鞋包配饰"？
- 是否写清层与层的露出关系、鞋履结构与闭合、饰品左右与固定方式、包袋肩带方向？
- 是否核对了鞋型与腿部层的独立选择、且未默认高跟/厚底/黑丝？
- 是否按分支逐条写了【避免】负向清单，且负向不禁止正向已选项？
- 同作同类角色是否满足第4节的"至少四项＋必含两类"差异化？
- 同一角色多套造型是否写"仅调整服装与配饰"并保留五官、发型与比例？

以上质量门任一项缺失即判定未完成，退回补足，不得进入生图。§3.1 的三段式命名、分节骨架与服装节顺序属默认方向，不计入未完成判定。

# 表演、摄影、分镜与连续性

## 镜头是可审查单元

一个镜头围绕一个主要可见动作或一个明确的观察变化。复杂打斗可有连续的子节拍，但每一节拍要有明确起因和结束状态。镜头切换须带来信息、关系、动作阶段、时空或观察位置变化；不要仅为填镜数切。

镜头工作表字段：

| 字段 | 需要记录的内容 |
|---|---|
| `shot_id / group_id` | 全局稳定ID与生成组ID |
| `start/end` | 项目时间线起止秒数；无空洞、重叠 |
| `purpose` | 观众在此新增知道/感受到什么 |
| `focus_owner / viewpoint` | 本场当前由谁带领观众；本镜客观、主观或过肩/反打视点 |
| `subject/framing` | 谁或什么是主体，景别、构图和层次 |
| `screen_height_ratio` | 人物或关键主体约占画面高度比例；双人镜分别记录 |
| `camera` | 机位位置/高度/朝向、焦点和必要的景深 |
| `movement` | 移动类型、触发点、路径、幅度、速度与终点 |
| `blocking` | 人物位置、身体朝向、视线对象、持物手、入离画路径 |
| `cut_reason` | 切镜触发事件、切后焦点及新增信息；无切镜时标 none |
| `performance` | 情绪目标、策略、触发、可见身体/面部变化、听者反应 |
| `dialogue/audio` | utterance ID、原文、说者、语气、OS/VO、同步声音事件 |
| `start_state/end_state` | 人、物、姿态、场景、伤损、光线与声音接缝状态 |
| `continuity_from` | 应从哪个镜头状态继承；跳时/换场明确标注 |

## 人物与场景的画面尺度、视点和景别变化

每场先建立一条可剪辑的观察路径：写明本场的 `focus_owner`（当前由谁的目标、感知或行动带领观众）、观众此刻能知道什么，以及焦点何时因什么可见事件转交。逐镜标记 `viewpoint`（客观观察、角色主观、过肩/反打等）、`shot_scale`、`screen_height_ratio`（人物或关键物体约占画面高度的比例）、`spatial_layer`（前/中/后景）、场景锚点和 `cut_reason`。人物占比是构图描述，不是让模型精确测量的硬像素指标；比例变化要与景别、机位、遮挡、透视和16:9画面共同说明。

以下是16:9横屏的起始构图范围，不是每场必须覆盖的清单，且景别名称应以实际裁切范围为准：大远景人物约占画高3–10%，远景约10–25%，主要交代天地/建筑群/地形、人物进入路径及人物在场景中的位置；全身动作镜让完整人体约占画高65–85%，要看清动作路径时可留更多空间，但不得无意缩成环境里的小点；中远景（膝上或大腿上）约45–70%；中景（腰部以上）约35–60%；中近景/近景（胸部或肩部以上）约55–80%；脸部特写通常以脸部占画面高度约55–85%作为起点，手、眼睛、法器触点等局部按剧情信息另定。双人镜分别标注两人的画面占比与相对距离，不能只写“中景”。范围可按构图裁切和剧情目的偏离，但要写出理由。需要交代宏大场景时人物应明显小于建筑/地形主体；需要读清表情或关键接触时才有依据地推近。

每场应有远近景别的有因果变化，不得连续把所有内容写成中景或固定大小的双人景。可按戏剧任务选择“建立环境/人物关系 → 角色视线或动作引出主观目标 → 对象/动作细节 → 回到观察者的反应或双方关系 → 为下一动作留出空间”的序列；这只是覆盖逻辑，不是强制镜头模板。每次切换需写触发事件、切前观众关注点、切后新增信息和承接的空间方向。主观镜头写明视点角色、视线目标、观察动机及何时回切；过肩/反打维持轴线与场景锚点。动作戏在建立空间后按攻防因果调整镜头远近，完整动作须保证发起者、目标、路径、接触和反馈可读；关键技能或情绪反应可短暂获得近景，但不能用无因果特写遮掉动作结果。

完稿后做景别分布检查：若连续多个 shot 的人物占比和景别几乎不变，且没有剧情理由，重排其中一处为有叙事动机的环境尺度、主观视点、动作全身或反应细节；若频繁切换导致方向和距离不可读，则恢复建立镜头或延长当前可读镜头。不能为了“有变化”随机切镜，也不能让环境建立镜头、动作镜头和反应镜头都挤成同一中景。

镜头时长由对白试读、动作节拍、反应停留和转场需求倒推。2–5秒对话近景、短动作镜可作节奏参考，不设所有项目通用硬门槛。生成任务时长单独计算。禁止靠空镜拉长镜头凑剧本标注时长。

## 摄影可执行性

摄影机从一个可理解的位置出发，按可达路径移动到一个有叙事意义的终点。区分：推轨/拉轨是相机位置改变，变焦是视角/焦距变化；摇摄是机位不平移而镜头转向，横移是摄影机横向移动；升降与俯仰分别说明相机高度变化和视线角度变化。景别与焦距不互相替代。只有在能控制透视或景深时才填焦距/光圈。

动作化运镜要交代对象和终点：跟随谁、从哪个方向跟、何时停；环绕需说明弧线路径和被摄对象，不能写“镜头炫酷环绕”。复杂镜头先拆成文字化的构图、机位路径和动作状态序列；玄幻仙侠武打不默认制作多格故事板图，优先稳定机位或短程跟拍。动作本身不需要高难运动时优先稳定机位。

## 表演与人物关系

逐句判断角色此刻想影响谁、达到什么目的、遇到什么阻力、采用什么表达策略、听者如何即时反应。没有证据不新编隐藏动机。角色表演用可见动作写：眼神目标与停留、眼睑/眉间、嘴唇/下颌、呼吸节奏、肩颈、手指、重心和动作幅度。每镜只选少数有效信号，不把十种微表情堆在同一时点。

情绪提示按“触发事件 → 外在目标/掩饰策略 → 面部信号 → 身体/呼吸信号 → 行为或关系变化”组织。面部可拆眉间/眉梢、眼睑/视线、嘴角/唇部/下颌，并选一两项有因果的细节（如泪光渐聚、吞咽、咬肌收紧）；不要求每镜把眉眼嘴三项写满，也不把瞳孔骤缩、青筋暴起、眼底无光等词机械套用到所有角色。可将同类情绪按强度递进，如察觉异样→迟疑→错愕，克制不满→压住怒意→失控；强度只随事件变化，不为镜头表演而跳级。

表演描述需要有时间过程：起始表情/姿态、哪个信息触发变化、变化先出现在何处、角色是否压回去、最后停在哪里。反应镜头给观众足够读取时间；对白中的面部变化不能覆盖口型需要，也不要把复杂表情、台词、转身和大动作都塞在同一时点。听者反应依据其实际听到/看到的信息安排，可用回避视线、停顿、呼吸中断、手上动作停止等克制反应，不必自动切成夸张脸。

写实表演与表情包夸张是不同路线。漫剧默认按角色身份和项目风格控制幅度；只有剧情明确需要喜剧化/漫画式反差时才放大五官动作。角色既定的表情习惯可记录为表演约束或少量复用参考；单次分镜不自动要求制作九宫格/独立表情资产。若确需表情参考图，保持脸型、年龄感、发型、妆面和服饰等身份锚点，只改变情绪状态。

FACS仅按需：L1用普通可见词；L2在局部近景需要精确表情时记录相关AU/肌肉区域；L3用于表情设计/逐帧诊断。AU编号是内部分析提示，不直接把多组代码塞进普通视频提示词。悲伤不自动等于流泪，愤怒不自动等于红眼发光。妆面、肤色、年龄感和身份保持，状态改变要有剧情触发。

听者和背景人物有处境合适的微反应，不抢主动作；不知道的信息不提前反应。OS/VO是画外声音，明确来源和画内人物是否张口。某人被写为“在场”就要在画面、焦外或明确离画状态中交代；别在镜头间凭空消失/回到旧位置。

## 双人对话镜头调度进阶规范

**标准三镜头调度结构**（文戏对话的基础范式）

双人对话场景的镜头调度遵循经典好莱坞三镜头制式，时间戳与景别分配如下：

- **0–2 秒：中景双人** - 建立两人关系与空间距离，让观众理解站位与亲密度（60–80% 两人全身）
- **2–5 秒：过肩镜头 A** - 从某人肩后拍摄，聚焦说话者的面部表情与口型同步，对方肩部/耳侧/后脑勺占画面约一成作为前景参考
- **5–7 秒：反转过肩镜头 B** - 从对方肩后拍摄，捕捉听者的微反应、眼神接触、理解停顿、准备回应的时刻

**空间轴线锁定与前景层设计**

- 双人对话时设定一条虚拟的空间轴线连接两人，所有镜头必须在该轴线同侧拍摄，不得越轴（除非用建立镜头或实际人物运动说明新方向）
- 过肩镜头的前景层（肩膀/耳侧/头发）需保持一致性：若 A 镜头中对方头部在画面左侧作为前景，反转镜头中该人物头部也应在右侧作为前景
- 前景层占比约 8–12%，不能遮挡说话者的眼睛与嘴角

**反应镜头时间戳与常见失效案例**

- 反应镜头（听者镜头）的时长应与说话人镜头的对白长度匹配，不能提前切走（切走会让反应显得不真实）
- 常见失效案例：
  - 说话人还在讲话，镜头已切回来，导致观众不知道此时谁在说话
  - 反应镜头中听者表情变化与对白节奏不同步，显得演员反应迟缓
  - 过肩前景层在两个镜头间不一致，显得空间跳跃
  - 反应镜头中听者眼睛看向画外（看向说话人），但说话人在画面另一侧，逻辑错乱

## 文戏表演链与时间戳设计

**六步情感表演链**

文戏的情感表演遵循完整的心理-生理-行动链，时间戳需要为每个环节留出可读的时间：

1. **刺激（0.0s）** - 角色听到/看到触发信息，这是时间起点
2. **理解停顿（0.5–1.0s）** - 大脑处理信息的短暂空白，身体微僵/呼吸中断/眼神失焦
3. **无意识反应（1.0–2.0s）** - 真实情绪泄露：瞳孔变化、吞咽、微表情闪现、呼吸改变
4. **主动选择（2.0–3.0s）** - 角色决定掩饰或表达：压制表情、调整姿态、准备说话
5. **台词/行动（3.0–5.0s）** - 执行策略：说话、转身、回避、直面对质
6. **残留情感（5.0–6.0s）** - 台词后的情绪余波：眼神未散、手指仍紧握、呼吸尚未恢复

**时间戳分配规范**

- **建立镜头（0–2秒）**：中景双人，显示两人初始关系与距离
- **刺激镜头（2–3秒）**：说话者近景，口型与对白同步
- **反应镜头（3–6秒）**：听者近景，完整走完理解停顿→无意识反应→主动选择的三步
- **回应镜头（6–9秒）**：反转回说话者或切回双人，捕捉对话节奏变化

时间戳需与对白试读时长匹配：一句 3 秒的对白，反应镜头至少给 1.5–2 秒读取时间，不能对白刚结束立刻切走。

**微动作与细节堆积**

表演细节按优先级堆积，不是全选：

- **眼睛微动（优先级 1）** - 视线目标、停留时长、回避/直视、眼睑张合、泪光聚散
- **面部肌肉（优先级 2）** - 眉间收紧/舒展、嘴角上扬/下压、咬肌收紧、下颌微抬/低垂
- **呼吸与身体（优先级 3）** - 呼吸节奏变化、肩膀起伏、手指收紧/松开、重心前倾/后仰

每个时间戳选 1–2 项有因果的细节，不把十种微表情堆在同一秒。

**文戏常见失效案例**

- 刺激与反应时间戳重叠，听者在说话人开口前就开始反应（预知剧情）
- 理解停顿时长不足（< 0.5秒），显得角色反应过快不真实
- 无意识反应与主动选择混在同一时间戳，情绪表演显得机械
- 台词时长与镜头时长不匹配，口型同步失败或画面空等
- 残留情感被下一镜头硬切，情绪断裂显得剪辑粗糙
- 反应镜头中堆砌过多微表情（眉眼嘴手呼吸全选），显得表演过度

## FPV 与一镜到底工作流

**第一人称视角规范与景别调度**

FPV（第一人称视角）漫剧镜头将摄影机等同于主角的眼睛，观众直接以角色的视角体验场景。Seedance 2.5 对 FPV 的支持主要体现在以下规范：

- **视角锚定** - 摄影机永远处于主角眼睛高度（通常距地 1.5–1.7 米），视线中心对准当前交互对象（对话者面部、操作物体、行进方向）
- **景别控制** - FPV 中的"景别"转化为"距离感"：亲密对话时对方脸部占画面高度 50–70%（相当于传统近景），递交物品时手部占画面 30–50%（相当于中景特写），环境浏览时远处物体占比 10–20%（相当于远景）
- **互动对象位置** - 对话者、操作对象、行进目标应始终保持在画面中心 1/3 区域，避免重要元素偏移至边缘导致视觉不适
- **禁止事项** - FPV 中不得出现主角自身的身体部位（除非剧情需要看手部操作），不得突然 180° 转向（需分段过渡），不得无动机的上下摇晃

**手持质感与自动对焦呼吸**

Seedance 2.5 生成 FPV 镜头时，应通过以下参数模拟真实手持设备的拍摄质感：

- **微动摇晃** - 添加"subtle handheld breathing"（细微手持呼吸感）或"iPhone handheld POV"（iPhone 手持质感），模拟人体自然晃动（幅度约 ±1–2 像素的水平/垂直偏移）
- **自动对焦呼吸** - 描述"autofocus shifts between [对象 A] and [对象 B]"（自动对焦在 A 与 B 之间切换），模拟手机/相机的自动对焦过程，前景与背景在 0.5–1.0 秒内交替清晰
- **行进时的节奏感** - 行走时添加"walking rhythm bounce"（行走节奏弹跳），每步约 0.4–0.6 秒一次轻微上下起伏
- **转向平滑** - 头部转向需描述"slow pan left to [目标]"（缓慢向左平移至目标），转向速度控制在 30–60°/秒，避免突兀甩头

**30 秒长形式结构与完整性保证**

Seedance 2.5 支持最长 30 秒单镜头，FPV 一镜到底工作流充分利用这一能力，按以下结构组织：

- **0–5 秒：建立环境** - 主角视角扫视当前场景（房间、街道、店铺），让观众理解空间布局与氛围
- **5–15 秒：主要交互** - 聚焦核心剧情事件（与对话者交流、操作关键物品、接收信息、做出决策）
- **15–25 秒：行动与转折** - 执行决策（行走、转身、拿取物品、离开现场），可包含一次空间位置变化
- **25–30 秒：过渡或悬念** - 镜头引导至下一场景的入口、新角色的出现、或停留在某个悬念物体上

**完整性保证**

- 整段 30 秒为一个不间断的时间流，时间戳从 `0.0s` 到 `30.0s` 连续标注
- 每 5–8 秒标注一个关键时间戳，描述此刻主角视线目标、摄影机朝向、场景变化
- 禁止在 30 秒内出现硬切或黑场，所有转场通过主角视线移动完成
- 结尾状态需明确标注主角最终视线目标与所在位置，为下一镜头提供连接点

## 多人群戏远近景配合

### 远景-近景协作逻辑

多人群戏需要在远景与近景之间建立清晰的信息传递链条：

**远景职责（建立空间与因果）**
- 展示完整的空间布局：所有角色的相对位置、群体分布形态（包围圈、对峙线、混战区）
- 明确动作发起源头：谁先动、动作方向、目标对象
- 建立因果关系起点：远景中的群体移动 → 近景中的个体反应

**近景职责（聚焦情感与细节）**
- 捕捉关键角色的面部表情、微动作、武器接触瞬间
- 展示力量传导的接触点：拳头落点、剑刃擦过、法术碰撞
- 提供情感读取时间：惊讶、痛苦、决断的0.5–1.0秒停顿

**协作时间戳规范**
- 远景建立镜头：0.0–3.0s，展示完整空间与群体动态
- 近景聚焦镜头A：3.0–6.0s，捕捉主角应对第一波攻击
- 远景更新镜头：6.0–8.0s，展示空间变化（包围圈收紧、敌人倒地）
- 近景聚焦镜头B：8.0–11.0s，捕捉主角反击与第二波威胁
- 远景结果镜头：11.0–14.0s，展示新的战局态势

### 人物占比与群体分布

**远景人物占比标准**
- 主角占画面高度：15–25%（保证可识别身份与姿态）
- 敌对群体单人占比：8–15%（保证数量感与威胁感）
- 最小可辨识占比下限：5%（低于此值则角色失去辨识度）

**群体分布三种典型形态**

*包围圈态势*
- 主角位于画面中心偏下1/3处，占比20–25%
- 4–6个敌人分布在圆形包围圈上，每人占比10–15%
- 圆心到边缘的径向空间：保留用于动作路径与特效轨迹
- 时间戳：主角转身扫视（0.0–2.0s）→ 第一个敌人发起攻击（2.0–3.0s）

*对峙线态势*
- 两方阵营分别占据画面左右1/3区域
- 主角方3人 vs 敌方5–7人，形成不对等压迫感
- 中间1/3区域为交战缓冲带，用于冲锋与碰撞
- 时间戳：双方对峙静止（0.0–1.5s）→ 主角方率先突进（1.5–3.0s）

*混战区态势*
- 8–12个角色交错分布，无明确阵线
- 主角占比维持20%，通过服饰色彩（明度对比）保持视觉焦点
- 背景与前景层各放置2–3个战斗组，制造景深与空间密度
- 时间戳：混战持续流动（0.0–4.0s）→ 主角突破到画面右上（4.0–6.0s）

### 远近景衔接原则

**空间锚点延续**
- 远景中的标志性物体（石柱、断桥、祭坛）必须在后续近景中作为背景元素出现
- 近景中角色的身体朝向必须与远景中的空间方位一致
- 远景中敌人A位于主角左侧 → 近景特写中敌人A的攻击必须从画面左侧进入

**动作因果链强制要求**
- 远景中出现的攻击发起动作 → 必须在3.0秒内切换到近景展示接触结果
- 近景中角色的反应表情 → 必须在前一个远景镜头中能找到对应的刺激源
- 禁止出现"远景中敌人静止 → 近景中主角突然受击"的因果断裂

**群体数量一致性**
- 远景中出现5个敌人 → 后续近景累计出场的独特敌人不能超过5个
- 远景中敌人倒地 → 后续远景更新镜头中该位置必须为空或显示尸体
- 远景中友军角色位于画面右侧 → 近景中不能出现该友军突然在左侧的镜头

**时间戳衔接检查表**
```
远景镜头A结束时间戳：t1
近景镜头B起始时间戳：t1（无缝衔接）或 t1+0.5s（微小时间跳跃）

检查项：
□ 近景中角色的起始姿态是否延续自远景结尾姿态？
□ 近景中的空间方向（左/右/前/后）是否与远景一致？
□ 近景中出现的新威胁是否在远景中已有伏笔（背景中的蓄势动作）？
```

**常见失效案例**
- 远景显示主角被三人包围 → 近景只出现一对一打斗（群体压力感消失）
- 远景中主角面向画面左侧 → 近景中主角突然面向右侧（空间方向混乱）
- 远景中敌人从右侧冲来 → 近景特写中攻击从左侧进入（方向反转）
- 远景更新镜头中敌人数量凭空增加（违反空间连续性）

## 空间连续性

角色自身左/右、空间地图方向和画面左/右是三个不同坐标。建立主空间轴线，并用门、桌、窗、地砖、壁灯等具体锚点定义位置；正反打的画面左右可以变化，人物世界位置不能因剪辑无故改变。越轴时用建立镜头或实际运动说明新的空间方向。

局部镜头要写清这是谁的手/肩、它位于画面哪一侧、连接到何处；身体朝向和眼睛目标分开写。持物手与物件状态需跨镜一致。进出画写清从哪个门/方向进入、路径与目的地。场景真实图没显示的部分不补造为已确认空间。

空间复杂度选路：S0单背景无位移；S1单区域简单双人；S2多入口/遮挡/交接物；S3追逐或跨区域动作；S4多层建筑/群战/连续空间变化。S2以上按需求做可走路径或调度图；S0/S1不自动产生多余地图。

## 连续性与段缝

逐对检查上一镜末态与下一镜首态：位置/朝向/动作相位、左右手与道具、道具开合、服装/伤损、视线目标、表情呼吸、场景时间天气、光源和声音尾部。连接点若有跳时/闪回/转场，标清变化发生在哪里。

输出的末态必须是可见具体状态，不写“保持连续/严格继承”。边界帧只在实际存在、可用且当前锁定版本接受时进入素材清单；没有边界帧就用文字描述并接受实际一致性检查，不宣称强锁。语言单元按ID拼回原文；动作不能超出对白可用时间。

## 预演与局部修复

当S2以上空间、多人动作或复杂VFX可能导致走位错误，先生成静态构图/纸面路线草图；无需每个场次都出分镜图。审核问题按`shot_id + 时间码 + 缺陷 + 最小修复 + 影响邻镜`记录。优先顺序为身份/主体→空间/轴线→动作因果→对白/表情→摄影→装饰细节。通过镜头锁定，仅让受影响镜头及其直接邻接镜头重新审核。

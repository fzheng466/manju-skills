# 人物提示词模板矩阵：按风格差异化增减

本文件把 `character-archetype-wardrobe-library.md`（Look Card）、`face-archetype-library.md`（骨相）、`face-design-and-opulence.md`（四视图胸像骨架）、`visual-style-and-asset-modules.md`（风格短模块）和 `palette-costume-jewelry.md`（腿部层/鞋袜）编排为**人物四视图提示词模板**：按风格增减，避免不同风格、不同题材的角色提示词雷同。

本仓库仅启用 AI 漫剧3D半写实分支：国漫、最终幻想高精度半写实、BJD、韩系、UE5与通用高精度半写实。源表中的其他媒介保留作对照，不自动用于生成；不得仅因表中存在就调用。男主在同一风格行下额外读取 `male-character-asset-design.md`，不另建与女主割裂的渲染标准。

使用顺序固定：**基座骨架 → 风格增减 → 题材身份槽 → 角色专属轴 → 正负向冲突检查**。基座只负责资产板结构与一致性，不带默认审美，不得直接当完成稿使用。

## 1. 基座骨架（所有风格共用，仅此一层共用）

基座只负责三件事：**四视图版式、同人一致性、双手空置**。它不写脸型、不写服装、不写风格词。

```text
生成一张16:9横屏人物四视图资产板。左侧约38%为同一角色的超大正面胸像，面部占足够面积以清楚呈现脸型、眉眼、鼻唇、肤质与妆容；右侧并排正面全身、人物自身左转45度全身、背面全身。
【骨相与五官】
【妆面】
【发型发色】
【上身衣层】
【下身结构】
【腰肩腕承载】
【鞋履】
【袜类/腿部层】
【饰品成套】
【体态与气质转译】
【环境与光线】
保持同一身份、同一骨相、同一发型发色、同一服装与同一配饰；全身视角只产生透视变化。双手空置，不手持、怀抱或提举任何物件。背景为**单一纯色无缝底（白底或淡灰底）**，除该底色外不出现环境场景、家具、道具、地面投影、渐变或第二背景色；画面内**不出现任何文字**（角色名、标签、色卡、编号、尺寸标注、说明、logo、水印、乱码标签），也不加入边框、标尺、分割线、额外头像窗。不做面部磨皮、模板化网红脸或五官漂移。
```

十一个方括号槽位必须逐个填写；确实不适用写"无"并给一句原因，不留空、不留"任选/同上"。

## 3. 题材身份槽（题材只填客观约束，不指定审美）

默认角色未被用户明确标注为配角/NPC/路人/侍从时，按男主/女主的高精美完成度编译。若题材为玄幻修仙、仙侠或修真，增加仙侠精致材质与服制：精致面料、层叠剪裁、灵纹/法器挂点、玉石金属织物分材质和有来源的灵性细节；粗麻、破旧和无设计感素衣不得作为默认。

题材只往【上身衣层】【下身结构】【腰肩腕承载】【鞋履】里追加**客观限制**，不改脸型、不改气质、不改风格。

| 题材 | 追加的客观约束 | 明确禁止 |
|---|---|---|
| 玄幻修仙 | 门派服制、修行阶段、灵力/法器挂点、织物灵纹层级；服装按 `xianxia-manju-costume-library.md` 九槽组合生成 | “仙气飘飘”必须转译为具体纱质、飘带、开衩、悬垂与配色结构，不得只留形容词；不给普通 NPC 套主角级法器；不做汉服形制考据 |
| 武侠江湖 | 兵器习惯与磨损、行旅负重、绑腿/腰带受力、可行动余量 | 不默认黑衣夜行衣；不默认长剑 |

## 4. 骨相槽：风格再换也要先定骨相

脸型与骨相独立于风格。每个核心角色从 `face-archetype-library.md` 选**一条主路径**（或明确复合路径），落到具体几何，不写脸型名：

```text
【骨相与五官】脸型为【窄长椭圆/柔长椭圆/短椭圆/鹅蛋/菱形/方圆/宽方/长方/倒三角/梨形/倒卵/颧宽/下颌角/窄额宽颧/长圆/短方/复合】，脸长与脸宽关系为【…】；最宽点在【太阳穴/颧弓/下颌角】，下颌沿【…】收窄至【圆/微尖/方/平】下巴；面中与下庭比例为【…】。眉【…】；眼【眼睑形态、眼裂长度高度、眼距、眼尾走向、虹膜颜色】；鼻【鼻根高低、鼻背直微弧、鼻尖形态、鼻翼宽度】；颧颊【…】；唇【口宽、唇峰、上下唇比例、唇角】。肤色与底调为【…】，皮肤保留【真实纹理程度（随风格增减）】，稳定识别点为【痣/疤/雀斑/眉缺口/面纹，写部位尺寸颜色与面部左右，两至四项】。
```

**防圆脸控制**：目标为窄长/菱形/心形时，在骨相段**前部**写清"脸长明显大于脸宽、颧弓不外鼓、下颌收窄、保留下庭长度"，并检查发型不横向蓬松框脸；负向词只排除短圆脸、婴儿肥、鼓胀苹果肌、宽圆下颌，不写"不要大脸"。甜美气质不绑定圆脸。

## 5. 气质转译槽（一条主气质 + 至多两条修饰）

```text
【体态与气质转译】主气质为【明亮亲和/娇憨灵动/清冷疏离/明艳强势/温柔知性/野心攻击/尊贵统御/疲惫受创】，可见为【站姿、肩颈、重心、视线停留、动作速度与空间占用】；修饰方向为【…】。站姿【…】，双手自然空置于【…】。
```

气质不得自动指定脸型或服装；"强势女性≠西装"、"温柔女性≠白裙"、"男主≠黑大衣"。

## 6. 腿部层与鞋袜槽（独立于风格与气质，禁止默认件）

按 `palette-costume-jewelry.md` 的覆盖长度、织法、渐变、装饰与鞋履关系组合：

```text
【袜类/腿部层】腿部层为【裸腿，无袜 / 短白袜 / 中筒 / 长袜 / 连裤袜 / 绑腿 / 护膝 / 功能袜】，【透明度/厚度】、【织法/渐变/装饰】、袜口【固定方式】，与鞋口【衔接关系】。
【鞋履】鞋型【…】、鞋头【…】、鞋面【…】、鞋底/跟高【…】、闭合结构【…】、材质【…】，与裤脚/裙摆【关系】。
```

裸腿也明确写"裸腿，无袜"。黑丝袜、厚底大头鞋、短白袜都只是可选，不作任何性别的默认件。腿部层与鞋型独立选择后再做整体比例核对。

玄幻修仙/仙侠/修真题材的腿部层与足部不限于袜类：按 `xianxia-manju-costume-library.md` 槽F/槽G 选择鞋履（绣履、软底纱履、绑带凉履、软靴、长筒战靴、赤足+足环、悬浮踏云等）与腿足点缀（腿环、大腿绑带、缠腿飘带、踝链、足环、脚背珠链、绑腿、护胫、腿纹等）；写清左右可不对称、固定方式与是否随动作摆动，无腿饰也必须明确写出“无”。赤足与悬浮须与身份或功法绑定并给理由，未成年角色仍按合宜着装执行。

## 7. 正负向冲突检查（交付前逐项过）

- **语义冲突**：裸腿与连裤袜并存；半扎与全盘发并存；同件衣物既开襟又完全闭合；写无饰品又出现项链。
- **结构冲突**：短内袖伸出长外袖；裙长覆盖袜口却要求看清袜口；冠饰/肩带/披帛互相穿透；鞋扣包袋左右前后不一致。
- **视觉冲突**：轻盈制服配巨大鞋底或仪式披肩；面部被发饰高光与复杂领口抢焦点。
- **正负向冲突**：负向不得禁止正向已选的袜型/领带/制服/配饰/材质；修订后删除过时负向词。
- **资产用途冲突**：16:9、同一人四视图、全身完整、双手空置；不得出现抱书/拿手机/扶剑柄/手提包。
- **模型输入冲突**：每件物体只有一个确定版本；不保留"或者/任选/同上"，不把多套候选拼成一条。
- **风格一致性冲突**：基座槽位填满后，风格增减表的"减"列不得残留；负面词基线须与所选风格匹配，不得跨风格混用。

## 8. 角色成稿要求矩阵（不提供固定成稿文本）

### 8.1 硬性规定：本文件不写死任何角色成稿

- 本节只规定**每条人物提示词必须满足的要求**，不提供可以直接复制、改名即用的整段成稿文本；任何一条四视图提示词都必须由执行者按"1.1 映射表"从各素材库取词、现场组合生成，不得从本节或任何文件照抄字符串。
- 禁止把任何具体设计词（具体脸型名、发色词、面料词、饰品词、风格标签）当作固定答案套用；设计词一律从对应素材库现取，并随骨相、气质、题材、角色层级、剧情状态变化。
- 若发现自己在复用同一段服装/发型/饰品描写，判定为违规，须重新从库取词。
- 同一作品中多名核心角色必须在骨相、气质、发型发色、上身层数、下身型、腿部层与鞋型上落在不同组合，不得复用同一套落词。

### 8.2 每条人物提示词必须覆盖的槽位要求

| 槽位 | 取词来源库 | 必须满足的要求 |
|---|---|---|
| 版式与一致性 | 本文件 §1 基座 | 16:9 四视图（左超大正面胸像 + 右侧正面/左转45°/背面全身）；同身份、同骨相、同发型发色、同服装、同配饰；双手空置 |
| 视觉风格 | 本文件 §2 + 视觉风格模块库 | 选定一种主风格并按 §2 的加/减/负面词基线落地；不得残留"减"列内容；负面词与风格匹配 |
| 骨相与五官 | 骨相/脸型库 | 写明脸型路径、额颧颌下巴关系、面部软组织量、面中与下庭比例；每条角色落在不同骨相路径 |
| 妆面 | 妆容库 | 按气质与题材给妆面方向与工艺、浓淡；素颜须有题材依据 |
| 发型发色 | 发型库 | 写明长度、分区、发缝、体积、垂落关系、发色与发丝质感；核心角色之间不得同构 |
| 上身衣层 | 服饰/造型库 + 仙侠服饰槽位库 | 按题材下限判定“结构丰富度”：玄幻修仙/仙侠/修真男主女主须命中 `xianxia-manju-costume-library.md` 第5节任一路径（重工多层叠 / 半透纱罩层次 / 高开衩+披帛飘带 / 抹胸+外纱外套 / 腰封+腿饰绑腿结构 / 大氅披风+内层结构），不设固定层数，也不为凑层数强加无露出关系的衣层；古风宫廷按宫廷等级标记；都市现代题材按 `modern-manju-costume-library.md` 九槽组合生成，可单层，但须写明剪裁、面料、层搭露出关系与版型 |
| 露肤与开衩 | 仙侠/现代服饰槽位库 | 玄幻修仙/仙侠/修真与都市现代题材须逐点写颈/肩/背/腰/腿的露肤程度与开衩位置高度（可全覆盖但须明确写出）；不与性别或气质绑定，不默认露腿 |
| 下身结构 | 服饰/造型库 | 写清裤/裙/裙裤型、腰位、长度、褶向或裤线、内外叠层 |
| 腰肩腕承载 | 服饰/造型库 | 写清腰封/腰带、肩背披覆、腕部承载与法器/挂具挂点及受力点；道具只呈现挂具不持物 |
| 鞋履 | 鞋履库 | 写清鞋型、鞋头、鞋底、跟高、闭合方式与装饰 |
| 袜类/腿部层 | 袜类库 | 写清袜型、袜长、袜口位置、有无装饰，以及与鞋口/裙裤的衔接关系 |

| 环境与光线 | 视觉风格模块库 | 影棚光位方向、补光、色温、阴影与噪光控制；**资产板背景固定为单一纯色无缝底（白底/淡灰底），不写场景环境** |

### 8.3 差异化硬约束（替代原先的"示例差异自检"）

- 同一作品多名核心角色必须形成可验证差异：骨相路径、主气质、发型发色、上身廓形与层搭路径、下身型、腿部层、鞋型、饰品成套等级——任两项不得与同作其他核心角色相同。
- 玄幻修仙/仙侠/修真：还须满足 `xianxia-manju-costume-library.md` 第4节的槽位差异化硬约束——同作同类角色至少四个槽位取不同选值，且差异必须包含廓形、层搭或纱质处理、露肤与开衩处理、鞋履中的至少两项；只换配色与花纹判定不合格。
- 都市现代题材：还须满足 `modern-manju-costume-library.md` 第4节的槽位差异化硬约束——同作同类角色至少四个槽位取不同选值，且差异必须包含廓形、层搭、露肤处理、鞋履中的至少两项；只换配色与款式名判定不合格。同一角色多套场合造型须写明"保持参考人物的五官、发型和身材比例不变，仅调整服装与配饰"。
- 玄幻修仙/仙侠/修真/古风宫廷的男主女主：装饰密度、定点工艺与成套配饰为默认下限，不可削减；"克制、素雅、清冷"只降装饰密度与色彩对比，不降材质与工艺等级（细则见 `character-archetype-wardrobe-library.md` §1.0）。
- 凡俗、外门、受伤、逃亡、末世等降级造型须由剧情明确写出，并保留身份识别点。
- 定稿后须按 `character-styling-review.md` 的"装饰密度与成套度检查"逐条验收，未过不得进入生图。

## 9. 平台实践增量（抖音 / 小红书 / 知乎 / 哔哩哔哩 / 红果漫剧）

以下为本地 MiniMaxH3 源文件已有的社区经验摘要，保留其制作建议；本次没有重新核验平台原文，不作为新增男主规则的外部证据。检索状态见 `asset-research-basis.md`。

### 9.1 变脸防护

- 骨相几何前置（§4）；进入 P3/P4 后每个含该角色的镜头提示词复述其 2 项稳定识别点（从 Look Card"稳定识别点"字段引用），不只依赖参考图。
- 每镜真实绑定该角色四视图板（当前 Seedance 版本核验支持的参考方式；上传文件与用途登记在请求清单）；`same character, consistent outfit` 类关键词仅辅助，不替代结构句与附件绑定。

### 9.2 动作与神态稳定

- 人物资产板仍默认一张四视图，不加表情板/九宫格。
- 动作与神态稳定走 P3 `performance_plan`（基线→2–3 个有序微表情信号→收束）与 P4 表演过程句；同一动作多镜反复崩坏且导演谱无法约束时，才按需制作动作/表情参考板（非默认，按费用与确认规则逐张生成）。

### 9.3 四视图排版

- 跨平台收敛为"左侧大尺寸正脸胸像 + 右侧正面/侧面/背面全身"，§1 基座已符合，无需改版。
- "设定集信息栏 + 视觉色卡"为可选扩展，仅用户明确要求时加入，数值须来自项目设定，不编造。

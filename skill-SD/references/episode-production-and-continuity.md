# 单集生产与片段连续性

本文件供 Seedance 2.0/2.5 共用，只记录故事制作事实。具体输入模式、字段、素材约束和提示词语法必须回到锁定版本文件核验。

## 单集与片段

完整单集为连续剧情，目标时长90–180秒。单次模型生成片段是剪辑单元，按当前版本与接入限制拆分；不得把单段上限误当成单集长度，也不得用展示镜头、无因果空镜或长运镜补时。用户只要求局部测试时，标记为测试片段，不伪称完整单集。

先按场次转折和人物选择分集，再按可见因果链拆成生成片段。每个片段必须改变目标、信息、关系、危险、动作位置或观众理解中的至少一项。

## 片段卡

在编写模型提示词前，为每个片段记录：

| 字段 | 内容 |
|---|---|
| 片段职责 | 本段新增信息、推动的目标/关系/局势变化 |
| 承接来源 | 前一片段或场次；首段注明建立依据 |
| 首态 | 人物可见性、锚点、站位、朝向、视线、手与道具、伤损、场景状态、光线、环境动态及声音尾部 |
| 主因果链 | 触发 → 行动/应对 → 可见结果 → 新状态 |
| 焦点移交 | 先跟随谁，何时因何种可见事件交给谁 |
| 末态/接口 | 下一段能继承的构图、动作相位、表情、道具、场景和声音 |

“继续对视”“保持动作”不是足够的状态描述；用人物相对固定场景锚点的位置、肢体姿态、目光目标、环境运动方向等可画事实表达。

## 负荷与段缝

把对白试读、动作、反应停留和摄影变化分别估时。多人物入离场、道具交接、表情转折、切镜、显著运镜、复杂特效都会增加生成负荷；当一个短片段同时塞入多次切镜、连续走位、长对白和精细交互时，拆分或删减非关键动作，不删冻结台词或关键因果。

跨片段续接基于已生成、人工审核并归档的实际成片末态。记录真实末帧中的站位、视线、动作相位、道具、伤损、光线、天气/粒子、场景破坏和声音尾部。提示词中的“预期末态”不能替代已生成片段的实际末态。若该版本/接入支持图像锚定，才从已归档片段提取真实帧并按对应模式绑定；否则用文本重建接缝或后期剪接，不伪称有首尾帧控制。

## 生成绿灯与审看

提交前检查片段职责、因果链、出场顺序、角色可见性、动作起因与结果、资产绑定、对白原文、接缝状态、锁定版本能力、费用授权和媒体映射。生成后先逐段审核，再与前后段连看。

问题记录包含片段ID、时间码、可复现证据、失败类别、最小修复和受影响邻段。身份/可见性、空间轴线、动作因果、剧情表演、摄影声音依次排查。先修根因：资产或锚图回资产阶段，站位/动作/台词回导演稿，字段/素材回版本编译，只对生成漂移返修对应片段。

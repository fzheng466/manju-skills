# 剧情故事板预演

## 适用边界

玄幻仙侠武打默认不使用故事板图预演；请改用 references/xianxia-martial-action-prompting.md 生成可核对的逐镜头动作状态表和详细提示词。其他题材仅在文字镜头表无法解决剧情顺序或空间理解问题时按需使用。本文件不代表每个项目必须生图。

## 用途

在付费视频生成前，用已确认角色资产、场景结构参考和必要道具，预演剧情的事件顺序、人物可见性与站位、观察关系、动作因果、情绪反应、环境动态和片段接缝。故事板不证明视频运动、口型或声音表现已经达标。

## 分格

格数跟随实际剧情节拍，不设固定格数；单张最多24格。超过24格时，在自然动作/信息节点按连续时间线拆为多张，并让前板末格与后板首格继承相同的人物位置、朝向、动作相位、场景状态与必要声音尾部。每格表达一个可辨动作状态、观察变化或信息揭示；动作链保留足够的起手、变化和结果。

板外登记 `panel_id / shot_id / 时间窗 / 焦点或观察者 / 景别与机位 / 可见角色及场景锚点 / 视线目标 / 动作起点与结果 / 环境动态 / 下一格承接`。图内不要依赖模型生成可读文字。主观镜头先明确观察者与视线证据，再展示所见或反应；武打按起手、应对、接触、受力、新站位拆格。

## 参考和审核

每张板注明真实输入和控制范围：角色图负责身份与衣着，场景图负责可见空间结构，道具图负责形态；具体镜位、走位、表演和动作由镜头计划控制。逐格检查身份、场景锚点、世界轴、前后状态与事件顺序；只修受影响的格子及其接缝。

用户确认故事展示后记录版本与审核结论。整张多宫格图不能直接当作首帧、尾帧或唯一视频参考。只有锁定版本的输入模式允许时，才将通过的单格裁成无边框、无标注的锚图，复核画幅、清晰度和资产一致性后绑定。故事板通过本身不构成视频生成授权。

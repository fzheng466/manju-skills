# 剧本审查、分镜交接与修补

审查不直接覆盖原稿。每项问题记录场次、原句或事件证据、观众影响、严重度和最小修补。

| 等级 | 判定 | 处理 |
|---|---|---|
| P0 | 因果断裂、人物无证据知情、道具能力凭空出现、锁定事实冲突、不可拍或无法接续 | 冻结前必须修复 |
| P1 | 动机不足、说明性台词、关系跳跃、动作或空间不可读、无推进、集尾接口弱 | 给最小改法并复审 |
| P2 | 台词节奏、情绪层次、视觉化、场景复用或细节优化 | 供选择 |

审查顺序：事实与知识、因果与选择、人物动机与关系、道具能力空间、可拍性连续性、节奏与集尾。

跨集硬伤给前向修补和后向修补：前向在未定稿前文补入必要触发、来源或条件；后向在当前场提供可见证据和合理行动。修订后只更新受影响账本和相邻场次。

分镜交接时，每个beat记录时间窗、焦点、可见行动、场景锚点和画面区域、身体朝向、视线、出场顺序、表演、台词和声音、末态。它只传递已发生或锁定事实，不是视频提示词。

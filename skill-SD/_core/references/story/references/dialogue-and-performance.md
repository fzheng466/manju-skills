# 对白与表演

每句对白先写说者意图：试探、掩饰、索取、拒绝、施压、安抚、拖延或承认。再写听者实际听到什么、何时反应、关系如何变化。

| 字段 | 内容 |
|---|---|
| utterance ID | 稳定ID |
| 说者与听者 | 角色ID、画内/OS/VO |
| 冻结原句 | 原文和标点 |
| 触发 | 角色看到、听到或选择什么后开口 |
| 表演 | 视线、呼吸、音量、语速、重音、停顿和句末状态 |
| 听者反应 | 触发词或句尾后的可见反应 |
| 结果 | 信息、关系或行动的变化 |

对白不替代行动。说明性信息优先让人物在争取、隐瞒、验证、误解或付代价时说出。真正需要情绪高潮的句子前后保留可读反应；人物发声时不安排复杂走位、精细道具操作和无因运镜。

潜台词来自角色目标与限制，不是给普通台词附加神秘感。角色说与想不同，必须能从回避、停顿、换题、动作停止、选择或后果读出。

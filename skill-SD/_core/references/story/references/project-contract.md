# 剧集账本与文件契约

长篇或连续剧使用唯一账本，不创建互相矛盾的设定表。仅在用户要求落盘时创建项目目录。

| 账本 | 必填内容 |
|---|---|
| 事实与规则 | ID、内容、来源场次、状态、锁定条件、允许变化 |
| 人物知识 | 角色、已知事实、未知或误解、获得信息的场次与证据 |
| 关系与情感 | 角色对、权力位、信任或敌对、隐藏意图、变化触发 |
| 道具与能力 | ID、持有人或位置、状态、启动条件、范围、代价、最近变化 |
| 伏笔与回收 | ID、埋设锚点、观众已知程度、计划回收条件、实际回收、状态 |
| 场景状态 | 场景、固定结构、天气光线、入口、损伤、持续动态、可用范围 |
| 集与场次 | 集号、场号、时间地点、目标、冲突、结果、首态、末态、接续场次 |

状态使用 planned、active、resolved、stale 或 locked。locked项只能由用户明确授权修改。作者真相、角色所知、观众所知分别记录；角色只可依据实际得到的信息行动。

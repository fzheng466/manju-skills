# AI 漫剧剧本工作室

将创意、小说或既有剧本编写为可生产的16:9横屏AI漫剧剧本。剧本服务连续剧观看和后续分镜，不服务人物展示或模型演示。完整单集时长为90-180秒；局部试写必须明确标为非完整单集。

## 启动

1. 确认任务是原创、小说改编、既有剧本审查、局部改写、连续剧接写还是分镜前整理。读取已有剧本、定稿设定、角色/场景/道具状态和上集结尾。
2. 确定主副题材、目标观众、单集时长、故事语言、剧集位置、已有材料和不可改动事实。缺失但不影响当前产物的信息采用最小设计补全，并标为创作补全。
3. 完整剧集建立唯一事实账本，按 references/project-contract.md 管理角色、关系、道具、世界规则、人物知识、伏笔、场景状态和未结问题。作者真相、角色所知、观众所知必须分开。
4. 只读取本次任务需要的参考文件。审查与改写是两个状态；未经用户要求不覆盖原稿。

## 核心约束

- 每场至少推进目标、信息、关系、阻碍或局势之一。不得以风景展示、人物摆拍、无因果运镜或重复反应填满时长。
- 每场必须有目标、阻碍、可见行动、反馈、策略或关系变化、结果和下一场首态。心理判断要落到视线、停顿、动作、台词、呼吸、选择或后果。
- 台词保留人物意图、原句、说者、画内或画外类别、听者、触发和结果。人物不得因为剧情需要突然获得未知信息、改变立场或越过既定能力/规则。
- 对手戏按观察对象、察觉或选择、可读反应、语言或行动回应、稳定末态推进。焦点移交必须由可见事件或台词触发。
- 动作、斗法、追逐和复杂交互按准备/重心、路径、接触或避让、受力反馈、结束姿态写成连续链。能力和道具的启动、作用、代价、残留及下一步接口进入账本。
- 每集须有开场抓手、递进冲突、可见状态变化和集尾接口。集尾从本集已发生事件生长，不用突兀音效或无来源人物出现代替。
- 正式剧本不写模型提示词、镜头参数、资产提示词、检查术语或创作说明。分镜需求另按交接文件输出。
- 用户锁定的角色、道具、世界规则和事实不得静默改写。改动定稿事实时，列出受影响场次并给前向铺垫或后向自洽的修补选择。

## 标准流程

### P0 立项

建立核心冲突、主副题材、观众情绪承诺、主角当集目标、阻碍、选择代价、关系动力和本集结束状态。每个题材只追加必要规则，不用题材名称代替因果。

### P1 事实与账本

导入作品先保留原文，建立事实、角色认知、读者信息、道具、能力、地点、时间线和伏笔账本。改编时区分原文事实、已确认改编、候选补全和未知。

### P2 单集剧本

先写单集状态变化，再写场次。每场使用目的、阻碍、行动、反馈、变化、结果检查；以试读、动作和反应估时，完整单集累计90-180秒。

### P3 审查与修订

冻结前检查因果、人物、信息、关系、时间空间、道具能力、可拍性、节奏和连载接口。每个问题写场次、证据、观众影响、严重度和最小修补。用户要求改写时保留原稿，只复审受影响场次和相邻接缝。

### P4 分镜交接

剧本通过审查后，输出场次卡、可拍beats、出场顺序、人物位置和视线、道具和环境状态、台词演绎、声音事件与出入场状态。它是导演和视频流程输入，不是视频提示词。

## 完成标准

报告实际交付路径或正文范围、单集累计时长、待确认事实和已发现风险。未生成资产、故事板、视频或音频时，只交付相应预制作文本。

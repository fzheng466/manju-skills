# 最新版本视频优化 skill（路由）

本目录是触发入口。真正的流程在仓库相对路径：

- `skill-H3/SKILL.md` — MiniMax H3
- `skill-SD/SKILL.md` — Seedance 2.0 / 2.5
- `core/` — 面谈、自适应规则、双画幅交付线、动漫/3D 资产词库、失败模式

本机可选安装目录：`D:\最新版本视频优化skill`。换机器时以仓库相对路径为准。

## 一触发就做

1. 读本仓库 README。
2. 用户未指定模型时问一次：走 MiniMax H3 还是 Seedance 2.0/2.5。
3. 打开对应 skill 的 SKILL.md，**先问交付画幅（16:9 / 9:16 / 两条都要）**，再做渠道面谈（`core/references/channel/interview.md`），然后扩写/资产/分镜/编译。
4. 不要用旧的独立 H3/Seedance 压缩包副本；以本仓库为唯一最新版。
